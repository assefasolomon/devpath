⚖️ Balancing Redox — Oxidation Number Method

Balancing a redox equation isn't just about atoms — the electrons lost must equal the electrons gained. The oxidation number method uses a simple 6-step procedure to get it exactly right.

📖 Reading: ~22 min
✏️ Examples: 5 worked
🎯 Quiz: 5 questions
🎥 Videos: 4 resources
🎯
Introduction
What you will learn

In a redox reaction, chemical equations must balance two things: atoms (as in any equation) AND electrons (unique to redox). The oxidation number method tracks the change in oxidation state of each element and uses those changes to find the correct coefficients.

By the end of this lesson you will be able to:

  • Explain why redox equations need electron balance
  • Assign oxidation numbers to elements in any formula
  • Apply the 6-step oxidation number method
  • Balance redox equations like PbS + O₂ → PbO + SO₂
  • Handle fractional coefficients in redox balancing
  • Identify oxidizing and reducing agents after balancing
🔢
Oxidation Number Rules — Quick Reference
You need these before you can balance

Before applying the method, you must be fluent at assigning oxidation numbers. Here's the essential rule set:

RuleOxidation Number
Free element (Na, O₂, Cl₂)0
Monatomic ion (Na⁺, Cl⁻, Ca²⁺)Charge on the ion
Group IA metals in compounds+1
Group IIA metals in compounds+2
Fluorine in compounds−1 (always)
Hydrogen (with non-metals)+1
Hydrogen (with active metals)−1
Oxygen in most compounds−2
Oxygen in peroxides (H₂O₂)−1
Sum in a neutral compound0
Sum in a polyatomic ionCharge on the ion
📝 Quick example — Cr in K₂CrO₄

K = +1, O = −2. Let Cr = x → 2(+1) + x + 4(−2) = 0 → 2 + x − 8 = 0 → x = +6

📝
The 6-Step Oxidation Number Method
MoE Textbook, p. 59

This method is used to balance redox reactions that do not occur in aqueous solution, and also reactions that do not involve ions.

  1. Write an unbalanced chemical equation. Include all reactants and products.
  2. Assign oxidation numbers to all elements in the reaction.
  3. Identify the oxidized and reduced species from the changes in oxidation numbers.
  4. Compute electrons lost and gained from the oxidation number changes.
  5. Multiply by appropriate factors to make electrons lost = electrons gained. Use these factors as balancing coefficients.
  6. Complete the balancing by inspection — add states of matter.
📝 The key principle

Electrons lost = Electrons gained. This is the conservation of charge in a redox reaction. Every step in this method exists to enforce this equality.

Worked Examples
Two full textbook examples
Example 1PbS + O₂ → PbO + SO₂
Problem: Balance the following chemical equation using the change in oxidation-number method.
PbS(s) + O₂(g) → PbO(s) + SO₂(g)
Step 1
Write the unbalanced equation:
PbS(s) + O₂(g) → PbO(s) + SO₂(g)
Step 2
Assign oxidation numbers:
Pb in PbS = +2; S in PbS = −2
O in O₂ = 0
Pb in PbO = +2; O in PbO = −2
S in SO₂ = +4; O in SO₂ = −2
Step 3
PbS is oxidized — S changes from −2 to +4
O₂ is reduced — O changes from 0 to −2
Step 4
In the oxidation: S lost 6 electrons (−2 → +4)
In the reduction: O gained 2 electrons (0 → −2), but O₂ has 2 atoms → 4 electrons gained per O₂
Step 5
S lost 6 e⁻; O₂ gained 4 e⁻
LCM = 12 → multiply PbS by 2 and O₂ by 3
Put coefficient 3/2 before O₂ (to balance 6 lost = 4·(3/2) gained... see Step 6):
PbS(s) + 3/2 O₂(g) → PbO(s) + SO₂(g)
Step 6
Complete the balancing by inspection:
PbS(s) + 3/2 O₂(g) → PbO(s) + SO₂(g)
Both sides have 1 Pb, 1 S, and 3 O.
✅ Balanced: PbS + 3/2 O₂ → PbO + SO₂ (or multiply by 2 → 2PbS + 3O₂ → 2PbO + 2SO₂)
Example 2Cu + HNO₃ → Cu(NO₃)₂ + NO + H₂O
Problem: Balance the following chemical equation using the change in oxidation-number method.
Cu + HNO₃ → Cu(NO₃)₂ + NO + H₂O
Step 1
Write the unbalanced equation:
Cu + HNO₃ → Cu(NO₃)₂ + NO + H₂O
Step 2
Assign oxidation numbers to the elements that change:
Cu: 0 → +2
N in HNO₃: +5 → N in NO: +2
Step 3
Cu is oxidized — Cu goes 0 → +2
HNO₃ is reduced — N goes +5 → +2
Step 4
In the oxidation: Cu lost 2 electrons
In the reduction: each N gained 3 electrons (+5 → +2)
Step 5
Cu lost 2 e⁻, N gained 3 e⁻. LCM = 6 →
Put 3 before Cu and 2 before NO:
3Cu + ?HNO₃ → 3Cu(NO₃)₂ + 2NO + ?H₂O
Step 6
Complete by inspection: 3 Cu(NO₃)₂ contains 6 NO₃⁻ + 2 NO = 8 N total → coefficient 8 for HNO₃. Then 8 H → 4 H₂O.
3Cu + 8HNO₃ → 3Cu(NO₃)₂ + 2NO + 4H₂O
✅ Balanced: 3Cu + 8HNO₃ → 3Cu(NO₃)₂ + 2NO + 4H₂O
½
A Note on Fractional Coefficients
When to keep them, when to clear them
📌 Rule

During Step 5 of the method, you may temporarily get a fractional coefficient (like 3/2 or 5/2). This is normal and often unavoidable — it comes from setting electron loss = electron gain.

In a final answer, you can either keep the fraction or multiply the entire equation by the denominator to clear it. Both are correct.

Clearing the Fraction

PbS + 3⁄₂ O₂ → PbO + SO₂
(multiply everything by 2)
2PbS + 3O₂ → 2PbO + 2SO₂ ✓

📝 Exam tip

MoE exams typically accept both forms, but integer coefficients are preferred unless the problem says otherwise. Always check that the final equation is balanced for both atoms AND charge.

More Practice
3 additional worked problems
Example 3HNO₃ + H₃AsO₃ → NO + H₃AsO₄ + H₂O
Problem: Balance by the oxidation number method and identify the oxidizing and reducing agents.
Ox. numbers
N in HNO₃: +5 → N in NO: +2 (reduction, gain 3 e⁻)
As in H₃AsO₃: +3 → As in H₃AsO₄: +5 (oxidation, loss 2 e⁻)
Balance e⁻
LCM of 2 and 3 = 6 → multiply N-containing species by 2 and As-containing species by 3
Coefficients
2HNO₃ + 3H₃AsO₃ → 2NO + 3H₃AsO₄ + H₂O
Balance H & O
Left: 2+9 = 11 H, 6+9 = 15 O
Right: 2·1 + 3·3 + w·2 for H₂O — solve → w = 1
2HNO₃ + 3H₃AsO₃ → 2NO + 3H₃AsO₄ + H₂O
✅ Oxidizing agent: HNO₃ (N reduced)  |  Reducing agent: H₃AsO₃ (As oxidized)
Example 4KClO₃ + HBr → Br₂ + H₂O + KCl
Problem: Balance using the oxidation number method.
Ox. numbers
Cl in KClO₃: +5 → Cl in KCl: −1 (reduction, gain 6 e⁻)
Br in HBr: −1 → Br in Br₂: 0 (oxidation, loss 1 e⁻ per Br)
Balance e⁻
Cl gains 6 e⁻; each Br loses 1 e⁻ → need 6 Br atoms → 6 HBr
Coefficients
KClO₃ + 6HBr → 3Br₂ + KCl + 3H₂O
✅ Balanced: KClO₃ + 6HBr → 3Br₂ + KCl + 3H₂O
Example 5H₂S + HNO₃ → S + NO + H₂O
Problem: Balance by oxidation number method and identify agents.
Ox. numbers
S in H₂S: −2 → S: 0 (oxidation, loss 2 e⁻)
N in HNO₃: +5 → N in NO: +2 (reduction, gain 3 e⁻)
Balance e⁻
LCM of 2 and 3 = 6 → 3 H₂S and 2 HNO₃
Complete
3H₂S + 2HNO₃ → 3S + 2NO + 4H₂O
✅ Oxidizing agent: HNO₃  |  Reducing agent: H₂S

Lesson Summary
Everything you learned in Lesson 2.2
✅ Key Points — Oxidation Number Method
  • Redox equations must balance both atoms and electrons
  • Core principle: electrons lost = electrons gained
  • The method is best for reactions that do not involve ions or aqueous solutions
  • Follow the 6 steps: write → assign ox. no. → identify → compute e⁻ → balance e⁻ → inspect
  • Step 5 uses LCM to find the multipliers, then applies them as coefficients
  • Fractional coefficients (like 3/2) are OK — multiply the whole equation to clear if you prefer integers
  • Textbook examples: PbS + 3/2 O₂ → PbO + SO₂ and 3Cu + 8HNO₃ → 3Cu(NO₃)₂ + 2NO + 4H₂O
  • Once balanced, identify oxidizing and reducing agents from the changes
  • Reference: MoE Chemistry Grade 12 Student Textbook, §2.1.3 (pp. 59–61)
