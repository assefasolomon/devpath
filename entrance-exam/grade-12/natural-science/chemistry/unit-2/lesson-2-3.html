⚗️ Balancing Redox — Half-Reaction Method

The half-reaction method is the most reliable way to balance complex redox equations, especially in acidic or basic aqueous solutions. It splits the reaction into two halves, balances each separately, then recombines them.

📖 Reading: ~25 min
✏️ Examples: 5 worked
🎯 Quiz: 5 questions
🎥 Videos: 4 resources
🎯
Introduction
What you will learn

The half-reaction method (also called the ion-electron method) is the standard approach for balancing redox reactions that occur in aqueous solution — particularly those involving ions and especially those in acidic or basic media. It is more systematic than the oxidation number method and the method of choice in IB, AP, and EUEE exams.

By the end of this lesson you will be able to:

  • Split any redox equation into its oxidation half-reaction and reduction half-reaction
  • Balance each half-reaction for atoms (non-H/O → O → H) and charge
  • Use H₂O and H⁺ to balance in acidic media
  • Convert to basic media by adding OH⁻
  • Multiply and combine half-reactions so electrons cancel
  • Balance complex ionic equations like Fe²⁺ + Cr₂O₇²⁻ and MnO₄⁻ + I⁻
💡
The Half-Reaction Idea
Split, balance, recombine
📌 Core idea

Any redox reaction can be split into two separate half-reactions: one for oxidation and one for reduction. We balance each one independently, then add them back together, making sure the electrons cancel.

Half-Reaction Method — Workflow
📝 Remember

In an oxidation half-reaction, electrons appear as a product (right side).
In a reduction half-reaction, electrons appear as a reactant (left side).

⚖️
Acidic vs Basic Media
The key difference

The atoms-and-charge balancing rules are the same in both media — only the "helper" species differ:

🔴 Acidic Medium

Balance O by adding H₂O
Balance H by adding H⁺
Balance charge by adding e⁻

Example: Fe²⁺ + Cr₂O₇²⁻ → Fe³⁺ + Cr³⁺

🔵 Basic Medium

First balance as if it were acidic.
Then for every H⁺, add equal OH⁻ to both sides.
Combine H⁺ + OH⁻ → H₂O where they appear on the same side.
Cancel any remaining H₂O molecules.

📌 Balance order for atoms

1. Atoms other than O and H first (e.g., Cr, Mn, Fe, I)
2. Oxygen atoms (use H₂O)
3. Hydrogen atoms (use H⁺ for acidic; convert to OH⁻ for basic)
4. Charge (add electrons e⁻)

📝
The 5-Step Procedure
MoE Textbook, p. 62
  1. Separate the equation into an oxidation half-reaction and a reduction half-reaction.
  2. Balance the atoms and charges in each half-reaction. Balance atoms in this order: atoms other than O and H, then O, then H. For acidic media, add H₂O to balance O and H⁺ to balance H. Balance charge by adding electrons (e⁻) to the right in the oxidation half-reaction and to the left in the reduction half-reaction.
  3. Multiply one or both half-reactions by an integer so that the number of electrons gained in reduction equals the number of electrons lost in oxidation.
  4. Add the balanced half-reactions together and include states of matter. Electrons on both sides must cancel.
  5. Check that the atoms and charges are balanced on both sides of the final equation.
📝 For basic media

Proceed through all 5 steps as if the reaction were in acidic medium. Then, for every H⁺ ion, add an equal number of OH⁻ ions to both sides of the equation. Where H⁺ and OH⁻ appear on the same side, combine them to give H₂O. Finally, cancel any water molecules that appear on both sides.

✏️
Worked Examples
Two textbook examples
Example 1Fe²⁺ + Cr₂O₇²⁻ (acidic medium)
Problem: Use the half-reaction method to balance:
Fe²⁺ + Cr₂O₇²⁻ → Fe³⁺ + Cr³⁺
Step 1
Separate into half-reactions:
Fe²⁺ → Fe³⁺ (oxidation)
Cr₂O₇²⁻ → Cr³⁺ (reduction)
Step 2a
Oxidation half: Fe already balanced for atoms. Add 1 e⁻ to the right to balance charge:
Fe²⁺ → Fe³⁺ + e⁻
Step 2b
Reduction half (acidic): Balance Cr: Cr₂O₇²⁻ → 2Cr³⁺
Balance O by adding 7 H₂O on right: Cr₂O₇²⁻ → 2Cr³⁺ + 7H₂O
Balance H by adding 14 H⁺ on left: 14H⁺ + Cr₂O₇²⁻ → 2Cr³⁺ + 7H₂O
Balance charge (left = +12, right = +6 → add 6 e⁻ on left):
14H⁺ + Cr₂O₇²⁻ + 6e⁻ → 2Cr³⁺ + 7H₂O
Step 3
Oxidation gives 1 e⁻, reduction needs 6 e⁻. Multiply the oxidation half by 6:
6Fe²⁺ → 6Fe³⁺ + 6e⁻
Step 4
Add the two halves together and cancel the 6 e⁻ on both sides:
6Fe²⁺ + 14H⁺ + Cr₂O₇²⁻ + 6e⁻ → 6Fe³⁺ + 2Cr³⁺ + 7H₂O + 6e⁻
Cancelling electrons gives:
6Fe²⁺ + 14H⁺ + Cr₂O₇²⁻ → 6Fe³⁺ + 2Cr³⁺ + 7H₂O
Step 5
Check atoms: Fe: 6=6; Cr: 2=2; H: 14=14; O: 7=7
Check charge: Left = 6(+2) + 14(+1) + (−2) = +24. Right = 6(+3) + 2(+3) = +24 ✓
✅ 6Fe²⁺ + 14H⁺ + Cr₂O₇²⁻ → 6Fe³⁺ + 2Cr³⁺ + 7H₂O
Example 2MnO₄⁻ + I⁻ (basic medium)
Problem: Balance in basic solution:
MnO₄⁻ + I⁻ → MnO₂ + I₂
Step 1
Separate:
Oxidation: I⁻ → I₂
Reduction: MnO₄⁻ → MnO₂
Step 2a
Oxidation half: Balance I: 2I⁻ → I₂
Balance charge: add 2 e⁻ to right → 2I⁻ → I₂ + 2e⁻
Step 2b
Reduction half (as if acidic): Balance O by adding 2 H₂O on right: MnO₄⁻ → MnO₂ + 2H₂O
Balance H by adding 4 H⁺ on left: MnO₄⁻ + 4H⁺ → MnO₂ + 2H₂O
Balance charge: left = +3, right = 0 → add 3 e⁻ on left:
MnO₄⁻ + 4H⁺ + 3e⁻ → MnO₂ + 2H₂O
Step 3
Oxidation gives 2 e⁻, reduction needs 3 e⁻. LCM = 6 → multiply oxidation by 3 and reduction by 2:
3(2I⁻ → I₂ + 2e⁻)
2(MnO₄⁻ + 4H⁺ + 3e⁻ → MnO₂ + 2H₂O)
Step 4
Add and cancel electrons:
6I⁻ + 2MnO₄⁻ + 8H⁺ + 6e⁻ → 3I₂ + 2MnO₂ + 4H₂O + 6e⁻
After cancellation:
6I⁻ + 2MnO₄⁻ + 8H⁺ → 3I₂ + 2MnO₂ + 4H₂O
Convert to basic
Add 8 OH⁻ to both sides to neutralize the 8 H⁺:
6I⁻ + 2MnO₄⁻ + 8H⁺ + 8OH⁻ → 3I₂ + 2MnO₂ + 4H₂O + 8OH⁻
Combine H⁺ + OH⁻ → H₂O on the left (8 pairs give 8 H₂O):
6I⁻ + 2MnO₄⁻ + 8H₂O → 3I₂ + 2MnO₂ + 4H₂O + 8OH⁻
Cancel 4 H₂O from both sides:
6I⁻ + 2MnO₄⁻ + 4H₂O → 3I₂ + 2MnO₂ + 8OH⁻
Step 5
Check atoms: I: 6=6; Mn: 2=2; O: 2(4) + 4 = 12 on left, 2(2) + 4 + 8 = 12 on right ✓
Check charge: Left = 6(−1) + 2(−1) = −8. Right = 8(−1) = −8 ✓
✅ 6I⁻ + 2MnO₄⁻ + 4H₂O → 3I₂ + 2MnO₂ + 8OH⁻
🔵
Basic Medium Strategy — Quick Reference
Convert from acid to base in one line
📌 The conversion trick

Balance the equation as if it were in acidic medium, then:

Add (number of H⁺) OH⁻ to BOTH sides → H⁺ + OH⁻ → H₂O → cancel water

Worked conversion

Step A — Acidic form:
6I⁻ + 2MnO₄⁻ + 8H⁺ → 3I₂ + 2MnO₂ + 4H₂O

Step B — Add 8 OH⁻ to both sides:
6I⁻ + 2MnO₄⁻ + 8H⁺ + 8OH⁻ → 3I₂ + 2MnO₂ + 4H₂O + 8OH⁻

Step C — Combine H⁺ + OH⁻ → H₂O on left:
6I⁻ + 2MnO₄⁻ + 8H₂O → 3I₂ + 2MnO₂ + 4H₂O + 8OH⁻

Step D — Cancel 4 H₂O:
6I⁻ + 2MnO₄⁻ + 4H₂O → 3I₂ + 2MnO₂ + 8OH⁻

📝 Exam tip

In basic medium final answers, OH⁻ appears as a product if the reduction used up H⁺. If you see OH⁻ on the reactant side, double-check — you may have added it to the wrong side.

More Practice
3 additional worked problems
Example 3MnO₄⁻ + Fe²⁺ (acidic)
Problem: Balance in acidic medium:
MnO₄⁻ + Fe²⁺ → Mn²⁺ + Fe³⁺
Halves
Oxidation: Fe²⁺ → Fe³⁺ + e⁻
Reduction: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O
Balance e⁻
Multiply oxidation by 5 to match 5 e⁻ from reduction
Combine
5Fe²⁺ + MnO₄⁻ + 8H⁺ → 5Fe³⁺ + Mn²⁺ + 4H₂O
✅ 5Fe²⁺ + MnO₄⁻ + 8H⁺ → 5Fe³⁺ + Mn²⁺ + 4H₂O
Example 4Cr₂O₇²⁻ + I⁻ (acidic)
Problem: Balance in acidic medium:
Cr₂O₇²⁻ + I⁻ → Cr³⁺ + I₂
Halves
Oxidation: 2I⁻ → I₂ + 2e⁻
Reduction: Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O
Balance e⁻
Multiply oxidation by 3 to match 6 e⁻
Combine
Cr₂O₇²⁻ + 6I⁻ + 14H⁺ → 2Cr³⁺ + 3I₂ + 7H₂O
✅ Cr₂O₇²⁻ + 6I⁻ + 14H⁺ → 2Cr³⁺ + 3I₂ + 7H₂O
Example 5Cl₂ + OH⁻ (basic)
Problem: Balance in basic medium:
Cl₂ → Cl⁻ + ClO⁻ (disproportionation)
Halves
Reduction: Cl₂ + 2e⁻ → 2Cl⁻
Oxidation: Cl₂ + 4OH⁻ → 2ClO⁻ + 2H₂O + 2e⁻
Balance e⁻
Both halves have 2 e⁻ — already balanced
Combine
2Cl₂ + 4OH⁻ → 2Cl⁻ + 2ClO⁻ + 2H₂O
Simplify by dividing by 2:
Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O
✅ Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O

Lesson Summary
Everything you learned in Lesson 2.3
✅ Key Points — Half-Reaction Method
  • The half-reaction method splits redox reactions into oxidation and reduction halves
  • Balance atoms in this order: non-H/O → O → H
  • Acidic medium: balance O with H₂O, balance H with H⁺
  • Basic medium: first balance as acidic, then add OH⁻ to both sides for every H⁺, combine H⁺ + OH⁻ → H₂O, cancel water
  • Electrons: product in oxidation half, reactant in reduction half
  • Step 3 multiplies halves so e⁻ lost = e⁻ gained
  • Electrons must cancel when the halves are recombined
  • Key textbook example: 6Fe²⁺ + 14H⁺ + Cr₂O₇²⁻ → 6Fe³⁺ + 2Cr³⁺ + 7H₂O
  • Key textbook example (basic): 6I⁻ + 2MnO₄⁻ + 4H₂O → 3I₂ + 2MnO₂ + 8OH⁻
  • Reference: MoE Chemistry Grade 12 Student Textbook, §2.1.3 (pp. 62–65)
