⚡ Oxidation-Reduction Reactions

Redox reactions power batteries, rust iron, and keep you alive. Learn the modern definitions of oxidation and reduction, how to spot them in any reaction, and how to identify oxidizing and reducing agents.

📖 Reading: ~20 min
✏️ Examples: 5 worked
🎯 Quiz: 5 questions
🎥 Videos: 4 resources
🎯
Introduction
What you will learn

Every time you charge your phone, digest food, or watch iron rust, a redox reaction is at work. The term comes from the two coupled processes — reduction and oxidation — that always happen together. In this lesson we build the modern electron-based understanding of both.

By the end of this lesson you will be able to:

  • Define oxidation in terms of electron loss and change in oxidation number
  • Define reduction in terms of electron gain and change in oxidation number
  • Identify the species oxidized and reduced in a reaction
  • Distinguish the oxidizing agent from the reducing agent
  • Recognize redox reactions versus non-redox reactions
🔴
2.1.1 Oxidation
Loss of electrons
📌 Original Definition

The term oxidation was originally defined in terms of the addition of oxygen to a compound — for example, burning magnesium in air to form MgO.

📌 Modern Definition (MoE Textbook, p. 57)

Oxidation is a process in which an atom/element loses an electron and therefore increases its oxidation number.

Oxidation — Electron Loss
OIL — Oxidation Is Loss
of electrons (and oxidation number increases)
📝 Example

Zn → Zn²⁺ + 2e⁻
Zinc loses 2 electrons. Its oxidation number goes from 0 to +2. Zinc is oxidized.

🔵
2.1.2 Reduction
Gain of electrons
📌 Original Definition

The term reduction was originally used to describe the production of a metal from its ore — for example, extracting iron from iron oxide.

📌 Modern Definition (MoE Textbook, p. 58)

Reduction is a process in which an atom gains an electron and therefore decreases its oxidation number.

Reduction — Electron Gain
RIG — Reduction Is Gain
of electrons (and oxidation number decreases)
📝 Example

Cu²⁺ + 2e⁻ → Cu
Copper ion gains 2 electrons. Its oxidation number goes from +2 to 0. Copper is reduced.

📌 Key Statement (MoE Textbook, p. 58)

Oxidation and reduction reactions always occur in pairs. Since they cannot occur independently, they are collectively called Redox Reactions.

🔁
Oxidizing and Reducing Agents
Who causes what

Students often confuse the substance that is oxidized with the substance that causes oxidation. Here is the precise distinction:

🔴 Oxidizing Agent

Gets reduced itself
Takes electrons from the other species
Causes the other species to be oxidized

Example: Cu²⁺ in Zn + Cu²⁺ → Zn²⁺ + Cu

🔵 Reducing Agent

Gets oxidized itself
Gives electrons to the other species
Causes the other species to be reduced

Example: Zn in Zn + Cu²⁺ → Zn²⁺ + Cu

📝 Memory trick

The word always describes what the agent does to the OTHER species, not what happens to itself:

• Oxidizing agent → oxidizes the other species (and is reduced itself)
• Reducing agent → reduces the other species (and is oxidized itself)

Electron Flow in a Redox Reaction
Electrons flow from the reducing agent (oxidized) to the oxidizing agent (reduced).
⚖️
Redox vs Non-Redox Reactions
How to tell them apart

Not every reaction is a redox reaction. A quick test: track oxidation numbers. If any element's oxidation number changes, it is a redox reaction. If nothing changes, it is not.

Reaction TypeOxidation Number Change?Example
RedoxYes — at least one element changesZn + Cu²⁺ → Zn²⁺ + Cu
RedoxYesMg + 2HCl → MgCl₂ + H₂
Non-redox (acid-base)NoHCl + NaOH → NaCl + H₂O
Non-redox (precipitation)NoAgNO₃ + NaCl → AgCl↓ + NaNO₃
Non-redox (double displacement)NoH₂SO₄ + 2NaOH → Na₂SO₄ + 2H₂O
📝 Quick test procedure

1. Assign oxidation numbers to every element on both sides.
2. If any element's number changes → redox reaction.
3. If no number changes → non-redox reaction.

Worked Examples
5 problems solved step by step
Example 1Identify Oxidation and Reduction
Problem: For the reaction Mg(s) + 2HCl(aq) → MgCl₂(aq) + H₂(g), identify which species is oxidized and which is reduced.
Ox. numbers
Mg: 0 → +2  |  H: +1 → 0  |  Cl: −1 → −1 (unchanged)
Oxidized
Mg loses 2 electrons and its oxidation number increases → Mg is oxidized
Reduced
H⁺ gains 1 electron (per atom) and its oxidation number decreases → H⁺ is reduced
Spectator
Cl⁻ does not change — it is a spectator ion
✅ Mg is oxidized; H⁺ (from HCl) is reduced
Example 2Identify the Agents
Problem: In the reaction Zn(s) + Cu²⁺(aq) → Zn²⁺(aq) + Cu(s), identify the oxidizing agent and the reducing agent.
Ox. numbers
Zn: 0 → +2 (oxidized)  |  Cu: +2 → 0 (reduced)
Reducing agent
Zn is oxidized → it is the reducing agent (it gives electrons to Cu²⁺)
Oxidizing agent
Cu²⁺ is reduced → it is the oxidizing agent (it takes electrons from Zn)
✅ Reducing agent = Zn  |  Oxidizing agent = Cu²⁺
Example 3Spot the Redox Reaction
Problem: Which of the following is a redox reaction?
(a) HCl + NaOH → NaCl + H₂O
(b) 2Mg + O₂ → 2MgO
(c) AgNO₃ + NaCl → AgCl + NaNO₃
Check (a)
H: +1, Cl: −1, Na: +1, O: −2 → no change → not redox
Check (b)
Mg: 0 → +2 (oxidized); O: 0 → −2 (reduced) → redox ✓
Check (c)
Ag: +1 → +1, Na: +1 → +1, Cl: −1 → −1 → no change → not redox
✅ Only (b) 2Mg + O₂ → 2MgO is a redox reaction
Example 4Oxidation Number Change for Carbon
Problem: Determine the oxidation number of carbon in C₂O₄²⁻ (oxalate ion) and explain how the carbon is oxidized when oxalate is converted to CO₂.
Set up equation
2x + 4(−2) = −2 (where x = ox. no. of C)
Solve
2x − 8 = −2 → 2x = +6 → x = +3
Compare
In CO₂, C = +4. In C₂O₄²⁻, C = +3. Change is +3 → +4 → oxidation (loss of electrons)
✅ Oxidation number of C in C₂O₄²⁻ = +3; oxidation to CO₂ raises it to +4
Example 5Chromium and Chlorine Oxidation Numbers
Problem: Calculate the oxidation number of (a) Cr in K₂CrO₄ and (b) Cl in HClO₄.
(a) K₂CrO₄
K = +1, O = −2. Let Cr = x → 2(+1) + x + 4(−2) = 0 → 2 + x − 8 = 0 → x = +6
(b) HClO₄
H = +1, O = −2. Let Cl = x → +1 + x + 4(−2) = 0 → 1 + x − 8 = 0 → x = +7
✅ (a) Cr = +6  |  (b) Cl = +7

Lesson Summary
Everything you learned in Lesson 2.1
✅ Key Points — Oxidation-Reduction Reactions
  • Oxidation = loss of electrons → oxidation number increases
  • Reduction = gain of electrons → oxidation number decreases
  • Mnemonic: OIL RIG — Oxidation Is Loss, Reduction Is Gain
  • Oxidation and reduction always occur in pairs → redox reactions
  • Oxidizing agent = gets reduced; causes the other species to be oxidized
  • Reducing agent = gets oxidized; causes the other species to be reduced
  • To test if a reaction is redox: track oxidation number changes
  • Acid-base and precipitation reactions are usually not redox
  • Spectator ions do not change oxidation number and do not participate in redox
  • Reference: MoE Chemistry Grade 12 Student Textbook, §2.1.1–2.1.2 (pp. 57–58)
