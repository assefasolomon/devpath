⚖️ Equivalents and Normality

Normality is a concentration unit used frequently in acid-base titration. Instead of counting moles, it counts "reactive units" — accounting for how many H⁺ or OH⁻ each molecule can donate or accept.

📖 Reading: ~18 min
✏️ Examples: 5 worked
🎯 Quiz: 5 questions
🎥 Videos: 4 resources
🎯
Introduction
What you will learn

When you titrate an acid with a base, "equal moles" isn't always the neutralization condition. H₂SO₄ has TWO acidic protons per molecule. So 1 mole of H₂SO₄ can neutralize 2 moles of NaOH, not 1. The concept of equivalents captures this reactive capacity.

By the end of this lesson you will be able to:

  • Define equivalent and equivalent weight
  • Calculate the number of equivalents in a given sample
  • Define and compute normality
  • Convert between normality and molarity
  • Apply the titration equation N₁V₁ = N₂V₂
  • Perform neutralization calculations using equivalents
⚗️
9.1 Equivalents
The concept of reactive capacity
📌 Equivalent Definition

An equivalent is the amount of a substance that reacts with (or supplies) one mole of H⁺ ions in an acid-base reaction.

Number of Equivalents — Acids and Bases

📌 For Acids

The number of equivalents of an acid is the number of replaceable H⁺ ions per molecule:

n (equivalents) = number of ionizable H⁺ per molecule

📌 For Bases

The number of equivalents of a base is the number of replaceable OH⁻ ions per molecule:

n (equivalents) = number of OH⁻ provided per molecule

SubstanceFormulaEquivalents per mole (n)
Hydrochloric acidHCl1
Nitric acidHNO₃1
Acetic acidCH₃COOH1
Sulfuric acidH₂SO₄2
Phosphoric acidH₃PO₄3
Sodium hydroxideNaOH1
Barium hydroxideBa(OH)₂2
Aluminum hydroxideAl(OH)₃3
📝 Equivalent Weight

Equivalent Weight = Molar Mass / n

Example: Equivalent weight of H₂SO₄ = 98 g/mol ÷ 2 = 49 g/equivalent

🔢
9.2 Normality
The concentration unit based on equivalents
📌 Normality (N)

The normality of a solution is the number of equivalents of solute per liter of solution:

N = number of equivalents / liters of solution

Equivalent to: N = equivalents × 1000 / mL solution

Relationship Between Normality and Molarity

📌 Key Formula

N = M × n

Where M is molarity and n is the number of equivalents per mole (H⁺ or OH⁻ ions).

Examples

• 0.1 M HCl → 0.1 N (n = 1)
• 0.1 M H₂SO₄ → 0.2 N (n = 2)
• 0.5 M NaOH → 0.5 N (n = 1)
• 0.2 M Ba(OH)₂ → 0.4 N (n = 2)

📝 When is normality useful?

Normality is especially useful in titration problems because equal volumes of solutions with equal normality always neutralize each other — no need to consider stoichiometry separately.

🧪
9.3 The Titration Equation N₁V₁ = N₂V₂
Neutralization using normality

In a neutralization reaction, the acid and base must supply equal numbers of equivalents:

📌 Titration Equation

N₁ V₁ = N₂ V₂

Where:
• N₁ and N₂ are normalities of acid and base
• V₁ and V₂ are volumes in the same units (mL or L)

Why This Works

At the equivalence point: equivalents of acid = equivalents of base:

Derivation

N₁ × V₁ = equivalents of acid (in liters)
N₂ × V₂ = equivalents of base (in liters)

At equivalence: N₁V₁ = N₂V₂

📝 Compare with molarity method

Using molarity, you would need: M₁V₁/n₁ = M₂V₂/n₂ (where n is electrons transferred). Normality absorbs the n factor into the concentration, making the equation simpler.

Worked Examples
5 exam-style problems solved step by step
Example 1Calculate Normality from Molarity
Problem: What is the normality of a 0.5 M H₂SO₄ solution?
Formula
N = M × n
Find n
H₂SO₄ has 2 replaceable H⁺ ions per molecule → n = 2
Substitute
N = 0.5 × 2 = 1.0 N
✅ Normality = 1.0 N
Example 2Simple Titration
Problem: What volume of 2.0 N NaOH is required to neutralize 25.0 mL of 2.70 N H₂SO₄?
Formula
N₁ V₁ = N₂ V₂
Identify
Acid: N₁ = 2.70 N, V₁ = 25.0 mL
Base: N₂ = 2.0 N, V₂ = ?
Solve
V₂ = (N₁ V₁) / N₂ = (2.70 × 25.0) / 2.0
Compute
V₂ = 67.5 / 2.0 = 33.8 mL
✅ Volume of NaOH = 33.8 mL
Example 3Convert Molarity to Normality
Problem: What is the normality of 0.20 M H₃PO₄?
Formula
N = M × n
Find n
H₃PO₄ has 3 replaceable H⁺ ions → n = 3
Compute
N = 0.20 × 3 = 0.60 N
✅ Normality = 0.60 N
Example 4Calculate Normality from Mass
Problem: What is the normality of a solution made by dissolving 4.9 g of H₂SO₄ in enough water to make 500 mL of solution? (Molar mass H₂SO₄ = 98 g/mol.)
Find moles
moles = 4.9 g / 98 g/mol = 0.05 mol
Find equivalents
eq = moles × n = 0.05 × 2 = 0.10 eq
Convert volume
V = 500 mL = 0.500 L
Normality
N = eq / V = 0.10 / 0.500 = 0.20 N
✅ Normality = 0.20 N
Example 5Find Unknown Concentration
Problem: 20.0 mL of an HCl solution is titrated with 0.10 N NaOH. If 25.0 mL of NaOH is required to reach the end point, what is the normality (and molarity) of the HCl solution?
Formula
N₁ V₁ = N₂ V₂
Identify
HCl: N₁ = ?, V₁ = 20.0 mL
NaOH: N₂ = 0.10 N, V₂ = 25.0 mL
Solve
N₁ = (0.10 × 25.0) / 20.0 = 0.125 N
Convert to M
HCl has n = 1, so M = N/n = 0.125 M
✅ Normality = 0.125 N   Molarity = 0.125 M

Lesson Summary
Everything you learned in Lesson 1.9
✅ Key Points — Equivalents and Normality
  • An equivalent is the amount of substance that reacts with 1 mole of H⁺ (or OH⁻)
  • For acids, n = number of replaceable H⁺ ions per molecule
  • For bases, n = number of OH⁻ ions per molecule
  • Equivalent weight = Molar Mass / n
  • Normality (N) = equivalents / liter of solution
  • N = M × n — the key conversion formula
  • 0.1 M H₂SO₄ = 0.2 N; 0.5 M H₃PO₄ = 1.5 N
  • N₁V₁ = N₂V₂ — the titration equation at the equivalence point
  • Volume can be in mL or L as long as both sides use the same unit
  • Normality simplifies titrations because it accounts for equivalent ratios directly
