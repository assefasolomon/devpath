🔢 Logic Gates and Logic Circuits

Logic gates are the building blocks of every digital computer. Learn how simple switches — AND, OR, NOT, NAND, NOR — implement logical operations and turn 0s and 1s into everything from calculators to AI.

Introduction
What you will learn

Digital electronics processes information as 0s and 1s. Logic gates are the fundamental circuits that implement logical operations on these binary values. Every computer, calculator, and smartphone is built from billions of logic gates.

By the end of this lesson you will be able to:

  • Differentiate analog and digital signals
  • Understand positive and negative logic
  • Draw symbols and truth tables for AND, OR, NOT
  • Draw symbols and truth tables for NAND, NOR
  • Write Boolean expressions for each gate

Explanation

6.1 Analog vs Digital Signals

📌 Analog Signal

A continuous signal that varies smoothly with time — can take any value. Example: a sine wave voltage from 0 to 5 V. Analogue signals carry sound and temperature naturally.

📌 Digital Signal

A signal that takes only discrete values. In binary digital circuits: two values only — 0 (low, off) or 1 (high, on).

Any information — pictures, music, text, video — can be turned into a pattern of 0s and 1s.

Analog vs Digital Waveforms
Analog (red) is continuous; digital (green) toggles only between 0 and 1 — clean, noise-resistant, and easy to process.

6.2 Positive and Negative Logic

📌 Positive Logic

• 1 = ON circuit, closed switch, HIGH voltage (e.g., 5V), TRUE
• 0 = OFF circuit, open switch, LOW voltage (0V), FALSE

📌 Negative Logic

• 0 = ON circuit, HIGH voltage, TRUE
• 1 = OFF circuit, LOW voltage, FALSE

6.4 Universal Gates — NAND and NOR

NAND Gate
🔗○
NOT + AND — output is 0 only when ALL inputs are 1
y = (A·B)‾
NOR Gate
⊕○
NOT + OR — output is 1 only when ALL inputs are 0
y = (A+B)‾
📝 Why "Universal Gates"?

NAND and NOR are called universal logic gates because ANY other gate can be built from combinations of NAND alone or NOR alone.

6.5 Boolean Algebra Basics

📌 Notation Rules

• OR → addition sign + (e.g., y = A + B)
• AND → multiplication sign · (e.g., y = A·B)
• NOT → bar over symbol ‾ (e.g., y = Ā)

Note: In Boolean algebra, 1 + 1 = 1 (NOT 2). Logic has no "2".

Worked Examples
5 exam-style problems solved step by step
Example 1AND Gate Output
Problem: An AND gate has inputs A = 1 and B = 0. What is the output?
Rule
AND outputs 1 only when ALL inputs are 1.
Apply
A = 1, B = 0 → at least one input is 0.
✅ Output y = 0
Example 2OR Gate Output
Problem: An OR gate has inputs A = 0 and B = 1. What is the output?
Rule
OR outputs 1 when ANY input is 1.
Apply
B = 1 → output = 1 regardless of A.
✅ Output y = 1
Example 3NOT Gate Output
Problem: A NOT gate has input A = 1. What is the output?
Rule
NOT inverts the input: 0 → 1, 1 → 0.
Apply
Input = 1 → output = 0.
✅ Output y = 0
Example 4NAND Gate Output
Problem: A NAND gate has inputs A = 1 and B = 1. What is the output?
Step 1
AND of 1 and 1 = 1
Step 2
NAND = NOT(AND) = NOT(1) = 0
✅ Output y = 0 (NAND outputs 0 only when both inputs are 1)
Example 5Circuit from a Truth Table
Problem: Given the truth table below, what single gate produces this output?
Table
A=0, B=0 → 1
A=0, B=1 → 0
A=1, B=0 → 0
A=1, B=1 → 0
Compare
Output is 1 only when BOTH inputs are 0 — matches NOR gate.
✅ The gate is NOR

Lesson Summary
Everything you learned in Lesson 5.6
✅ Key Points — Logic Gates and Logic Circuits
  • Analog signals are continuous; digital signals are discrete (0 or 1).
  • Positive logic: 1 = ON/HIGH, 0 = OFF/LOW.
  • Three basic gates: AND, OR, NOT.
  • AND: y = A·B — output 1 only if both inputs are 1.
  • OR: y = A+B — output 1 if either input is 1.
  • NOT: y = Ā — inverts the input.
  • NAND: y = (A·B)‾ — inverse of AND.
  • NOR: y = (A+B)‾ — inverse of OR.
  • NAND and NOR are universal gates — any other gate can be built from them.
  • In Boolean algebra, 1 + 1 = 1 (there's no "2" in logic).
  • Logic gates are the foundation of every digital computer.
