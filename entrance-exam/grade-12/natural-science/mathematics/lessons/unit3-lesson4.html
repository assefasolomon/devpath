Introduction
Why applications matter most

The derivative is not just a mathematical object — it is a powerful tool for solving real problems. A farmer wants to build a fence that encloses the maximum area. A company wants to minimize its cost. An engineer needs to find the highest point of a structure. All of these problems are solved using derivatives.

This lesson brings together everything from Unit 3 — the derivative definition, differentiation rules, and second derivatives — and applies them to practical problems that appear directly on the Ethiopian entrance exam.

By the end of this lesson you will be able to:

  • Find intervals where f is increasing or decreasing using the sign of f'
  • Find all critical points by solving f'(x) = 0
  • Classify critical points using the first or second derivative test
  • Find absolute maximum and minimum on a closed interval [a, b]
  • Solve optimization word problems step by step
  • Use all information to sketch the graph of a function
📖
Explanation
Complete theory with sign charts and visual diagrams

2.1 Increasing and Decreasing Functions

📌 Increasing/Decreasing Test

If f'(x) > 0 on an interval → f is increasing on that interval.
If f'(x) < 0 on an interval → f is decreasing on that interval.
If f'(x) = 0 at a point → f has a critical point there.

f' > 0 → rising (green), f' < 0 → falling (red), f' = 0 at turning points (critical points).

2.2 Critical Points and Local Extrema

A critical point is where f'(x) = 0 or f'(x) does not exist. At critical points, f may have a local maximum, local minimum, or neither (inflection with horizontal tangent).

📌 First Derivative Test

Suppose x = c is a critical point of f.

• If f' changes from positive to negative at c → local maximum
• If f' changes from negative to positive at c → local minimum
• If f' does not change sign at c → neither (saddle point)

Sign chart: when f' goes from + to − at c, the function has a local maximum at x = c.

2.3 Absolute Maximum and Minimum on [a, b]

On a closed interval [a, b], the absolute extrema (global max/min) occur at either critical points or endpoints. Use the Closed Interval Method:

1
Find all critical points in (a, b) by solving f'(x) = 0
2
Evaluate f at each critical point and at both endpoints a and b
3
The largest value is the absolute maximum. The smallest value is the absolute minimum.
⚠ Never forget the endpoints!

The absolute maximum or minimum can occur at an endpoint, not just at a critical point. Always check all three types of candidates: f(a), f(critical points), f(b).

2.4 Optimization — Solving Word Problems

Optimization problems ask you to maximize or minimize a quantity. Follow these steps:

1
Read carefully. Identify what is being maximized or minimized (the objective function) and what constraints are given.
2
Draw a diagram and label all variables clearly.
3
Write the objective function in terms of one variable only (use the constraint to eliminate extra variables).
4
Differentiate and set f'(x) = 0 to find critical points.
5
Verify using the second derivative test or by checking values.
6
Answer the question — state the maximum or minimum value with units.

2.5 Curve Sketching Checklist

To sketch the graph of f accurately using calculus:

Using f(x)
  • Domain and range
  • x-intercepts (set f=0)
  • y-intercept (set x=0)
  • Symmetry (even/odd)
Using f'(x) and f''(x)
  • Critical points (f'=0)
  • Increasing/decreasing intervals
  • Local max and min
  • Concavity and inflection points

Worked Examples
5 exam-style problems covering all applications
Example 1 Increasing and Decreasing Intervals
Problem: Find the intervals where f(x) = x³ − 3x² − 9x + 5 is increasing and decreasing.
Find f'
f'(x) = 3x²−6x−9 = 3(x²−2x−3) = 3(x−3)(x+1)
Critical points
f'(x) = 0  ⟹  x = 3 and x = −1
Sign chart
x < −1: test x=−2: f'(−2)=3(−5)(−1)=15 > 0 → increasing
−1 < x < 3: test x=0: f'(0)=3(−3)(1)=−9 < 0 → decreasing
x > 3: test x=4: f'(4)=3(1)(5)=15 > 0 → increasing
✅ Increasing on (−∞,−1) and (3,∞). Decreasing on (−1, 3).
Example 2 Finding and Classifying Local Extrema
Problem: Find all local maxima and minima of f(x) = x³ − 3x² − 9x + 5.
Critical points
From Example 1: x = −1 and x = 3
Classify x = −1
f' changes from + to − → local maximum
f(−1) = (−1)³−3(1)−9(−1)+5 = −1−3+9+5 = 10
Classify x = 3
f' changes from − to + → local minimum
f(3) = 27−27−27+5 = −22
✅ Local maximum (−1, 10). Local minimum (3, −22).
Example 3 Absolute Extrema on a Closed Interval
Problem: Find the absolute maximum and minimum of f(x) = x³ − 6x² + 9x + 1 on [0, 4].
Find critical points
f'(x) = 3x²−12x+9 = 3(x−1)(x−3) = 0
Critical points: x = 1 and x = 3 (both in [0,4])
Evaluate all
f(0) = 0−0+0+1 = 1
f(1) = 1−6+9+1 = 5
f(3) = 27−54+27+1 = 1
f(4) = 64−96+36+1 = 5
✅ Absolute maximum = 5 at x=1 and x=4. Absolute minimum = 1 at x=0 and x=3.
Example 4 Optimization — Maximum Area (Classic Exam Problem)
Problem: A farmer has 120 m of fencing to enclose a rectangular field. One side is a river (no fence needed). Find the dimensions that maximize the area.
Rectangle with one side along the river. Three sides need fencing: x + 2y = 120.
Constraint
x + 2y = 120, so x = 120 − 2y
Objective
Maximize Area = xy:
A(y) = (120−2y)y = 120y−2y²
Differentiate
A'(y) = 120−4y = 0  ⟹  y = 30
Verify max
A''(y) = −4 < 0 → concave down → maximum ✓
x = 120−2(30) = 60
✅ Maximum area when x = 60 m (side parallel to river) and y = 30 m (each perpendicular side). Max area = 60 × 30 = 1800 m²
Example 5 Optimization — Minimum Cost
Problem: A company produces x units at a total cost C(x) = x³ − 6x² + 15x + 10 (in hundreds of ETB). Find the production level that minimizes the marginal cost.
Marginal cost
Marginal cost = C'(x):
C'(x) = 3x²−12x+15
Minimize C'(x)
Differentiate C'(x) and set equal to zero:
C''(x) = 6x−12 = 0  ⟹  x = 2
Verify minimum
C'''(x) = 6 > 0 → x=2 is a minimum of C'(x) ✓
C'(2) = 3(4)−12(2)+15 = 12−24+15 = 3
✅ Marginal cost is minimized at x = 2 units, with minimum marginal cost = 3 hundred ETB.

Lesson Summary
Everything you learned in Unit 3 Lesson 4
✅ Key Points — Applications of Derivatives
  • f'(x) > 0 on interval → f increasing. f'(x) < 0 → f decreasing.
  • Critical points: solve f'(x) = 0. These are candidates for local extrema.
  • First Derivative Test: f' changes + → − means local max; − → + means local min.
  • Second Derivative Test: at critical point a, f''(a)>0 → min; f''(a)<0 → max.
  • Absolute extrema on [a,b]: evaluate f at all critical points AND both endpoints, then compare.
  • Optimization: write objective function in one variable using the constraint, differentiate, solve f'=0.
  • Classic result: among all rectangles with fixed perimeter, the square has maximum area.
  • Always verify your answer is a maximum or minimum using the second derivative or sign chart.
