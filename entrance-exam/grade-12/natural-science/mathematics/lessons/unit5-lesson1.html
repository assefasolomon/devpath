Unit 5 · Statistics and Probability

📊 Statistical Data Analysis

Master measures of central tendency and dispersion — the statistical tools most frequently tested on the Ethiopian entrance exam. Learn to compute mean, median, mode, variance and standard deviation from raw data and frequency tables.

📖 Reading: ~20 min
✏️ Examples: 5 worked
🎯 Quiz: 5 questions

Introduction
What you will learn in this lesson

Statistics is the science of collecting, organising, analysing and interpreting data. In everyday life — from government surveys to hospital records to sports scores — raw numbers need to be summarised before they can be understood. The tools you learn in this lesson do exactly that.

By the end of this lesson you will be able to:

  • Define and compute the mean (arithmetic average) from raw data and grouped data
  • Find the median (middle value) for both odd and even datasets
  • Identify the mode (most frequent value) including bimodal cases
  • Compute the range as a simple measure of spread
  • Calculate variance and standard deviation step by step
  • Interpret what a high or low standard deviation tells you about a dataset
  • Work with data presented in a frequency table

Explanation
Complete theory with visual aids

2.1 Key Terms and Data Types

Population
The complete set of all items being studied (e.g. all Grade 12 students in Ethiopia).
Sample
A subset of the population selected for study (e.g. 200 students from one region).
Variable
Any characteristic that can take different values — e.g. age, score, height.
Frequency
How many times a value appears in the dataset.

2.2 Measures of Central Tendency

These three measures each describe the "centre" of a dataset in a different way. The exam tests all three.

📌 Mean (Arithmetic Average)

The mean is the sum of all values divided by the number of values:

x̄ = (x₁ + x₂ + … + xₙ) / n = Σxᵢ / n

For a frequency table, use: x̄ = Σ(fᵢ · xᵢ) / Σfᵢ
where fᵢ is the frequency of value xᵢ.

📌 Median

The median is the middle value when data is arranged in order.

• Odd n: Median = value at position (n+1)/2
• Even n: Median = average of values at positions n/2 and n/2 + 1

Always sort the data first before finding the median.

📌 Mode

The mode is the value that appears most frequently.

• A dataset can have one mode (unimodal), two modes (bimodal), or no mode if all values appear equally often.
• The mode is the only measure that works for non-numeric (categorical) data.

⚠ When to use which measure

Mean: best for symmetric data with no extreme outliers. Median: best when data has outliers (e.g. income data). Mode: best for categorical data or finding the most common value. The entrance exam may ask you to choose the appropriate measure — remember this distinction.

2.3 Measures of Dispersion (Spread)

Central tendency alone does not tell the full story. Two datasets can have the same mean but very different spreads. Measures of dispersion quantify how spread out the data is.

📌 Range

Range = Maximum value − Minimum value

Simple but affected by outliers. Only uses two data points.

📌 Variance (σ²)

Variance measures the average squared distance from the mean:

σ² = Σ(xᵢ − x̄)² / n

Steps: (1) Find the mean x̄. (2) Subtract x̄ from each value. (3) Square each difference. (4) Sum the squares. (5) Divide by n.

📌 Standard Deviation (σ)

Standard deviation is the square root of the variance:

σ = √(Σ(xᵢ − x̄)² / n)

It is in the same units as the original data, making it easier to interpret than variance. A small σ means data is clustered near the mean. A large σ means data is spread out.

Visualising Standard Deviation
Small σ (data clustered)
Values are close to the mean. Low variability.
Large σ (data spread out)
Values are far from the mean. High variability.

Worked Examples
5 exam-style problems solved step by step
Example 1Mean, Median and Mode from Raw Data
Problem: Find the mean, median and mode of: 5, 3, 8, 3, 7, 9, 3, 6, 8, 4
Mean
Sum = 5+3+8+3+7+9+3+6+8+4 = 56. n = 10.
x̄ = 56/10 = 5.6
Median
Sort: 3, 3, 3, 4, 5, 6, 7, 8, 8, 9. n = 10 (even).
Middle positions: 5th = 5, 6th = 6.
Median = (5+6)/2 = 5.5
Mode
3 appears 3 times (most frequent).
Mode = 3
✅ Mean = 5.6  |  Median = 5.5  |  Mode = 3
Example 2Range and Variance
Problem: Find the range and variance of: 4, 8, 6, 5, 3, 2, 8, 9, 2, 3
Range
Range = 9 − 2 = 7
Mean
Sum = 4+8+6+5+3+2+8+9+2+3 = 50. n = 10.
x̄ = 50/10 = 5
Variance
Deviations from mean (xᵢ − 5): −1, 3, 1, 0, −2, −3, 3, 4, −3, −2
Squared deviations: 1, 9, 1, 0, 4, 9, 9, 16, 9, 4
Sum of squares = 62
σ² = 62/10 = 6.2
✅ Range = 7  |  Variance = 6.2  |  Std Dev = √6.2 ≈ 2.49
Example 3Mean from a Frequency Table
Problem: Find the mean from this frequency table:
Score: 1, 2, 3, 4, 5  |  Frequency: 2, 4, 6, 5, 3
Step 1
Compute f·x for each row:
1×2=2,   2×4=8,   3×6=18,   4×5=20,   5×3=15
Step 2
Σ(f·x) = 2+8+18+20+15 = 63
Σf = 2+4+6+5+3 = 20
Step 3
x̄ = 63/20 = 3.15
✅ Mean = 3.15
Example 4Standard Deviation Step by Step
Problem: Find the standard deviation of: 2, 4, 4, 4, 5, 5, 7, 9
Step 1
Mean: Sum = 40, n = 8. x̄ = 40/8 = 5
Step 2
Deviations (xᵢ − 5): −3, −1, −1, −1, 0, 0, 2, 4
Step 3
Squared deviations: 9, 1, 1, 1, 0, 0, 4, 16
Sum = 32
Step 4
σ² = 32/8 = 4
σ = √4 = 2
✅ Standard Deviation = 2
Example 5Choosing the Right Measure
Problem: Monthly salaries (in ETB): 2000, 2200, 2100, 2300, 18000. Which measure of central tendency best represents this data?
Mean
Sum = 26600, n = 5. x̄ = 26600/5 = 5320 ETB
This is misleading — most workers earn around 2000–2300, not 5320.
Median
Sorted: 2000, 2100, 2200, 2300, 18000. Middle value = 2200 ETB
This represents the typical salary much better.
Conclusion
The 18000 outlier pulls the mean far above the typical value. The median is the better measure here.
✅ Median (2200 ETB) best represents this data. The mean is distorted by the outlier.

Lesson Summary
Everything you learned in Lesson 1
✅ Key Points — Statistical Data Analysis
  • The mean (x̄ = Σx/n) is the arithmetic average. For a frequency table use x̄ = Σ(fx)/Σf.
  • The median is the middle value after sorting. For odd n it is position (n+1)/2; for even n it is the average of the two middle values.
  • The mode is the most frequently occurring value. A dataset can be unimodal, bimodal, or have no mode.
  • The range = max − min. It is quick but sensitive to outliers.
  • The variance σ² = Σ(xᵢ − x̄)²/n measures average squared spread from the mean.
  • The standard deviation σ = √σ² is in the same units as the data. Small σ = data clustered near mean; large σ = data spread out.
  • Use the median instead of the mean when outliers are present — the median is not pulled by extreme values.
  • For frequency tables, multiply each value by its frequency before summing, then divide by the total frequency.
