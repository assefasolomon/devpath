Introduction
From sequences to sums

In the previous lessons you learned how to find individual terms of a sequence. Now we go further — what if you need to find the sum of all terms? For example, a company pays its workers increasing daily wages: 100 ETB on day 1, 110 ETB on day 2, 120 ETB on day 3, and so on. What is the total pay after 30 days?

Adding all terms one by one would take a long time. Fortunately, there is a beautiful formula — discovered by the mathematician Gauss as a child — that lets you find the sum instantly.

By the end of this lesson you will be able to:

  • Define an arithmetic series and use sigma notation
  • Derive and use the sum formula: Sₙ = n/2 · (a₁ + aₙ)
  • Use the alternative form: Sₙ = n/2 · (2a₁ + (n−1)d)
  • Find the number of terms, first term, or common difference from a given sum
  • Solve real-world problems involving the sum of arithmetic sequences
  • Apply sigma notation to express series compactly

Explanation
Complete theory with visual aids
📌 Definition — Arithmetic Series

An arithmetic series is the sum of the terms of an arithmetic sequence. If the sequence is a₁, a₂, a₃, ..., aₙ then the series is:

Sₙ = a₁ + a₂ + a₃ + ... + aₙ

Sₙ denotes the sum of the first n terms.

2.1 The Story of Gauss — Deriving the Formula

At age 10, Carl Friedrich Gauss was asked by his teacher to add the numbers 1 to 100. While classmates added one by one, Gauss finished in seconds by noticing a pattern:

💡 Gauss's Pairing Trick
Forward:   1 + 2 + 3 + ... + 98 + 99 + 100
Backward: 100 + 99 + 98 + ... + 3 + 2 + 1
Each pair sums to 101: (1+100), (2+99), (3+98), ...
There are 100 pairs, so 2·S = 100 × 101 = 10,100
Therefore S = 10,100 / 2 = 5,050

This same idea gives us the general formula for any arithmetic series.

2.2 Deriving the Sum Formula

Write the series forwards and backwards then add:

Sₙ = a₁  +  (a₁+d)  +  (a₁+2d)  +  ...  +  aₙ
Sₙ = aₙ  +  (aₙ−d)  +  (aₙ−2d)  +  ...  +  a₁
2Sₙ = n(a₁ + aₙ)   ⟹   Sₙ = n/2 · (a₁ + aₙ)

Since aₙ = a₁ + (n−1)d, substituting gives the second form:

Sₙ = n/2 · [2a₁ + (n−1)d]

2.3 Two Forms of the Sum Formula

Form 1 — Use when aₙ is known
Sₙ = n/2 · (a₁ + aₙ)
n = number of terms
a₁ = first term, aₙ = last term
Form 2 — Use when d is known
Sₙ = n/2 · [2a₁ + (n−1)d]
n = terms, a₁ = first, d = difference
⚠ Which Form to Use?

If the problem gives you the last term (aₙ) use Form 1. If the problem gives you the common difference (d) but not the last term, use Form 2. Both give the same answer when used correctly.

2.4 Sigma Notation

Sigma notation (∑) is a compact way to write a series. The Greek letter Σ means "sum of":

∑(k=1 to n) aₖ = a₁ + a₂ + a₃ + ... + aₙ

Example: ∑(k=1 to 5) (2k+1) = 3 + 5 + 7 + 9 + 11 = 35
The variable k starts at 1, goes up to 5, and we substitute each value into 2k+1.

2.5 Working Backwards — Finding Unknown Values

Sometimes the exam gives you the sum and asks you to find n, a₁, or d. Use algebra:

Strategy — Finding n when Sₙ is given

Substitute the known values into Sₙ = n/2 · [2a₁ + (n−1)d] and solve the resulting quadratic equation in n.

Example: If S₁₀ = 145 and a₁ = 5, find d.
145 = 10/2 · [2(5) + (10−1)d]
145 = 5 · [10 + 9d]
29 = 10 + 9d  ⟹  9d = 19  ⟹  d = 19/9

2.6 Sum of the First n Natural Numbers

A special and frequently tested case: the sum of 1 + 2 + 3 + ... + n:

1 + 2 + 3 + ... + n = n(n+1)/2

This follows directly from the sum formula with a₁ = 1, d = 1:
Sₙ = n/2 · (2·1 + (n−1)·1) = n/2 · (n+1) = n(n+1)/2

Worked Examples
5 exam-style problems solved step by step
Example 1 Basic Sum Using Form 1
Problem: Find the sum of the arithmetic series: 3 + 7 + 11 + 15 + ... + 47
Step 1
Identify: a₁ = 3, d = 4, aₙ = 47
Step 2
Find n using aₙ = a₁ + (n−1)d:
47 = 3 + (n−1)(4)  ⟹  44 = 4(n−1)  ⟹  n−1 = 11  ⟹  n = 12
Step 3
Apply Form 1:
S₁₂ = 12/2 · (3 + 47) = 6 · 50 = 300
✅ The sum is 300
Example 2 Sum Using Form 2
Problem: Find the sum of the first 20 terms of the arithmetic sequence with a₁ = 5 and d = 3.
Given
a₁ = 5, d = 3, n = 20
Apply
Use Form 2 since d is given and last term is not:
S₂₀ = 20/2 · [2(5) + (20−1)(3)]
= 10 · [10 + 57]
= 10 · 67 = 670
✅ S₂₀ = 670
Example 3 Finding d from the Sum
Problem: The sum of the first 10 terms of an arithmetic sequence is 200, and the first term is 5. Find the common difference.
Given
S₁₀ = 200, a₁ = 5, n = 10
Substitute
Use Form 2:
200 = 10/2 · [2(5) + (10−1)d]
200 = 5 · [10 + 9d]
40 = 10 + 9d  ⟹  9d = 30  ⟹  d = 10/3
✅ The common difference is d = 10/3
Example 4 Sigma Notation
Problem: Evaluate ∑(k=1 to 8) (3k + 1)
Step 1
Write out first and last terms:
k=1: 3(1)+1 = 4    k=8: 3(8)+1 = 25
So a₁ = 4, a₈ = 25, n = 8
Step 2
Apply Form 1:
S₈ = 8/2 · (4 + 25) = 4 · 29 = 116
✅ ∑(k=1 to 8) (3k+1) = 116
Example 5 Real-World Word Problem
Problem: A worker earns 1,200 ETB in the first month and receives a 100 ETB raise each month. What are the total earnings over 12 months?
Identify
a₁ = 1,200, d = 100, n = 12
Apply
S₁₂ = 12/2 · [2(1,200) + (12−1)(100)]
= 6 · [2,400 + 1,100]
= 6 · 3,500 = 21,000 ETB
✅ Total earnings over 12 months = 21,000 ETB

Lesson Summary
Everything you learned in Lesson 4
✅ Key Points — Arithmetic Series
  • An arithmetic series is the sum of terms of an arithmetic sequence: Sₙ = a₁ + a₂ + ... + aₙ
  • Form 1: Sₙ = n/2 · (a₁ + aₙ) — use when both first and last terms are known.
  • Form 2: Sₙ = n/2 · [2a₁ + (n−1)d] — use when d is known but last term is not.
  • The sum of natural numbers 1 to n is n(n+1)/2 — memorize this formula.
  • Sigma notation ∑ means "sum of" — substitute each value of k into the formula.
  • To find n from Sₙ: substitute known values and solve the resulting quadratic in n.
  • The average of an AP = Sₙ/n = (a₁ + aₙ)/2 = middle term.
  • For real-world problems: identify a₁ (starting value), d (fixed increase), and n (number of periods).
