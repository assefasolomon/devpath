Unit 6 · Three Dimensional Geometry and Vectors in Space

📦 Coordinate Axes and Coordinate Planes in Space

Extend the familiar 2D coordinate system into three dimensions. Learn to name the three coordinate axes, identify the three coordinate planes, understand the eight octants, and describe the geometry of three-dimensional space.

📖 Reading: ~18 min
✏️ Examples: 5 worked
🎯 Quiz: 5 questions
🎥 Videos: 4 resources
🎯
Introduction
What you will learn in this lesson

You have spent years working in two dimensions — a flat plane with an x-axis and a y-axis. But the real world has three dimensions: length, width and height. To describe the position of a point in space — such as an aircraft's location, a molecule's position, or a corner of a building — we need a third axis.

By the end of this lesson you will be able to:

  • Name and describe the three coordinate axes: x-axis, y-axis and z-axis
  • Identify the three coordinate planes: xy-plane, yz-plane and xz-plane
  • Understand how the three planes divide space into eight octants
  • Describe the relationship between the 2D and 3D coordinate systems
  • Identify points that lie on axes or coordinate planes from their coordinates
  • Apply the right-hand rule to orient the 3D system correctly
📖
Explanation
Complete theory with visual aids

2.1 From Two Dimensions to Three Dimensions

In 2D, every point on a plane is located by an ordered pair (x, y). In 3D, every point in space is located by an ordered triple (x, y, z). The third coordinate z measures how far the point is above or below the xy-plane.

2D Coordinate System
  • 2 axes: x-axis, y-axis
  • 1 plane: the xy-plane
  • 4 quadrants
  • Points: ordered pairs (x, y)
  • Origin: (0, 0)
3D Coordinate System
  • 3 axes: x-axis, y-axis, z-axis
  • 3 planes: xy, yz, xz
  • 8 octants
  • Points: ordered triples (x, y, z)
  • Origin: (0, 0, 0)

2.2 The Three Coordinate Axes

📌 The Three Axes

Three mutually perpendicular lines all pass through the origin O = (0, 0, 0):

• x-axis: points along this axis have the form (x, 0, 0) — runs left–right
• y-axis: points along this axis have the form (0, y, 0) — runs forward–backward
• z-axis: points along this axis have the form (0, 0, z) — runs up–down

Each pair of axes is perpendicular. All three meet only at the origin.

The three coordinate axes — x (green), y (blue), z (red) — meeting at the origin O.

📝 The Right-Hand Rule

To orient the axes correctly, use your right hand: point your fingers along the positive x-axis, curl them toward the positive y-axis, and your thumb points in the direction of the positive z-axis. This is the standard orientation used in mathematics and the entrance exam.

2.3 The Three Coordinate Planes

Each pair of axes determines a coordinate plane — a flat surface that contains both axes. The three planes divide all of space.

xy-plane
z = 0
Contains the x-axis and y-axis. Every point on this plane has z-coordinate = 0. This is the familiar 2D plane from earlier grades.
yz-plane
x = 0
Contains the y-axis and z-axis. Every point on this plane has x-coordinate = 0. It is perpendicular to the x-axis.
xz-plane
y = 0
Contains the x-axis and z-axis. Every point on this plane has y-coordinate = 0. It is perpendicular to the y-axis.
📌 Key Identification Rules

A point lies on the x-axis if y = 0 AND z = 0 → form (x, 0, 0)
A point lies on the y-axis if x = 0 AND z = 0 → form (0, y, 0)
A point lies on the z-axis if x = 0 AND y = 0 → form (0, 0, z)

A point lies on the xy-plane if z = 0 → form (x, y, 0)
A point lies on the yz-plane if x = 0 → form (0, y, z)
A point lies on the xz-plane if y = 0 → form (x, 0, z)

2.4 The Eight Octants

Just as the two axes in 2D divide the plane into four quadrants, the three coordinate planes in 3D divide space into eight octants. Each octant is determined by whether x, y and z are positive or negative.

Only the first octant (x > 0, y > 0, z > 0) has a standard name. The others are referred to by their sign pattern:

OctantxyzDescription
First (I)+++The standard first octant — all positive
Second−++x negative
Third−−+x and y negative
Fourth+−+y negative
Fifth++−z negative
Sixth−+−x and z negative
Seventh−−−All negative
Eighth+−−y and z negative
📝 Exam focus

The entrance exam most often asks you to identify which octant a point belongs to, or which coordinate plane a point lies on. Master the sign pattern table and the identification rules in Section 2.3.

Worked Examples
5 exam-style problems solved step by step
Example 1Identifying Points on Axes
Problem: State which axis (if any) each point lies on: (a) (3, 0, 0)   (b) (0, −5, 0)   (c) (0, 0, 7)   (d) (2, 0, 4)
(a)
(3, 0, 0): y = 0 and z = 0 → lies on the x-axis.
(b)
(0, −5, 0): x = 0 and z = 0 → lies on the y-axis.
(c)
(0, 0, 7): x = 0 and y = 0 → lies on the z-axis.
(d)
(2, 0, 4): x ≠ 0 and z ≠ 0 but y = 0 → lies on the xz-plane, not on any axis.
✅ (a) x-axis  |  (b) y-axis  |  (c) z-axis  |  (d) xz-plane (not an axis)
Example 2Identifying the Coordinate Plane
Problem: Which coordinate plane does each point lie on? (a) (4, 0, −2)   (b) (0, 3, 5)   (c) (−1, 6, 0)
(a)
(4, 0, −2): y = 0 → lies on the xz-plane.
(b)
(0, 3, 5): x = 0 → lies on the yz-plane.
(c)
(−1, 6, 0): z = 0 → lies on the xy-plane.
✅ (a) xz-plane  |  (b) yz-plane  |  (c) xy-plane
Example 3Identifying the Octant
Problem: In which octant does each point lie? (a) (3, 2, 5)   (b) (−1, 4, 2)   (c) (2, −3, −1)   (d) (−4, −2, −6)
(a)
(3, 2, 5): x > 0, y > 0, z > 0 → First octant (+, +, +).
(b)
(−1, 4, 2): x < 0, y > 0, z > 0 → Second octant (−, +, +).
(c)
(2, −3, −1): x > 0, y < 0, z < 0 → Eighth octant (+, −, −).
(d)
(−4, −2, −6): x < 0, y < 0, z < 0 → Seventh octant (−, −, −).
✅ (a) First  |  (b) Second  |  (c) Eighth  |  (d) Seventh
Example 4Points on More Than One Plane
Problem: The point P = (0, 0, 5) lies on which axes and planes?
Axes
x = 0 AND y = 0 → P lies on the z-axis.
Planes
x = 0 → P lies on the yz-plane.
y = 0 → P lies on the xz-plane.
(z ≠ 0, so P does NOT lie on the xy-plane.)
Verify
The z-axis is the intersection of the yz-plane and the xz-plane, which is consistent.
✅ P lies on: the z-axis, the yz-plane and the xz-plane.
Example 5Describing a Set of Points
Problem: Describe the set of all points P = (x, y, z) satisfying: (a) x = 0   (b) z = 0 and y = 0   (c) x = 3
(a)
x = 0 means all points of the form (0, y, z) — this is the entire yz-plane.
(b)
z = 0 AND y = 0 means all points of the form (x, 0, 0) — this is the x-axis.
(c)
x = 3 describes all points (3, y, z) for any y and z — a plane parallel to the yz-plane, shifted 3 units in the positive x-direction.
✅ (a) yz-plane  |  (b) x-axis  |  (c) Plane parallel to yz-plane at x = 3

Lesson Summary
Everything you learned in Lesson 1
✅ Key Points — Coordinate Axes and Planes in Space
  • The 3D coordinate system has three mutually perpendicular axes: x-axis, y-axis and z-axis, all meeting at the origin O = (0, 0, 0).
  • Every point in space is described by an ordered triple (x, y, z).
  • The xy-plane (z = 0), yz-plane (x = 0) and xz-plane (y = 0) are the three coordinate planes.
  • A point lies on the x-axis if y = 0 and z = 0; on the y-axis if x = 0 and z = 0; on the z-axis if x = 0 and y = 0.
  • The three coordinate planes divide space into eight octants, determined by the signs of x, y and z.
  • The first octant is where x > 0, y > 0 and z > 0 — all coordinates positive.
  • The right-hand rule gives the standard orientation: fingers from x toward y, thumb points in +z direction.
  • A plane x = k (constant) is parallel to the yz-plane. Similarly y = k is parallel to xz, and z = k is parallel to xy.
