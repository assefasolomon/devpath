Unit 6 · Linear Programming

📐 Linear Inequalities in Two Variables

Before you can solve linear programming problems, you must master graphing linear inequalities and identifying feasible regions. This lesson builds the essential graphing skill that the entire next lesson depends on.

📖 Reading: ~18 min
✏️ Examples: 5 worked
🎯 Quiz: 5 questions
🎥 Videos: 4 resources
🎯
Introduction
What you will learn in this lesson

A linear inequality in two variables is like a linear equation (y = mx + b), except instead of an equals sign it uses <, >, ≤, or ≥. While an equation describes a single line, an inequality describes an entire half-plane — all the points on one side of that line.

By the end of this lesson you will be able to:

  • Graph a linear inequality as a boundary line (solid or dashed)
  • Determine which half-plane to shade using a test point
  • Graph a system of linear inequalities and identify the feasible region
  • Find the corner points (vertices) of a feasible region
  • Determine whether a feasible region is bounded or unbounded
  • Check whether a given point satisfies a system of inequalities
📖
Explanation
Complete theory with visual aids

2.1 Graphing a Single Linear Inequality

Follow these three steps every time:

Step 1 — Boundary Line
Replace the inequality sign with = and graph the line.

Solid line (—) for ≤ or ≥ (boundary included)
Dashed line (- -) for < or > (boundary excluded)
Step 2 — Test Point
Pick any point NOT on the line. The origin (0, 0) is the easiest choice when the line does not pass through it.

Substitute into the inequality.
Step 3 — Shade
If the test point satisfies the inequality → shade the side containing that point.

If it does not satisfy → shade the opposite side.

Solid line (≤). Test point (0,0): 2(0)+0=0 ≤ 4 ✓ — shade toward origin.

2.2 System of Linear Inequalities — Feasible Region

When you graph two or more inequalities on the same axes, the feasible region is the area where ALL inequalities are satisfied simultaneously — the overlap of all the shaded half-planes.

📌 Feasible Region

The feasible region is the set of all points (x, y) that satisfy every inequality in the system at the same time.

• Bounded: the region is enclosed (finite area — a polygon). This happens when constraints limit both x and y.
• Unbounded: the region extends to infinity in at least one direction.

The feasible region (green) is bounded by the two constraint lines and the axes. Corner points are where boundary lines intersect.

2.3 Finding Corner Points (Vertices)

Corner points are the vertices of the feasible region — where boundary lines intersect each other or the axes. They are critical because in the next lesson, the optimal value of the objective function always occurs at a corner point.

Origin corner
If x ≥ 0 and y ≥ 0 are constraints, (0, 0) is always a corner point.
Axis intercepts
Set x = 0 or y = 0 in each constraint equation to find where lines cross the axes.
Line intersections
Solve pairs of boundary equations simultaneously (substitution or elimination) to find interior vertices.
⚠ Always verify corner points

After finding a corner point algebraically, substitute it back into all the original inequalities to confirm it lies in the feasible region. If it fails even one inequality, it is not a valid corner point.

2.4 Non-negativity Constraints

Real-world problems almost always include x ≥ 0 and y ≥ 0 — you cannot produce a negative quantity of a product or spend negative hours on a task. These constraints restrict the feasible region to the first quadrant only.

📝 Standard Setup

Most entrance exam linear programming problems include x ≥ 0 and y ≥ 0 automatically. Always include them when drawing your feasible region, even if not explicitly stated.

Worked Examples
5 exam-style problems solved step by step
Example 1Graphing a Single Inequality
Problem: Graph the inequality 3x + 2y ≤ 12.
Step 1
Draw boundary line 3x + 2y = 12.
x-intercept: set y=0 → x=4. Point (4, 0).
y-intercept: set x=0 → y=6. Point (0, 6).
Draw a solid line (≤ includes boundary).
Step 2
Test (0, 0): 3(0)+2(0)=0 ≤ 12 ✓ — satisfied.
Step 3
Shade the half-plane containing (0, 0) — the region below and to the left of the line.
✅ Solid line through (4,0) and (0,6). Shade the side containing the origin.
Example 2Dashed Boundary Line (Strict Inequality)
Problem: Graph y > 2x − 3.
Step 1
Boundary: y = 2x − 3. Slope = 2, y-intercept = −3.
Draw a dashed line (strict > — boundary not included).
Step 2
Test (0, 0): 0 > 2(0)−3 = −3 ✓ — satisfied.
Step 3
Shade above the dashed line (the side containing the origin).
✅ Dashed line y = 2x − 3. Shade the region above the line.
Example 3Checking Whether a Point is in the Feasible Region
Problem: Is the point (2, 3) in the feasible region of the system: x + y ≤ 6, 2x − y ≥ 0, x ≥ 0, y ≥ 0?
Check 1
x+y ≤ 6: 2+3=5 ≤ 6 ✓
Check 2
2x−y ≥ 0: 2(2)−3=1 ≥ 0 ✓
Check 3
x ≥ 0: 2 ≥ 0 ✓   y ≥ 0: 3 ≥ 0 ✓
✅ (2, 3) satisfies all four constraints — it IS in the feasible region.
Example 4Finding Corner Points of a Feasible Region
Problem: Find all corner points of the feasible region defined by:
x + y ≤ 5,   x + 2y ≤ 8,   x ≥ 0,   y ≥ 0
Origin
x ≥ 0 and y ≥ 0 give corner (0, 0).
x-axis
Set y = 0 in x+y=5: x=5. Corner (5, 0).
y-axis
Set x = 0 in x+2y=8: y=4. Corner (0, 4).
Intersection
Solve x+y=5 and x+2y=8 simultaneously.
Subtract: y=3. Then x=5−3=2.
Corner (2, 3).
✅ Corner points: (0,0), (5,0), (2,3), (0,4)
Example 5Identifying Bounded vs Unbounded Region
Problem: Describe the feasible region of: x + y ≥ 2, x ≥ 0, y ≥ 0.
Step 1
Boundary: x+y=2. x-intercept (2,0), y-intercept (0,2).
Since ≥, shade above the line (away from origin — test (0,0): 0≥2 is false, so shade the other side).
Step 2
Combined with x≥0 and y≥0, the region is all points in the first quadrant above the line x+y=2.
Verdict
The region extends infinitely upward and to the right — it is unbounded. Corner points are (2,0) and (0,2) only.
✅ Unbounded region. Corner points: (2, 0) and (0, 2).

Lesson Summary
Everything you learned in Lesson 1
✅ Key Points — Linear Inequalities in Two Variables
  • A linear inequality in two variables describes a half-plane — all points on one side of a boundary line.
  • Use a solid line for ≤ or ≥ (boundary included). Use a dashed line for < or > (boundary excluded).
  • Test the origin (0,0) — if it satisfies the inequality, shade toward it. If not, shade the opposite side.
  • The feasible region of a system is the overlap where ALL inequalities are satisfied simultaneously.
  • A bounded feasible region is enclosed (finite polygon). An unbounded region extends to infinity.
  • Corner points are found by: (i) the origin, (ii) axis intercepts of boundary lines, (iii) solving pairs of boundary equations simultaneously.
  • Always verify corner points by substituting back into every original inequality.
  • Non-negativity constraints (x ≥ 0, y ≥ 0) restrict the feasible region to the first quadrant.
