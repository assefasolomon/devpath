〰️ Continuity of Functions

Understand what it means for a function to be continuous — no holes, no jumps, no breaks. Learn the three conditions for continuity, the three types of discontinuity with visual diagrams, and the powerful Intermediate Value Theorem.

Introduction
What does continuity mean?

Imagine drawing a curve on paper without lifting your pen. If you can do it, the function is continuous. If you have to lift your pen — because of a hole, a jump, or a vertical asymptote — the function is discontinuous at that point.

Continuity is one of the most important concepts in calculus. Without it, derivatives and integrals cannot be properly defined. The Ethiopian entrance exam tests continuity in several ways — checking the three conditions, identifying types of discontinuity, and applying the Intermediate Value Theorem.

By the end of this lesson you will be able to:

  • State the three conditions for continuity at a point
  • Test whether a function is continuous at a given point
  • Identify removable, jump, and infinite discontinuities
  • Determine intervals of continuity for common functions
  • Apply the Intermediate Value Theorem (IVT) to show existence of roots
  • Find values of constants that make a piecewise function continuous

Explanation
Theory with visual diagrams of all discontinuity types

2.1 Three Conditions for Continuity at a Point

A function f is continuous at x = a if and only if all three conditions hold:

1
Defined
f(a) exists
The function must have a value at x = a. No division by zero, no undefined expressions.
2
Limit Exists
lim(x→a) f(x) exists
The two-sided limit must exist at x = a. Left and right limits must be equal.
3
Equal
lim(x→a)f(x) = f(a)
The limit must equal the function value. The function must approach what it actually equals.
📌 Definition — Continuity at a Point

f is continuous at x = a if:

(1) f(a) is defined   (2) lim(x→a) f(x) exists   (3) lim(x→a) f(x) = f(a)

If any one of these three conditions fails, f is discontinuous at x = a.

2.2 Three Types of Discontinuity

Type 1 — Removable Discontinuity (Hole)
Removable: The limit exists but f(a) either does not exist or ≠ limit. A "hole" in the graph. Can be "fixed" by redefining f(a) = L.
Type 2 — Jump Discontinuity
Jump: Left and right limits exist but are different (L⁻ ≠ L⁺). The function "jumps" from one value to another. Cannot be fixed by redefining one point.
Type 3 — Infinite Discontinuity (Vertical Asymptote)
Infinite: f(x) → ±∞ as x → a. Usually caused by division by zero. The function has a vertical asymptote at x = a.

2.3 Continuity on an Interval

A function is continuous on an interval if it is continuous at every point in that interval.

Always Continuous
  • Polynomial functions — all x
  • Rational functions — where denominator ≠ 0
  • sin(x) and cos(x) — all x
  • √x — for x > 0 (or x ≥ 0)
  • eˣ and ln(x) — their domains
May be Discontinuous
  • Rational functions — at zeros of denominator
  • tan(x) — at x = π/2 + nπ
  • Piecewise functions — at boundary points
  • √(expression) — where expression < 0

2.4 The Intermediate Value Theorem (IVT)

📌 Intermediate Value Theorem

If f is continuous on [a, b], and N is any number between f(a) and f(b), then there exists at least one number c in (a, b) such that f(c) = N.

For any value N between f(a) and f(b), the continuous curve must cross the horizontal line y = N at some point c between a and b.
⚠ IVT Exam Application

The IVT is often used to prove a root exists. If f is continuous on [a,b] and f(a) and f(b) have opposite signs (one positive, one negative), then f(c) = 0 for some c in (a,b). The function must cross zero somewhere.

2.5 Continuity Checklist — How to Test at x = a

  • 1
    Check if f(a) is defined. Substitute x = a. If you get a real number → ✓. If you get 0/0 or undefined → ✗ (discontinuous).
  • 2
    Check if lim(x→a) f(x) exists. Compute left and right limits. If L⁻ = L⁺ → ✓. If L⁻ ≠ L⁺ → ✗ (jump discontinuity).
  • 3
    Check if limit = f(a). Compare your answers from steps 1 and 2. If they match → ✓ continuous. If not → ✗ (removable discontinuity).

Worked Examples
5 exam-style problems solved step by step
Example 1 Testing Continuity — Three Conditions
Problem: Is f(x) = (x²−4)/(x−2) continuous at x = 2?
Condition 1
f(2) = (4−4)/(2−2) = 0/0 — undefined ✗
Condition 1 fails immediately.
Classify
Factor: (x−2)(x+2)/(x−2) → limit = x+2 = 4 as x→2
Limit exists = 4, but f(2) is undefined → Removable discontinuity
✅ f is NOT continuous at x = 2. Removable discontinuity (hole at (2, 4)).
Example 2 Piecewise — Testing All Three Conditions
Problem: f(x) = x² for x ≠ 3 and f(3) = 7. Is f continuous at x = 3?
Condition 1
f(3) = 7 ✓ — defined
Condition 2
lim(x→3) x² = 9 ✓ — limit exists
Condition 3
lim = 9 ≠ f(3) = 7 ✗ — not equal
✅ f is NOT continuous at x = 3. Removable discontinuity — the point (3,7) is off the curve.
Example 3 Finding k for Continuity
Problem: f(x) = kx + 2 for x ≤ 1 and f(x) = 3x² for x > 1. Find k so f is continuous at x = 1.
Left limit
lim(x→1⁻) (kx+2) = k+2
Right limit
lim(x→1⁺) 3x² = 3
f(1)
f(1) = k(1)+2 = k+2
Set equal
For continuity, all three must be equal:
k+2 = 3  ⟹  k = 1
✅ k = 1 makes f continuous at x = 1
Example 4 Identifying Type of Discontinuity
Problem: Classify the discontinuity of f(x) = 1/(x−3) at x = 3.
Condition 1
f(3) = 1/0 — undefined ✗
Left limit
As x→3⁻: (x−3) → 0⁻, so 1/(x−3) → −∞
Right limit
As x→3⁺: (x−3) → 0⁺, so 1/(x−3) → +∞
✅ Infinite discontinuity (vertical asymptote) at x = 3. The function goes to ±∞ on each side.
Example 5 Applying the IVT
Problem: Show that f(x) = x³ − x − 1 has a root in the interval [1, 2].
Step 1
f is a polynomial → continuous everywhere ✓
Step 2
Evaluate at endpoints:
f(1) = 1−1−1 = −1 < 0
f(2) = 8−2−1 = 5 > 0
Step 3
f(1) < 0 < f(2) — opposite signs with 0 between them.
Apply IVT
By IVT, since f is continuous on [1,2] and f(1) < 0 < f(2), there must exist c ∈ (1,2) such that f(c) = 0.
✅ By the IVT, f(x) = x³−x−1 has at least one root in (1, 2).

Lesson Summary
Everything you learned in Unit 2 Lesson 4
✅ Key Points — Continuity of Functions
  • f is continuous at x = a if: (1) f(a) exists, (2) lim(x→a) f(x) exists, (3) they are equal.
  • Removable discontinuity: limit exists but f(a) is undefined or ≠ limit. A hole in the graph.
  • Jump discontinuity: left and right limits exist but are not equal. A jump in the graph.
  • Infinite discontinuity: f(x) → ±∞ as x → a. A vertical asymptote.
  • Polynomials are continuous everywhere. Rational functions are continuous where denominator ≠ 0.
  • For piecewise functions: check that left limit = right limit = f(a) at every boundary point.
  • To find k for continuity: set left limit = right limit and solve — all three must be equal.
  • IVT: if f is continuous on [a,b] and f(a), f(b) have opposite signs, f has a root in (a,b).
