f'' Higher Order Derivatives

Learn to find the second, third and higher derivatives of a function. Understand their geometric meaning — concavity and inflection points — and their physical interpretation as acceleration. A key topic on the Ethiopian entrance exam.

📖 Reading: ~20 min
✏️ Examples: 5 worked

Introduction
What happens when you differentiate again?

You have learned that differentiating a function f gives the derivative f' — which tells you the rate of change of f. But what if you differentiate f' again? The result is the second derivative f'', which tells you the rate of change of the rate of change.

In physics, if f is position, then f' is velocity and f'' is acceleration. In geometry, f'' tells us whether a curve is bending upward (concave up) or downward (concave down). These are powerful ideas that appear frequently on the entrance exam.

By the end of this lesson you will be able to:

  • Find the second derivative f''(x) by differentiating f'(x)
  • Find third and higher order derivatives
  • Use all standard notations: f'', d²y/dx², y''
  • Interpret f'' as acceleration in motion problems
  • Use f'' to determine concavity: concave up (f'' > 0) or down (f'' < 0)
  • Find inflection points where concavity changes

2.1 The Chain of Derivatives

Each derivative is obtained by differentiating the previous one. You can keep going as long as the result is differentiable:

function
d/dx →
f'(x)
1st derivative
d/dx →
f''(x)
2nd derivative
d/dx →
f'''(x)
3rd derivative
d/dx →
f⁽ⁿ⁾(x)
nth derivative
📌 Definition — Second Derivative

The second derivative of f is the derivative of the first derivative:

f''(x) = d/dx[f'(x)]

It measures how fast the slope (first derivative) is changing.

2.2 Notation for Higher Order Derivatives

Order Lagrange Notation Leibniz Notation Read as
1st f'(x) or y' dy/dx "f prime of x"
2nd f''(x) or y'' d²y/dx² "f double prime of x"
3rd f'''(x) or y''' d³y/dx³ "f triple prime of x"
nth f⁽ⁿ⁾(x) or y⁽ⁿ⁾ dⁿy/dxⁿ "f n-th derivative"
⚠ Exam Tip

The entrance exam uses both notations. When a question says "find y''", it means find d²y/dx² — the second derivative. When it says "find the second derivative of f", use f''(x). They mean the same thing.

2.3 Second Derivative and Concavity

The sign of f'' tells us about the shape (concavity) of the curve:

f''(x) > 0 → Concave Up ∪
The slope is increasing. The curve bends upward like a bowl. If f'(a)=0 and f''(a) > 0 → local minimum.
f''(x) < 0 → Concave Down ∩
The slope is decreasing. The curve bends downward like a hill. If f'(a)=0 and f''(a) < 0 → local maximum.

2.4 Inflection Points

📌 Definition — Inflection Point

An inflection point is a point where the concavity of the curve changes — from concave up to concave down, or vice versa.

To find inflection points: solve f''(x) = 0, then verify the concavity actually changes on either side.

At the inflection point, f'' changes sign. The curve transitions from concave up to concave down (or vice versa).

2.5 Physical Interpretation — Motion

f(t)
Position
Where the object is at time t
f'(t)
Velocity
How fast and in which direction

Acceleration
How fast the velocity is changing
⚠ Exam Application

When an object's position is s(t), its velocity is v(t) = s'(t) and its acceleration is a(t) = s''(t). The object is decelerating when velocity and acceleration have opposite signs.

If f'(a) = 0, you can use f''(a) to classify the critical point:

Worked Examples
5 exam-style problems
Example 1 Finding Second and Third Derivatives
Problem: Find f'(x), f''(x) and f'''(x) for f(x) = 2x⁴ − 5x³ + 3x − 7
f'(x)
= 8x³ − 15x² + 3
f''(x)
Differentiate f':
= 24x² − 30x
f'''(x)
Differentiate f'':
= 48x − 30
✅ f'= 8x³−15x²+3  |  f''= 24x²−30x  |  f'''= 48x−30
Example 2 Concavity — Where is f Concave Up or Down?
Problem: Determine concavity of f(x) = x⁴ − 4x³.
Find f''
f'(x) = 4x³−12x²  ⟹  f''(x) = 12x²−24x = 12x(x−2)
Solve f''=0
12x(x−2) = 0  ⟹  x = 0 or x = 2
Test intervals
x < 0: f''(−1) = 12(−1)(−3) = 36 > 0 → concave up
0 < x < 2: f''(1) = 12(1)(−1) = −12 < 0 → concave down
x > 2: f''(3) = 12(3)(1) = 36 > 0 → concave up
✅ Concave up on (−∞,0) and (2,∞). Concave down on (0,2). Inflection points at x = 0 and x = 2.
Example 3 Second Derivative Test for Extrema
Problem: Find and classify the critical points of f(x) = x³ − 3x² + 1.
Find f'
f'(x) = 3x²−6x = 3x(x−2)
Critical points: x = 0 and x = 2
Find f''
f''(x) = 6x−6
Apply test
f''(0) = −6 < 0 → Local maximum at x=0: f(0)=1
f''(2) = 6 > 0 → Local minimum at x=2: f(2)=−3
✅ Local maximum at (0, 1). Local minimum at (2, −3).
Example 4 Second Derivative of Trigonometric Function
Problem: Find f''(x) for f(x) = sin(x) + x cos(x).
Find f'
Use product rule on x cos(x):
f'(x) = cos(x) + [cos(x) − x sin(x)]
= 2cos(x) − x sin(x)
Find f''
Differentiate f' term by term:
f''(x) = −2sin(x) − [sin(x) + x cos(x)]
= −2sin(x) − sin(x) − x cos(x)
= −3sin(x) − x cos(x)
✅ f''(x) = −3sin(x) − x cos(x)
Example 5 Motion — Position, Velocity, Acceleration
Problem: A particle moves along a line with position s(t) = t³ − 6t² + 9t + 2 (in metres, t in seconds). Find the velocity and acceleration at t = 3.
Velocity
v(t) = s'(t) = 3t²−12t+9
v(3) = 3(9)−12(3)+9 = 27−36+9 = 0 m/s
Acceleration
a(t) = s''(t) = 6t−12
a(3) = 6(3)−12 = 18−12 = 6 m/s²
✅ At t=3: velocity = 0 m/s (momentarily at rest), acceleration = 6 m/s² (speeding up)

Lesson Summary
Everything you learned in Unit 3 Lesson 3
✅ Key Points — Higher Order Derivatives
  • The second derivative f''(x) = d/dx[f'(x)] — differentiate the first derivative once more.
  • Notation: f''(x), y'', d²y/dx² all mean the same thing — the second derivative.
  • f''(x) > 0 on an interval → curve is concave up (∪) — slope is increasing.
  • f''(x) < 0 on an interval → curve is concave down (∩) — slope is decreasing.
  • Inflection point: where f''(x) = 0 AND the sign of f'' changes on either side.
  • Second derivative test: if f'(a)=0 and f''(a)>0 → local min; f''(a)<0 → local max.
  • In motion: position s(t) → velocity v=s' → acceleration a=s''.
  • For polynomials: higher derivatives eventually become zero (after n derivatives of xⁿ).
