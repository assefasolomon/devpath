📈 Probability Distributions

Go beyond single events — learn how probability is distributed across all possible outcomes of a random variable. Master the binomial distribution and the normal distribution, the two most tested distributions on the Ethiopian entrance exam.

Introduction
What you will learn in this lesson

In Lesson 2 you found probabilities of individual events. Now you will study how probability is spread across all possible values of a random variable — this is a probability distribution. Instead of asking "what is P(X = 3)?", you build a complete picture of every possible outcome and its probability.

By the end of this lesson you will be able to:

  • Define a random variable and distinguish discrete from continuous types
  • Build and verify a probability distribution table
  • Compute the expected value (mean) of a random variable: E(X) = Σ x·P(x)
  • State the conditions for a binomial experiment (FIST)
  • Apply the binomial probability formula: P(X=k) = C(n,k) pᵏ (1−p)ⁿ⁻ᵏ
  • Find the mean and variance of a binomial distribution
  • Describe the key properties of the normal distribution and the 68-95-99.7 rule

Explanation
Complete theory with visual aids

2.1 Random Variables

📌 Random Variable

A random variable X is a variable whose value is determined by the outcome of a random experiment. It assigns a number to each outcome in the sample space.

• Discrete: takes countable values (0, 1, 2, 3 …). Example: number of heads in 3 coin flips.
• Continuous: takes any value in an interval. Example: height, weight, time.

Discrete Examples
  • Number of goals in a match
  • Number of defective items
  • Number of correct exam answers
  • Dice roll outcome
Continuous Examples
  • Height of a student
  • Time to complete an exam
  • Temperature in a city
  • Weight of a package

2.2 Probability Distribution Table

A probability distribution table lists every value of X and its probability. Two conditions must always hold:

Condition 1
0 ≤ P(x) ≤ 1
Each probability is between 0 and 1
Condition 2
Σ P(x) = 1
All probabilities sum to exactly 1

Example: Rolling a fair die once

X (outcome)123456Total
P(X)1/61/61/61/61/61/61
📌 Expected Value (Mean of a Distribution)

The expected value E(X) is the long-run average value of X:

E(X) = Σ x · P(x)

Multiply each value by its probability, then sum all products.

2.3 The Binomial Distribution

The binomial distribution models the number of successes in a fixed number of independent trials, where each trial has only two outcomes: success or failure.

FIST — The 4 Conditions for a Binomial Experiment
F
Fixed number of trials
n is fixed before the experiment begins
I
Independent trials
Each trial does not affect the others
S
Two outcomes only
Success (p) or Failure (1−p) per trial
T
Same probability p
p is constant across all trials
📌 Binomial Probability Formula

If X ~ B(n, p), then the probability of exactly k successes in n trials is:

P(X = k) = C(n,k) · pᵏ · (1−p)ⁿ⁻ᵏ

where C(n,k) = n! / (k!(n−k)!) is the number of ways to choose k successes from n trials.

Mean: μ = np    Variance: σ² = np(1−p)    Std Dev: σ = √(np(1−p))

2.4 The Normal Distribution

The normal distribution is the most important distribution in statistics. It describes many natural phenomena — heights, exam scores, measurement errors. Its graph is the famous bell curve.

📌 Properties of the Normal Distribution

• Symmetric and bell-shaped around the mean μ
• Mean = Median = Mode (all equal, at the centre)
• Described by two parameters: mean μ (location) and standard deviation σ (spread)
• Total area under the curve = 1
• Notation: X ~ N(μ, σ²)

The 68–95–99.7 rule (Empirical Rule)

📌 The Empirical Rule (68–95–99.7 Rule)

For any normal distribution X ~ N(μ, σ²):

• 68% of data falls within 1 standard deviation of the mean: (μ − σ, μ + σ)
• 95% of data falls within 2 standard deviations: (μ − 2σ, μ + 2σ)
• 99.7% of data falls within 3 standard deviations: (μ − 3σ, μ + 3σ)

📌 Standard Normal Distribution — z-scores

The standard normal distribution Z ~ N(0, 1) has mean 0 and standard deviation 1.

To convert any normal value x to a z-score:
z = (x − μ) / σ

The z-score tells you how many standard deviations x is from the mean. Use z-tables to find areas (probabilities) under the normal curve.

📝 Exam Focus for Normal Distribution

The Ethiopian entrance exam mainly tests the Empirical Rule and z-score interpretation at Grade 12 level — you are not expected to use z-tables extensively. Focus on understanding what the mean and standard deviation tell you about the spread of data, and applying the 68–95–99.7 rule.

Worked Examples
5 exam-style problems solved step by step
Example 1Verifying a Probability Distribution and Finding E(X)
Problem: X has the distribution below. Verify it is valid and find E(X).
X: 1, 2, 3, 4  |  P(X): 0.1, 0.3, 0.4, 0.2
Verify
Check all probabilities ≥ 0 ✓
Sum: 0.1 + 0.3 + 0.4 + 0.2 = 1.0 ✓ — valid distribution.
E(X)
E(X) = 1(0.1) + 2(0.3) + 3(0.4) + 4(0.2)
= 0.1 + 0.6 + 1.2 + 0.8 = 2.7
✅ Valid distribution. E(X) = 2.7
Example 2Binomial — Exactly k Successes
Problem: A fair coin is flipped 4 times. Find the probability of getting exactly 3 heads.
Setup
n = 4, k = 3, p = 0.5, (1−p) = 0.5. Check FIST: ✓ Fixed (4 flips), ✓ Independent, ✓ Two outcomes, ✓ Same p.
C(4,3)
C(4,3) = 4!/(3!·1!) = 4
Formula
P(X=3) = 4 × (0.5)³ × (0.5)¹ = 4 × 0.125 × 0.5 = 0.25
✅ P(X = 3) = 0.25 (or 1/4)
Example 3Binomial Mean and Standard Deviation
Problem: A student guesses randomly on a 20-question multiple choice test (4 options each). Find the mean and standard deviation of correct answers.
Setup
n = 20, p = 1/4 = 0.25 (probability of guessing correctly), q = 0.75.
Mean
μ = np = 20 × 0.25 = 5
Variance
σ² = np(1−p) = 20 × 0.25 × 0.75 = 3.75
Std Dev
σ = √3.75 ≈ 1.94
✅ Mean = 5 correct answers  |  Std Dev ≈ 1.94
Example 4Normal Distribution — Empirical Rule
Problem: Exam scores follow a normal distribution with μ = 70 and σ = 8. Find the range that contains the middle 95% of scores.
Rule
95% of data falls within 2 standard deviations of the mean.
Lower
μ − 2σ = 70 − 2(8) = 70 − 16 = 54
Upper
μ + 2σ = 70 + 2(8) = 70 + 16 = 86
✅ Middle 95% of scores lie between 54 and 86
Example 5z-score Interpretation
Problem: Heights of students are normally distributed with μ = 165 cm and σ = 10 cm. A student is 182 cm tall. Find their z-score and interpret it.
z-score
z = (x − μ)/σ = (182 − 165)/10 = 17/10 = 1.7
Interpret
z = 1.7 means this student's height is 1.7 standard deviations above the mean. Since 95% of students fall within z = ±2, this student is taller than most but not unusually so.
✅ z = 1.7 — the student is 1.7 standard deviations above the mean height.

Lesson Summary
Everything you learned in Lesson 3
✅ Key Points — Probability Distributions
  • A random variable assigns a number to each outcome. Discrete = countable values; continuous = any value in an interval.
  • A valid probability distribution requires: 0 ≤ P(x) ≤ 1 for all x, and Σ P(x) = 1.
  • Expected value E(X) = Σ x·P(x) — the long-run average outcome of the random variable.
  • A binomial experiment needs FIST: Fixed n, Independent trials, only two outcomes (S/F), same probability p each trial.
  • Binomial formula: P(X=k) = C(n,k) · pᵏ · (1−p)ⁿ⁻ᵏ. Mean = np. Variance = np(1−p).
  • C(n,k) = n! / (k!(n−k)!) counts the number of ways to arrange k successes in n trials.
  • The normal distribution is symmetric and bell-shaped. Mean = Median = Mode.
  • Empirical Rule: 68% within 1σ, 95% within 2σ, 99.7% within 3σ of the mean.
  • z-score = (x − μ)/σ measures how many standard deviations a value is from the mean.
