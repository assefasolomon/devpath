Unit 2 · Limits and Continuity

◀▶ One-Sided Limits

Learn to evaluate limits from the left and from the right separately. Understand when a two-sided limit exists and when it does not — a key skill for identifying discontinuities on the entrance exam.

📖 Reading: ~20 min
✏️ Examples: 5 worked
🎯 Quiz: 5 questions
🎥 Videos: 4 resources
🎯
Introduction
Approaching from one direction at a time

In real life, you can approach a location from the east or from the west. In mathematics, a function can be approached from the left side or from the right side. Sometimes the function behaves very differently depending on which direction you come from.

Consider a step function that equals 0 for x < 2 and 1 for x ≥ 2. Approaching x = 2 from the left gives 0. Approaching from the right gives 1. These are called one-sided limits, and they are essential for understanding whether a two-sided limit exists.

By the end of this lesson you will be able to:

  • Define left-hand and right-hand limits with correct notation
  • Evaluate one-sided limits from graphs and piecewise functions
  • Apply the existence theorem: two-sided limit exists ⟺ both one-sided limits are equal
  • Identify jump discontinuities using one-sided limits
  • Evaluate one-sided limits of absolute value functions
📖
Explanation
Theory and visual diagrams
◀ Left-Hand Limit
lim(x→a⁻) f(x) = L
Read as "the limit of f(x) as x approaches a from the left." x gets closer to a but stays less than a (x < a).
▶ Right-Hand Limit
lim(x→a⁺) f(x) = L
Read as "the limit of f(x) as x approaches a from the right." x gets closer to a but stays greater than a (x > a).
Approaching x = a from the left (x → a⁻) and from the right (x → a⁺). The two-sided limit only exists when both one-sided limits agree.
📌 Theorem — Existence of Two-Sided Limit

lim(x→a) f(x) = L exists if and only if both one-sided limits exist and are equal:

lim(x→a⁻) f(x) = L   AND   lim(x→a⁺) f(x) = L

If L⁻ ≠ L⁺, the two-sided limit does not exist (DNE).

2.1 Visual — Step Function (Jump Discontinuity)

Consider the step function: f(x) = 0 if x < 2, and f(x) = 1 if x ≥ 2.

Left-hand limit = 0, Right-hand limit = 1. Since 0 ≠ 1, the two-sided limit at x = 2 does NOT exist. This is called a jump discontinuity.

2.2 Piecewise Functions and One-Sided Limits

Piecewise functions are the most common way one-sided limits appear on the entrance exam. The key rule is:

⚠ Strategy for Piecewise Functions

For lim(x→a⁻): use the piece of the function where x < a.
For lim(x→a⁺): use the piece of the function where x > a.
Then compare the two results.

Both one-sided limits equal 5 — the two-sided limit exists and equals 5.

2.3 One-Sided Limits and Absolute Value

Absolute value functions often require one-sided limits. Remember:

|x − a| = (x − a) if x > a   and   |x − a| = −(x − a) if x < a
⚠ Key Rule

When you see |expression| in a limit, split into left and right cases using the definition of absolute value. The sign changes depending on which side of the point you approach from.

2.4 When Does the Two-Sided Limit Exist?

✅ Limit EXISTS
L⁻ = L⁺ = L
Both one-sided limits exist and are equal. The function may or may not be defined at x = a — it does not matter.
❌ Limit Does NOT Exist
L⁻ ≠ L⁺
The one-sided limits are different (jump discontinuity), or one/both limits are ±∞, or the function oscillates.

Worked Examples
5 exam-style problems solved step by step
Example 1 Piecewise — Limit Exists
Problem: Let f(x) = x + 3 for x < 1 and f(x) = 4 for x ≥ 1. Find lim(x→1) f(x).
Left limit
Use x + 3 (piece for x < 1):
lim(x→1⁻) (x+3) = 1+3 = 4
Right limit
Use 4 (piece for x ≥ 1):
lim(x→1⁺) 4 = 4
Compare
L⁻ = 4 = L⁺ = 4 ✓ — limits are equal
✅ lim(x→1) f(x) = 4 — the two-sided limit exists
Example 2 Piecewise — Limit Does NOT Exist
Problem: Let f(x) = 2x for x < 3 and f(x) = x + 4 for x ≥ 3. Does lim(x→3) f(x) exist?
Left limit
Use 2x:
lim(x→3⁻) 2x = 2(3) = 6
Right limit
Use x + 4:
lim(x→3⁺) (x+4) = 3+4 = 7
Compare
L⁻ = 6 ≠ L⁺ = 7 — limits are different
✅ lim(x→3) f(x) does NOT EXIST — jump discontinuity at x = 3
Example 3 Absolute Value Function
Problem: Evaluate lim(x→0⁻) |x|/x and lim(x→0⁺) |x|/x
Left limit
For x < 0: |x| = −x, so:
lim(x→0⁻) |x|/x = lim(x→0⁻) −x/x = −1
Right limit
For x > 0: |x| = x, so:
lim(x→0⁺) |x|/x = lim(x→0⁺) x/x = 1
✅ Left limit = −1, Right limit = 1. Since −1 ≠ 1, the two-sided limit DNE.
Example 4 Three-Piece Piecewise Function
Problem: f(x) = x² for x < 0, f(x) = 1 for x = 0, f(x) = 2x for x > 0. Find lim(x→0) f(x).
Left limit
Use x² (piece for x < 0):
lim(x→0⁻) x² = 0² = 0
Right limit
Use 2x (piece for x > 0):
lim(x→0⁺) 2x = 2(0) = 0
Compare
L⁻ = 0 = L⁺ = 0 ✓ — Note: f(0) = 1 but the limit is still 0
✅ lim(x→0) f(x) = 0 — even though f(0) = 1, the limit equals 0
Example 5 Finding k so that Limit Exists
Problem: f(x) = kx + 1 for x ≤ 2 and f(x) = x² − 1 for x > 2. Find k such that lim(x→2) f(x) exists.
Left limit
lim(x→2⁻) (kx+1) = 2k+1
Right limit
lim(x→2⁺) (x²−1) = 4−1 = 3
Set equal
For limit to exist: 2k+1 = 3
2k = 2  ⟹  k = 1
✅ k = 1 makes the two-sided limit exist and equal 3

Lesson Summary
Everything you learned in Unit 2 Lesson 3
✅ Key Points — One-Sided Limits
  • Left-hand limit lim(x→a⁻) f(x): approach a from values less than a (x < a).
  • Right-hand limit lim(x→a⁺) f(x): approach a from values greater than a (x > a).
  • The two-sided limit exists if and only if L⁻ = L⁺ — they must be equal.
  • If L⁻ ≠ L⁺ the two-sided limit does NOT exist — this is a jump discontinuity.
  • For piecewise functions: use the left piece for L⁻ and the right piece for L⁺.
  • For |x − a|: equals (x − a) when x > a, and −(x − a) when x < a.
  • f(a) does not affect the limit — the limit describes approach, not the actual value.
  • To find a parameter k: set L⁻ = L⁺ and solve the resulting equation.
