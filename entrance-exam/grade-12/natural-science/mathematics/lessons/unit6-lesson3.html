📏 Distance Between Two Points in Space

Extend the 2D distance formula into three dimensions. Derive the 3D distance formula from the Pythagorean theorem applied twice, apply it to find the distance between any two points in space, and use it to solve geometric problems on the entrance exam.

📖 Reading: ~18 min
✏️ Examples: 5 worked
🎯 Quiz: 5 questions
🎥 Videos: 4 resources

Introduction
What you will learn in this lesson

In 2D you know the distance formula: d = √((x₂−x₁)² + (y₂−y₁)²). In 3D, a point moves in three independent directions, so we need to account for all three coordinate differences. The result is a natural extension of the 2D formula using the Pythagorean theorem applied twice.

By the end of this lesson you will be able to:

  • State and apply the 3D distance formula: d = √((x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²)
  • Derive the formula from the Pythagorean theorem
  • Find the distance between any two given points in space
  • Find the distance from a point to the origin
  • Use the distance formula to verify whether three points are collinear or form a specific triangle type
  • Solve entrance exam problems involving distance in 3D
📖
Explanation
Complete theory with visual aids

2.1 Review — Distance Formula in 2D

Recall from Grade 10: the distance between two points P₁(x₁, y₁) and P₂(x₂, y₂) in the plane is:

d = √((x₂ − x₁)² + (y₂ − y₁)²)

This comes from the Pythagorean theorem applied to the right triangle formed by the two points and their horizontal/vertical legs. In 3D we simply add a third leg.

2.2 Deriving the 3D Distance Formula

Let P₁(x₁, y₁, z₁) and P₂(x₂, y₂, z₂) be two points. We build a rectangular box (cuboid) with P₁ and P₂ at opposite corners, sides parallel to the axes.

The diagonal d of the box from P₁ to P₂ is found using Pythagoras twice.

Step 1: The base diagonal (on the bottom face) has length d₁ = √(Δx² + Δy²) by 2D Pythagoras, where Δx = x₂−x₁ and Δy = y₂−y₁.
Step 2: The space diagonal d forms a right triangle with d₁ (base) and Δz = z₂−z₁ (vertical leg).
Step 3: Apply Pythagoras again: d² = d₁² + Δz² = (Δx² + Δy²) + Δz²
Result: d = √((x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²)
📌 3D Distance Formula

The distance between points P₁(x₁, y₁, z₁) and P₂(x₂, y₂, z₂) is:

d(P₁, P₂) = √((x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²)

This is always a non-negative number. The order of subtraction does not matter since differences are squared.

2.3 Distance from a Point to the Origin

A special but very common case: the distance from point P(x, y, z) to the origin O(0, 0, 0).

📌 Distance from Origin

|OP| = √(x² + y² + z²)

This is obtained by substituting (x₁, y₁, z₁) = (0, 0, 0) into the distance formula. This quantity also equals the magnitude (length) of the position vector of P — a concept you will use in Lesson 6.

2.4 Applications of the Distance Formula

Verify collinearity
Three points A, B, C are collinear if d(A,B) + d(B,C) = d(A,C) — one point lies between the other two on the same line.
Classify a triangle
Find all three side lengths. If all equal → equilateral. If two equal → isosceles. If a²+b²=c² → right triangle.
Find an unknown coordinate
Given d(P₁, P₂) = k and one unknown coordinate, square both sides and solve the resulting equation.
Sphere radius
The radius of a sphere with centre C and surface point P is r = d(C, P) — directly using the distance formula (see Lesson 5).
⚠ Most common exam mistake

Forgetting to include the z-term. The 3D formula has three squared differences under the radical: (x₂−x₁)², (y₂−y₁)² and (z₂−z₁)². Omitting the z-term gives the 2D distance — always wrong when z-coordinates differ.

Worked Examples
5 exam-style problems solved step by step
Example 1Basic Distance Calculation
Problem: Find the distance between A(1, 2, 3) and B(4, 6, 3).
Step 1
Identify the coordinates: (x₁,y₁,z₁) = (1,2,3) and (x₂,y₂,z₂) = (4,6,3).
Step 2
Compute the squared differences:
(4−1)² = 3² = 9
(6−2)² = 4² = 16
(3−3)² = 0² = 0
Step 3
d = √(9 + 16 + 0) = √25 = 5
✅ d(A, B) = 5
Example 2Distance with Negative Coordinates
Problem: Find the distance between P(−1, 3, −2) and Q(2, −1, 4).
Step 1
Squared differences:
(2−(−1))² = 3² = 9
(−1−3)² = (−4)² = 16
(4−(−2))² = 6² = 36
Step 2
d = √(9 + 16 + 36) = √61
✅ d(P, Q) = √61 ≈ 7.81
Example 3Distance from the Origin
Problem: Find the distance from P(2, −3, 6) to the origin.
Formula
Use |OP| = √(x² + y² + z²):
|OP| = √(2² + (−3)² + 6²) = √(4 + 9 + 36) = √49 = 7
✅ Distance from P to origin = 7
Example 4Finding an Unknown Coordinate
Problem: Point P(3, k, 1) is at distance √14 from the origin. Find k.
Setup
|OP| = √(3² + k² + 1²) = √14
Square both sides: 9 + k² + 1 = 14
Solve
k² = 14 − 10 = 4
k = ±2
✅ k = 2 or k = −2
Example 5Classifying a Triangle in 3D
Problem: Given A(0, 0, 0), B(2, 0, 0) and C(1, 1, 1), classify triangle ABC.
AB
d(A,B) = √((2−0)²+0+0) = √4 = 2
AC
d(A,C) = √(1+1+1) = √3
BC
d(B,C) = √((1−2)²+1+1) = √(1+1+1) = √3
Classify
AC = BC = √3, AB = 2. Two sides equal → isosceles.
Check right angle: AB² = 4, AC² + BC² = 3+3 = 6 ≠ 4. Not right-angled.
Check: AC² + BC² vs AB² → 6 > 4, so the angle at C is acute.
✅ Triangle ABC is isosceles (AC = BC = √3, AB = 2).

Lesson Summary
Everything you learned in Lesson 3
✅ Key Points — Distance Between Two Points in Space
  • The 3D distance formula: d = √((x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²). It has three squared differences — one for each dimension.
  • The formula is derived by applying the Pythagorean theorem twice: once on the base of the rectangular box, once on the space diagonal.
  • Distance is always non-negative. The order of subtraction does not matter since differences are squared.
  • Distance from P(x, y, z) to the origin: |OP| = √(x² + y² + z²).
  • To find an unknown coordinate: substitute into the formula, set equal to the given distance, square both sides and solve.
  • Three points are collinear if d(A,B) + d(B,C) = d(A,C) for some ordering.
  • To classify a triangle: compute all three side lengths, then check for equal sides (isosceles/equilateral) or apply a² + b² = c² (right-angled).
  • The 3D formula reduces to the 2D formula when z₁ = z₂ = 0 — the z-term vanishes.
