Introduction
What you will learn in this lesson

Linear programming is a method for finding the best outcome — maximum profit or minimum cost — when you have limited resources. It is used in business, agriculture, manufacturing, logistics and many other fields. The Ethiopian entrance exam tests your ability to set up and solve these problems using a graph.

By the end of this lesson you will be able to:

  • Identify the decision variables, objective function and constraints from a word problem
  • Formulate a linear programming problem mathematically
  • State and apply the Corner Point Theorem
  • Solve maximisation and minimisation problems using the graphical method
  • Evaluate the objective function at each corner point and identify the optimum
  • Interpret the solution in the context of the original problem

Explanation
Complete theory with visual aids

2.1 Components of a Linear Programming Problem

Decision Variables
The unknowns you control — usually x and y. They represent quantities to be determined (units produced, hours allocated, etc.).
Objective Function
The linear expression you want to maximise (profit, revenue) or minimise (cost, time). Written as Z = ax + by.
Constraints
Linear inequalities representing limitations — available materials, budget, time, machine capacity, and always x ≥ 0, y ≥ 0.
Optimal Solution
The point (x, y) in the feasible region that gives the maximum or minimum value of Z. Always found at a corner point.

2.2 The Corner Point Theorem

📌 Corner Point Theorem (Fundamental Theorem of Linear Programming)

If an optimal solution to a linear programming problem exists, it occurs at a corner point (vertex) of the feasible region.

To find the optimal solution:
1. Find all corner points of the feasible region.
2. Evaluate the objective function Z = ax + by at each corner point.
3. The corner point giving the largest Z is the maximum; the smallest Z is the minimum.

📝 Why corner points only?

The objective function Z = ax + by is a family of parallel lines (iso-profit or iso-cost lines). As you move these lines across the feasible region, the last point touched before leaving the region is always a corner point — never an interior point or an edge midpoint.

2.3 The Complete 6-Step Graphical Method

1
Define variables — identify what x and y represent in the problem.
2
Write the objective function — Z = ax + by (to maximise or minimise).
3
Write the constraints — translate each resource limitation into a linear inequality. Include x ≥ 0 and y ≥ 0.
4
Graph the feasible region — draw all boundary lines, shade each half-plane, and identify the overlap region.
5
Find all corner points — read from the graph or solve boundary line pairs simultaneously.
6
Evaluate Z at each corner point — the largest value is the maximum, the smallest is the minimum. State the answer in context.

2.4 Word Problem Formulation Tips

Reading word problems carefully is half the battle. Use this translation table:

Words in the problem Mathematical meaning
"maximise profit / revenue"Objective: Maximise Z
"minimise cost / time"Objective: Minimise Z
"at most / no more than / cannot exceed"≤ constraint
"at least / no fewer than / minimum of"≥ constraint
"cannot be negative / must be non-negative"x ≥ 0, y ≥ 0
"exactly / must equal"= constraint (rare)

Worked Examples
5 exam-style problems solved step by step
Example 1Maximising Profit — Full Solution
Problem: A factory makes two products A and B. Each unit of A requires 2 hours of labour and 1 kg of material. Each unit of B requires 1 hour of labour and 3 kg of material. Available: 8 hours labour and 9 kg material per day. Profit is 3 ETB per unit of A and 5 ETB per unit of B. How many units of each should be produced to maximise profit?
Step 1
Let x = units of A, y = units of B.
Step 2
Objective: Maximise Z = 3x + 5y
Step 3
Constraints:
Labour: 2x + y ≤ 8
Material: x + 3y ≤ 9
Non-negativity: x ≥ 0, y ≥ 0
Step 4–5
Find corner points:
• (0, 0) — origin
• (4, 0) — x-axis: 2x=8 → x=4
• (0, 3) — y-axis: 3y=9 → y=3
• Intersection of 2x+y=8 and x+3y=9:
  From first: y=8−2x. Sub: x+3(8−2x)=9 → x+24−6x=9 → −5x=−15 → x=3, y=2. Point (3,2).
Step 6
Evaluate Z = 3x + 5y:
Corner PointZ = 3x + 5y
(0, 0)0
(4, 0)12
(0, 3)15
(3, 2)3(3)+5(2) = 9+10 = 19 ← Maximum
✅ Produce 3 units of A and 2 units of B for maximum profit of 19 ETB.
Example 2Minimising Cost
Problem: Minimise Z = 2x + 3y subject to: x + y ≥ 4, x + 2y ≥ 6, x ≥ 0, y ≥ 0.
Corner points
• x-axis: set y=0 in x+y=4 → (4, 0)
• y-axis: set x=0 in x+2y=6 → (0, 3)
• Intersection of x+y=4 and x+2y=6: subtract → y=2, x=2. Point (2, 2).
Evaluate
Z at each corner:
Corner PointZ = 2x + 3y
(4, 0)8
(2, 2)4+6 = 10
(0, 3)9
📝 Minimisation note

The minimum is at (0,3) with Z=9. The feasible region is unbounded (≥ constraints), so always check: does the minimum actually exist? Here it does — the region is bounded below by the constraint lines.

✅ Minimum Z = 9 at point (0, 3).
Example 3Reading the Optimal Value Directly from the Table
Problem: A feasible region has corner points (0,0), (6,0), (4,3) and (0,5). The objective function is Z = 4x + 6y. Find the maximum and minimum values of Z.
Evaluate
No graphing needed — just substitute each corner point:
Corner PointZ = 4x + 6y
(0, 0)0 ← Minimum
(6, 0)24
(4, 3)16+18 = 34 ← Maximum
(0, 5)30
✅ Maximum Z = 34 at (4, 3).   Minimum Z = 0 at (0, 0).
Example 4Agriculture Word Problem
Problem: A farmer grows teff (x hectares) and wheat (y hectares). He has at most 10 hectares of land and at most 12 units of fertiliser. Teff needs 1 unit of fertiliser per hectare; wheat needs 2. Profit is 500 ETB/hectare for teff and 800 ETB/hectare for wheat. Maximise profit.
Formulate
Maximise Z = 500x + 800y
Subject to: x + y ≤ 10 (land), x + 2y ≤ 12 (fertiliser), x ≥ 0, y ≥ 0
Corner points
• (0, 0), (10, 0), (0, 6)
• Intersection of x+y=10 and x+2y=12: subtract → y=2, x=8. Point (8, 2).
Corner PointZ = 500x + 800y
(0, 0)0
(10, 0)5,000
(8, 2)4,000+1,600 = 5,600 ← Maximum
(0, 6)4,800
✅ Plant 8 hectares of teff and 2 hectares of wheat for maximum profit of 5,600 ETB.
Example 5Identifying the Objective Function from Context
Problem: The corner points of a feasible region are (1,2), (3,4) and (5,1). For which objective function is the maximum at (3,4)?
(A) Z = x + y   (B) Z = 2x + y   (C) Z = x + 3y   (D) Z = 3x + y
Strategy
Evaluate each function at all three corner points and check which one is maximised at (3,4).
Test Z = x + 3y
(1,2): 1+6=7   (3,4): 3+12=15   (5,1): 5+3=8
Maximum is at (3,4). ✓
Verify others
Z=x+y: (3,4)=7, (5,1)=6, (1,2)=3 → max at (3,4) ✓ — but also check Z=2x+y: (5,1)=11, (3,4)=10 → max NOT at (3,4). Z=3x+y: (5,1)=16 → max NOT at (3,4).
Only Z=x+3y gives maximum uniquely at (3,4).
✅ Answer: (C) Z = x + 3y

Lesson Summary
Everything you learned in Lesson 2
✅ Key Points — Linear Programming Problems
  • Every LP problem has three parts: decision variables (x, y), an objective function Z = ax + by to optimise, and constraints (linear inequalities).
  • The Corner Point Theorem: the optimal value of Z always occurs at a vertex of the feasible region — never at an interior point.
  • The 6-step method: Define variables → Write Z → Write constraints → Graph feasible region → Find corner points → Evaluate Z at each corner.
  • "At most / cannot exceed" → ≤ constraint. "At least / minimum of" → ≥ constraint.
  • Always include x ≥ 0 and y ≥ 0 for real-world problems — quantities cannot be negative.
  • Find corner points by solving pairs of boundary equations simultaneously (elimination or substitution).
  • For maximisation: pick the corner with the largest Z. For minimisation: pick the corner with the smallest Z.
  • Always state the answer in context: not just "Z = 19" but "maximum profit is 19 ETB when 3 units of A and 2 units of B are produced."
