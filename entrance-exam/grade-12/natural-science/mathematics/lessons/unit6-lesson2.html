📍 Coordinates of a Point in Space

Learn how to precisely locate any point in three-dimensional space using an ordered triple (x, y, z), how to read and plot 3D coordinates, and how to determine a point's coordinates by reading its perpendicular distances from each coordinate plane.

📖 Reading: ~18 min
✏️ Examples: 5 worked

Introduction
What you will learn in this lesson

In Lesson 1 you set up the 3D framework — the three axes and three planes. Now you will use that framework to locate specific points. Every point in space has exactly one address: an ordered triple (x, y, z). Reading and writing these coordinates precisely is a skill tested directly on the entrance exam.

By the end of this lesson you will be able to:

  • Read the coordinates (x, y, z) of a point plotted in 3D space
  • Understand that each coordinate is the perpendicular distance from the opposite coordinate plane
  • Plot a point in 3D space given its ordered triple
  • Find the coordinates of a point given its distances from the coordinate planes
  • Determine coordinates of projections of a point onto each axis and plane
  • Recognise how changing one coordinate moves a point along a specific direction

Explanation
Complete theory with visual aids

2.1 The Ordered Triple (x, y, z)

📌 Coordinates of a Point in Space

Every point P in three-dimensional space is uniquely identified by an ordered triple (x, y, z) where:

• x = the signed distance from the yz-plane (positive if in front, negative if behind)
• y = the signed distance from the xz-plane (positive if to the right, negative if to the left)
• z = the signed distance from the xy-plane (positive if above, negative if below)

We write P = (x, y, z) or P(x, y, z).

📝 Each coordinate = distance from the opposite plane

This is the key insight: x measures how far from the yz-plane, not from the x-axis. Similarly y measures how far from the xz-plane, and z measures how far from the xy-plane. The sign tells you which side of the plane you are on.

2.2 How to Read Coordinates from a Diagram

Given a point marked in a 3D diagram, find its coordinates using these steps:

x
Read how far the point is from the yz-plane, moving parallel to the x-axis.
y
Read how far the point is from the xz-plane, moving parallel to the y-axis.
z
Read how far the point is from the xy-plane, moving parallel to the z-axis.

Point P(3, 2, 3): move 3 units along x (green), 2 units along y (blue), 3 units up along z (red).

2.3 How to Plot a Point P(x, y, z)

Follow these four steps to plot any point in 3D space on a diagram:

1
Start at the origin O.
2
Move |x| units along the x-axis (right if x > 0, left if x < 0).
3
From that point, move |y| units parallel to the y-axis (forward if y > 0, back if y < 0).
4
From that point, move |z| units parallel to the z-axis (up if z > 0, down if z < 0). Mark the point.

2.4 Projections of a Point onto Axes and Planes

The projection of point P(x, y, z) is found by dropping a perpendicular from P onto an axis or plane. The foot of that perpendicular is the projection.

Projection onto xy-plane
(x, y, 0)
Drop perpendicular to the xy-plane — z becomes 0
Projection onto yz-plane
(0, y, z)
Drop perpendicular to the yz-plane — x becomes 0
Projection onto xz-plane
(x, 0, z)
Drop perpendicular to the xz-plane — y becomes 0
Projection onto x-axis
(x, 0, 0)
Only the x-coordinate survives
Projection onto y-axis
(0, y, 0)
Only the y-coordinate survives
Projection onto z-axis
(0, 0, z)
Only the z-coordinate survives
📝 Rule for projections

To project onto a plane: set the coordinate perpendicular to that plane to zero. To project onto an axis: set the two coordinates not on that axis to zero.

2.5 The 2D System as a Special Case of 3D

The familiar 2D coordinate system is simply the xy-plane (z = 0) inside the 3D system. Every 2D point (x, y) corresponds to the 3D point (x, y, 0). This means everything you know about 2D coordinates still works in 3D — you just add a third component.

2D Point
(x, y)
On the flat xy-plane
3D Equivalent
(x, y, 0)
Same point — z = 0 means on the xy-plane

Worked Examples
5 exam-style problems solved step by step
Example 1Reading Coordinates from a Description
Problem: Point P is 4 units from the yz-plane, 2 units from the xz-plane and 5 units from the xy-plane, all in the positive direction. What are its coordinates?
x
Distance from yz-plane = 4 (positive) → x = 4
y
Distance from xz-plane = 2 (positive) → y = 2
z
Distance from xy-plane = 5 (positive) → z = 5
✅ P = (4, 2, 5) — in the first octant.
Example 2Finding Projections of a Point
Problem: Find the projections of P(3, −1, 4) onto: (a) the xy-plane, (b) the yz-plane, (c) the x-axis, (d) the z-axis.
(a)
Projection onto xy-plane: set z = 0 → (3, −1, 0)
(b)
Projection onto yz-plane: set x = 0 → (0, −1, 4)
(c)
Projection onto x-axis: set y = 0 and z = 0 → (3, 0, 0)
(d)
Projection onto z-axis: set x = 0 and y = 0 → (0, 0, 4)
✅ (a) (3,−1,0)  |  (b) (0,−1,4)  |  (c) (3,0,0)  |  (d) (0,0,4)
Example 3Coordinates from Distances (Mixed Signs)
Problem: A point Q is 6 units from the yz-plane (in the negative x-direction), 3 units from the xz-plane (positive y-direction) and 2 units from the xy-plane (negative z-direction). Write the coordinates of Q.
x
6 units in the negative x-direction from the yz-plane → x = −6
y
3 units in the positive y-direction from the xz-plane → y = 3
z
2 units in the negative z-direction from the xy-plane → z = −2
✅ Q = (−6, 3, −2) — in the sixth octant (−, +, −).
Example 4Identifying Distances from Coordinate Planes
Problem: For P = (−2, 5, −3), find: (a) its distance from the yz-plane, (b) its distance from the xz-plane, (c) its distance from the xy-plane.
(a)
Distance from yz-plane = |x| = |−2| = 2
(b)
Distance from xz-plane = |y| = |5| = 5
(c)
Distance from xy-plane = |z| = |−3| = 3
✅ (a) 2 units  |  (b) 5 units  |  (c) 3 units
Example 5Effect of Changing One Coordinate
Problem: Start at P = (2, 3, 4). Describe where each new point is relative to P: (a) Q = (5, 3, 4)   (b) R = (2, 3, −1)   (c) S = (2, 0, 4)
(a)
Q = (5, 3, 4): only x changed from 2 to 5 (increased by 3). Q is 3 units to the right of P along the x-direction. y and z are the same.
(b)
R = (2, 3, −1): only z changed from 4 to −1 (decreased by 5). R is 5 units below P along the z-direction.
(c)
S = (2, 0, 4): y changed from 3 to 0. S is the projection of P onto the xz-plane, located 3 units from P in the negative y-direction.
✅ (a) 3 units right along x  |  (b) 5 units down along z  |  (c) Projection of P onto xz-plane

Lesson Summary
Everything you learned in Lesson 2
✅ Key Points — Coordinates of a Point in Space
  • Every point in 3D space has a unique ordered triple (x, y, z) as its address.
  • The x-coordinate is the signed distance from the yz-plane; y from the xz-plane; z from the xy-plane.
  • To plot P(x, y, z): start at O, move x units along x-axis, then y units parallel to y-axis, then z units parallel to z-axis.
  • Distance from any coordinate plane equals the absolute value of the corresponding coordinate.
  • Projection onto a plane: set the coordinate perpendicular to that plane to zero. (xy-plane → z=0; yz-plane → x=0; xz-plane → y=0)
  • Projection onto an axis: set the two other coordinates to zero. (x-axis → y=z=0; y-axis → x=z=0; z-axis → x=y=0)
  • Changing only the x-coordinate moves a point parallel to the x-axis. Same rule applies for y and z.
  • A 2D point (x, y) is the 3D point (x, y, 0) — it lies on the xy-plane where z = 0.
