📋 Introduction to Sequences

Understand what sequences are, how to describe and write them using notation, identify different types, and recognize patterns — the foundation for all of Unit 1.

📖 Reading: ~15 min
✏️ Examples: 4 worked
🎯 Quiz: 5 questions

Introduction
What you will learn in this lesson

Have you ever noticed how numbers sometimes follow a pattern? Consider the number of seats in a cinema where each row has 2 more seats than the row in front. Or the way bacteria doubles every hour. These are real-world examples of sequences.

A sequence is simply an ordered list of numbers that follows a rule. Understanding sequences is the foundation for calculus, statistics, and many real-world applications — all of which appear on the Ethiopian University Entrance Examination.

By the end of this lesson, you will be able to:

  • Define a sequence and explain what makes it different from a set
  • Use correct sequence notation: a₁, a₂, aₙ, {aₙ}
  • Find any term of a sequence using a given formula
  • Identify whether a sequence is finite or infinite
  • Recognize arithmetic, geometric, and other common patterns
  • Write the general term (nth term formula) of a simple sequence

Explanation
Detailed concepts with visual aids
📌 Definition — Sequence

A sequence is a function whose domain is the set of positive integers (or a subset of them). Each value in the sequence is called a term. The terms are written in a definite order: a₁, a₂, a₃, ..., aₙ, ...

2.1 Understanding Sequences Visually

Consider the sequence: 2, 4, 6, 8, 10, ...

a₁ = 2
→
a₂ = 4
→
a₃ = 6
→
a₄ = 8
→
aₙ = 2n

Each term is found by multiplying its position number by 2. The general term (also called the nth term) is the rule that generates any term: aₙ = 2n.

2.2 Sequence Notation

Sequences are written in several ways. You must be comfortable with all of them for the entrance exam:

Notation Meaning Example
{aₙ} The entire sequence {2, 4, 6, 8, ...}
a₁ First term a₁ = 2
aₙ The nth term (general term) aₙ = 2n
aₙ₊₁ The term after aₙ If aₙ = 2n, then aₙ₊₁ = 2(n+1)

2.3 Types of Sequences

Finite Sequence
Has a last term. The number of terms can be counted.
1, 3, 5, 7, 9
5 terms — ends at 9
Infinite Sequence
Has no last term. Continues forever, shown by "..."
1, 3, 5, 7, 9, ...
Continues indefinitely
Arithmetic Sequence
Each term differs from the previous by a constant amount (common difference d).
2, 5, 8, 11, 14, ...
d = 3 (add 3 each time)
Geometric Sequence
Each term is multiplied by a constant factor (common ratio r).
3, 6, 12, 24, 48, ...
r = 2 (multiply by 2)

2.4 Finding Terms Using the General Formula

If you are given the nth term formula, you can find any term by substituting the position number for n.

⚠ Key Exam Tip

On the entrance exam, you will often be given a formula like aₙ = 3n − 1 and asked to find a specific term, or given terms and asked to find the formula. Practice both directions.

For the sequence defined by aₙ = n² + 1:

a₁ = 1² + 1 = 2  |  a₂ = 2² + 1 = 5  |  a₃ = 3² + 1 = 10  |  a₄ = 4² + 1 = 17

So the sequence is: 2, 5, 10, 17, 26, ...

2.5 Recursive Sequences

A recursive formula defines each term in relation to the previous term(s). You need an initial term plus the rule.

Example — Fibonacci-style Recursive Sequence

Let a₁ = 1, a₂ = 1, and aₙ = aₙ₋₁ + aₙ₋₂ for n ≥ 3.

Then: a₃ = a₂ + a₁ = 1 + 1 = 2  |  a₄ = a₃ + a₂ = 2 + 1 = 3  |  a₅ = 3 + 2 = 5
Sequence: 1, 1, 2, 3, 5, 8, 13, ... (Fibonacci sequence)

Worked Examples
Step-by-step solutions — study these carefully
Example 1 Finding Terms from an Explicit Formula
Problem: The general term of a sequence is given by aₙ = 2n² − 3n + 1. Find the first four terms and the 10th term.
Step 1
Find a₁: substitute n = 1
a₁ = 2(1)² − 3(1) + 1 = 2 − 3 + 1 = 0
Step 2
Find a₂: substitute n = 2
a₂ = 2(2)² − 3(2) + 1 = 8 − 6 + 1 = 3
Step 3
Find a₃: substitute n = 3
a₃ = 2(3)² − 3(3) + 1 = 18 − 9 + 1 = 10
Step 4
Find a₄: substitute n = 4
a₄ = 2(4)² − 3(4) + 1 = 32 − 12 + 1 = 21
Step 5
Find a₁₀: substitute n = 10
a₁₀ = 2(10)² − 3(10) + 1 = 200 − 30 + 1 = 171
✅ Answer: The first four terms are 0, 3, 10, 21 and the 10th term is 171.
Example 2 Writing the General Term from a Pattern
Problem: Write the general term (nth term formula) for the sequence: 3, 7, 11, 15, 19, ...
Step 1
Check the differences between consecutive terms:
7 − 3 = 4,   11 − 7 = 4,   15 − 11 = 4
The difference is constant (d = 4), so this is an arithmetic sequence.
Step 2
The general term of an arithmetic sequence is aₙ = a₁ + (n−1)d
Here a₁ = 3 and d = 4:
aₙ = 3 + (n−1)(4) = 3 + 4n − 4 = 4n − 1
Step 3
Verify: a₁ = 4(1)−1 = 3 ✓   a₂ = 4(2)−1 = 7 ✓   a₃ = 4(3)−1 = 11 ✓
✅ Answer: The general term is aₙ = 4n − 1
Example 3 Recursive Sequence — Finding Terms
Problem: A sequence is defined recursively by a₁ = 5 and aₙ = aₙ₋₁ + 3 for n ≥ 2. Find the first 5 terms.
Step 1
a₁ = 5 (given)
Step 2
a₂ = a₁ + 3 = 5 + 3 = 8
Step 3
a₃ = a₂ + 3 = 8 + 3 = 11
Step 4
a₄ = a₃ + 3 = 11 + 3 = 14
Step 5
a₅ = a₄ + 3 = 14 + 3 = 17
✅ Answer: 5, 8, 11, 14, 17
Notice this is an arithmetic sequence with a₁ = 5 and d = 3.
Example 4 Identifying Sequence Type — Entrance Exam Style
Problem: Which of the following is a geometric sequence?
A) 2, 4, 6, 8, ...  B) 1, 3, 9, 27, ...  C) 5, 10, 20, 35, ...  D) 1, 4, 9, 16, ...
Step 1
For a geometric sequence, the ratio aₙ₊₁/aₙ must be constant. Check each option:
Check A
2, 4, 6, 8: ratios are 4/2=2, 6/4=1.5, 8/6=1.33 — NOT constant ✗
Check B
1, 3, 9, 27: ratios are 3/1=3, 9/3=3, 27/9=3 — Constant ratio r=3 ✓
Check C
5, 10, 20, 35: ratios are 10/5=2, 20/10=2, 35/20=1.75 — NOT constant ✗
Check D
1, 4, 9, 16: these are perfect squares (n²) — differences are 3, 5, 7 — NOT geometric ✗
✅ Answer: B) 1, 3, 9, 27, ... with common ratio r = 3

Lesson Summary
Key points to remember
✅ What you learned in Lesson 1
  • A sequence is an ordered list of numbers following a rule — each number is called a term.
  • Sequences are written as a₁, a₂, a₃, ..., aₙ where n is the position (index) of the term.
  • A finite sequence has a last term; an infinite sequence continues forever (shown by ...).
  • An explicit formula gives aₙ directly as a function of n — substitute n to find any term.
  • A recursive formula defines each term using previous terms — requires a starting value.
  • Arithmetic sequences have a constant difference between terms: aₙ₊₁ − aₙ = d.
  • Geometric sequences have a constant ratio between terms: aₙ₊₁ / aₙ = r.
  • To find the general term: look at the pattern, check differences (arithmetic) or ratios (geometric).
