Introduction
What you will learn in this lesson

Probability is the branch of mathematics that measures how likely an event is to occur. It turns everyday uncertainty — will it rain? will this coin land heads? — into precise numbers between 0 and 1.

Impossible (0)
Unlikely
Even chance (0.5)
Likely
Certain (1)

By the end of this lesson you will be able to:

  • Define an experiment, sample space, outcome and event
  • Apply the classical probability formula: P(A) = n(A) / n(S)
  • Use complement rule: P(A') = 1 − P(A)
  • Apply the addition rule for mutually exclusive and non-exclusive events
  • Apply the multiplication rule for independent and dependent events
  • Distinguish between independent and mutually exclusive events
  • Solve combined probability problems step by step

Explanation
Complete theory with visual aids

2.1 Core Vocabulary

Experiment
A process whose outcome cannot be predicted with certainty. Example: rolling a die, flipping a coin.
Sample Space (S)
The set of all possible outcomes. For a die: S = {1, 2, 3, 4, 5, 6}. n(S) = 6.
Outcome
A single possible result of one experiment. Rolling a 4 is one outcome.
Event (A)
A subset of the sample space. "Rolling an even number" = {2, 4, 6}. n(A) = 3.

2.2 Classical Probability Formula

When all outcomes are equally likely, the probability of event A is:

📌 Classical Probability

P(A) = n(A) / n(S)

where n(A) = number of outcomes in event A, and n(S) = total number of outcomes in the sample space.

Probability always satisfies: 0 ≤ P(A) ≤ 1
P(A) = 0 means impossible. P(A) = 1 means certain.

📝 Quick Check

The probabilities of all outcomes in a sample space must add up to 1. If they don't, you have made an error.

2.3 Complement Rule

The complement of event A, written A' (or Aᶜ), is the event that A does not happen — all outcomes in S that are not in A.

📌 Complement Rule

P(A') = 1 − P(A)

Use this whenever it is easier to count what does NOT happen than what does. For example: "at least one" problems are usually solved via the complement.

2.4 Addition Rule

The addition rule finds the probability that event A or event B occurs.

📌 General Addition Rule

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

We subtract P(A ∩ B) to avoid counting the overlap twice.

📌 Mutually Exclusive Events

Two events are mutually exclusive (disjoint) if they cannot both happen at the same time — their intersection is empty: A ∩ B = ∅.

For mutually exclusive events: P(A ∪ B) = P(A) + P(B)

Example: Rolling a 2 and rolling a 5 on one die are mutually exclusive.

2.5 Multiplication Rule

The multiplication rule finds the probability that event A and event B both occur.

📌 Independent Events

Two events are independent if the occurrence of one does not affect the probability of the other.

P(A ∩ B) = P(A) × P(B)

Example: Flipping a coin twice. Getting heads on the first flip does not affect the second.

📌 Dependent Events — Conditional Probability

When events are dependent, the probability of B changes given that A has occurred:

P(A ∩ B) = P(A) × P(B|A)

P(B|A) is read "the probability of B given A has already happened." This is the conditional probability.

Independent vs Mutually Exclusive — Don't Confuse Them
Independent
One event happening does not change the probability of the other. They can happen together.
Mutually Exclusive
They cannot happen together — P(A∩B) = 0. They are always dependent (unless P = 0).

2.6 Conditional Probability

📌 Conditional Probability Formula

The probability of B given A has occurred:

P(B|A) = P(A ∩ B) / P(A)

This formula can be rearranged to give the multiplication rule: P(A ∩ B) = P(A) × P(B|A).

⚠ Common Exam Trap

When drawing cards or balls without replacement, probabilities change on each draw — always update the denominator after each selection. When drawing with replacement, the events are independent and the denominator stays the same.

Worked Examples
5 exam-style problems solved step by step
Example 1Classical Probability — Rolling a Die
Problem: A fair die is rolled once. Find: (a) P(rolling a 4), (b) P(rolling an even number), (c) P(rolling a number greater than 4).
Setup
Sample space S = {1, 2, 3, 4, 5, 6}. n(S) = 6.
Part a
Event A = {4}. n(A) = 1.
P(4) = 1/6
Part b
Event B = {2, 4, 6}. n(B) = 3.
P(even) = 3/6 = 1/2
Part c
Event C = {5, 6}. n(C) = 2.
P(>4) = 2/6 = 1/3
✅ (a) 1/6  |  (b) 1/2  |  (c) 1/3
Example 2Complement Rule
Problem: A bag contains 4 red, 3 blue and 5 green balls. One ball is drawn at random. Find the probability that it is NOT red.
Step 1
n(S) = 4 + 3 + 5 = 12. n(red) = 4.
P(red) = 4/12 = 1/3
Step 2
Use the complement rule:
P(not red) = 1 − 1/3 = 2/3
✅ P(not red) = 2/3
Example 3Addition Rule — Non-Exclusive Events
Problem: A card is drawn from a standard 52-card deck. Find the probability of drawing a King or a Heart.
Step 1
P(King) = 4/52.   P(Heart) = 13/52.
These are not mutually exclusive — the King of Hearts is in both.
Step 2
P(King ∩ Heart) = 1/52 (only the King of Hearts).
Step 3
Apply the general addition rule:
P(King ∪ Heart) = 4/52 + 13/52 − 1/52 = 16/52 = 4/13
✅ P(King or Heart) = 4/13
Example 4Multiplication Rule — Independent Events
Problem: A coin is flipped and a die is rolled. Find the probability of getting Heads AND a 5.
Step 1
These are independent — the coin does not affect the die.
P(Heads) = 1/2.   P(5) = 1/6.
Step 2
P(Heads AND 5) = 1/2 × 1/6 = 1/12
✅ P(Heads and 5) = 1/12
Example 5Dependent Events — Without Replacement
Problem: A bag has 5 red and 3 blue balls. Two balls are drawn one at a time without replacement. Find the probability both are red.
Step 1
P(1st ball is red) = 5/8.
Step 2
Given the 1st was red, 4 red remain out of 7 total:
P(2nd red | 1st red) = 4/7.
Step 3
P(both red) = 5/8 × 4/7 = 20/56 = 5/14
✅ P(both red) = 5/14

Lesson Summary
Everything you learned in Lesson 2
✅ Key Points — Introduction to Probability
  • Probability measures likelihood on a scale from 0 (impossible) to 1 (certain). P(S) = 1 always.
  • Classical probability: P(A) = n(A) / n(S) — use only when all outcomes are equally likely.
  • Complement rule: P(A') = 1 − P(A). Use it when counting "not A" is easier than counting A.
  • General addition rule: P(A∪B) = P(A) + P(B) − P(A∩B). Subtract the overlap to avoid double-counting.
  • Mutually exclusive events cannot both occur: P(A∩B) = 0, so P(A∪B) = P(A) + P(B).
  • Independent events: P(A∩B) = P(A) × P(B). One event does not change the probability of the other.
  • Dependent events: P(A∩B) = P(A) × P(B|A). Update the probability after the first event occurs.
  • Without replacement → dependent events. With replacement → independent events.
