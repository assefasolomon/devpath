Unit 3 · Differential Calculus

⚡ Rules of Differentiation

Master the five essential differentiation rules — Power, Product, Quotient, Chain and Trigonometric. These rules are the practical toolkit that lets you differentiate any function quickly without using first principles every time.

📖 Reading: ~25 min
✏️ Examples: 5 worked

Introduction
Why rules matter

In Lesson 1 you used the limit definition to find derivatives from first principles. That method always works, but it is slow and tedious for complex functions. Imagine finding the derivative of f(x) = (x³ + 2x)(sin x) from scratch using limits — it would take a page of working.

Mathematicians have proven shortcut rules that let you differentiate instantly. These differentiation rules are the most used tools in all of calculus. The Ethiopian entrance exam expects you to apply them quickly and correctly.

By the end of this lesson you will be able to:

  • Apply the Constant Rule: d/dx[c] = 0
  • Apply the Power Rule: d/dx[xⁿ] = nxⁿ⁻¹
  • Apply the Sum/Difference Rule: (f ± g)' = f' ± g'
  • Apply the Product Rule: (fg)' = f'g + fg'
  • Apply the Quotient Rule: (f/g)' = (f'g − fg')/g²
  • Apply the Chain Rule: d/dx[f(g(x))] = f'(g(x))·g'(x)
  • Differentiate basic trigonometric functions: sin, cos, tan

Explanation
All differentiation rules with visual examples

2.1 Basic Rules

The four basic rules that handle most polynomial and simple function derivatives.
Rule 1 Power Rule — Most Used Rule on the Exam
d/dx [xⁿ] = n · xⁿ⁻¹
Bring the exponent down as a coefficient, then reduce the exponent by 1.

d/dx[x⁵] = 5x⁴
d/dx[x] = 1·x⁰ = 1
d/dx[x⁻²] = −2x⁻³ = −2/x³
d/dx[√x] = d/dx[x^(1/2)] = (1/2)x^(−1/2) = 1/(2√x)
Rule 2 Product Rule
(f · g)' = f'g + fg'
"Derivative of first times second, plus first times derivative of second."

Memory trick: "first · d(second) + second · d(first)"

Example: d/dx[(x²)(sin x)]
= 2x · sin x + x² · cos x
Product Rule memory: d(first)·second + first·d(second)
Rule 3 Quotient Rule
(f/g)' = (f'g − fg') / g²
Memory trick: "low d(high) minus high d(low), over low squared" (where high = numerator, low = denominator)

Example: d/dx[(x²+1)/(x−3)]
= [(2x)(x−3) − (x²+1)(1)] / (x−3)²
= [2x²−6x − x²−1] / (x−3)²
= (x²−6x−1) / (x−3)²
⚠ Sign Order Matters!

In the quotient rule the subtraction is f'g − fg', NOT fg' − f'g. Getting the sign wrong is the most common mistake. Always: numerator derivative first, then minus.

Rule 4 Chain Rule — Composite Functions
d/dx[f(g(x))] = f'(g(x)) · g'(x)
Used when a function is composed inside another function. Differentiate the outer function first (keeping inner unchanged), then multiply by the derivative of the inner function.
d/dx [outer]
at inner function
×
d/dx [inner]
derivative of inside
=
f'(g(x))·g'(x)
chain rule result
Example 1: d/dx[(x²+3)⁵]
Outer = uⁿ → 5u⁴. Inner = x²+3 → 2x
= 5(x²+3)⁴ · 2x = 10x(x²+3)⁴

Example 2: d/dx[sin(3x²)]
Outer = sin(u) → cos(u). Inner = 3x² → 6x
= cos(3x²) · 6x = 6x cos(3x²)
Rule 5 Trigonometric Derivatives
Function f(x) Derivative f'(x) Memory Aid
sin(x) cos(x) sin → cos (positive)
cos(x) −sin(x) cos → −sin (negative)
tan(x) sec²(x) tan → sec squared
cot(x) −csc²(x) cot → −csc squared
sec(x) sec(x)·tan(x) sec → sec·tan
csc(x) −csc(x)·cot(x) csc → −csc·cot

2.2 Exponential and Logarithmic Derivatives

Exponential
d/dx[eˣ] = eˣ
d/dx[aˣ] = aˣ ln(a)
eˣ is the only function equal to its own derivative.
Logarithmic
d/dx[ln x] = 1/x
d/dx[log_a x] = 1/(x ln a)
Valid for x > 0.

Worked Examples
5 exam-style problems applying all rules
Example 1 Power Rule and Sum Rule
Problem: Differentiate f(x) = 4x⁵ − 3x³ + 7x − 2
Apply
Differentiate term by term using power rule:
f'(x) = 4(5x⁴) − 3(3x²) + 7(1) − 0
= 20x⁴ − 9x² + 7
✅ f'(x) = 20x⁴ − 9x² + 7
Example 2 Product Rule
Problem: Differentiate f(x) = (x² + 1)(3x − 2)
Identify
f = x²+1, g = 3x−2, f' = 2x, g' = 3
Product Rule
= f'g + fg' = 2x(3x−2) + (x²+1)(3)
= 6x²−4x + 3x²+3
= 9x²−4x+3
✅ f'(x) = 9x² − 4x + 3
Example 3 Quotient Rule
Problem: Differentiate f(x) = (x² + 3) / (2x − 1)
Identify
f = x²+3, g = 2x−1, f' = 2x, g' = 2
Quotient Rule
= (f'g − fg') / g²
= [2x(2x−1) − (x²+3)(2)] / (2x−1)²
= [4x²−2x − 2x²−6] / (2x−1)²
= (2x²−2x−6) / (2x−1)²
✅ f'(x) = (2x²−2x−6)/(2x−1)²
Example 4 Chain Rule
Problem: Differentiate f(x) = (3x² + 5)⁴
Identify
Outer: uⁿ where u = 3x²+5, n = 4. Inner: u = 3x²+5
Chain Rule
= 4(3x²+5)³ · d/dx[3x²+5]
= 4(3x²+5)³ · 6x
= 24x(3x²+5)³
✅ f'(x) = 24x(3x²+5)³
Example 5 Chain Rule with Trigonometry
Problem: Differentiate f(x) = sin(x² + 1)
Identify
Outer: sin(u) → cos(u). Inner: u = x²+1 → 2x
Chain Rule
f'(x) = cos(x²+1) · 2x = 2x cos(x²+1)
✅ f'(x) = 2x cos(x²+1)

Lesson Summary
All rules in one place
✅ Key Points — Rules of Differentiation
  • Constant Rule: d/dx[c] = 0 — constants vanish when differentiated.
  • Power Rule: d/dx[xⁿ] = nxⁿ⁻¹ — bring down the exponent, reduce by 1.
  • Sum/Difference: differentiate each term separately.
  • Product Rule: (fg)' = f'g + fg' — d(first)·second + first·d(second).
  • Quotient Rule: (f/g)' = (f'g − fg')/g² — note the subtraction order.
  • Chain Rule: d/dx[f(g(x))] = f'(g(x))·g'(x) — outer × inner derivative.
  • Trig: (sin x)' = cos x, (cos x)' = −sin x, (tan x)' = sec²x.
  • Exponential/Log: (eˣ)' = eˣ, (ln x)' = 1/x.
