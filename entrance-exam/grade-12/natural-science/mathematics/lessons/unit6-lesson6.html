➡️ Vectors in Space

Extend vectors from the plane into three dimensions. Define 3D vectors using ordered triples, perform vector addition, scalar multiplication and compute magnitude. Master the dot product to find angles between vectors — a key entrance exam topic.

📖 Reading: ~22 min
✏️ Examples: 5 worked
🎯 Quiz: 5 questions
🎥 Videos: 4 resources

Introduction
What you will learn in this lesson

A vector has both magnitude (size) and direction. In 2D, a vector is an ordered pair (a, b). In 3D, it becomes an ordered triple (a, b, c) — three components, one for each axis. The same operations (addition, scalar multiplication, dot product) extend naturally from 2D to 3D.

By the end of this lesson you will be able to:

  • Represent a 3D vector as an ordered triple v = (a, b, c) or as aî + bĵ + ck̂
  • Find the vector from point P₁ to point P₂: P₁P₂ = (x₂−x₁, y₂−y₁, z₂−z₁)
  • Perform vector addition, subtraction and scalar multiplication
  • Compute the magnitude (length): |v| = √(a²+b²+c²)
  • Find a unit vector in the direction of v
  • Compute the dot product and use it to find the angle between two vectors
  • Determine whether two vectors are perpendicular (dot product = 0) or parallel

Explanation
Complete theory with visual aids

2.1 Representing a Vector in Space

📌 3D Vector

A vector in space is an ordered triple of real numbers:

v = (a, b, c) = aî + bĵ + ck̂

where î = (1,0,0), ĵ = (0,1,0) and k̂ = (0,0,1) are the standard unit vectors along the x, y and z axes respectively. The numbers a, b, c are called the components of v.

Vector v = (a, b, c) from the origin, with components along each axis.

📌 Vector from P₁ to P₂

Given two points P₁(x₁, y₁, z₁) and P₂(x₂, y₂, z₂), the vector from P₁ to P₂ is:

P₁P₂ = (x₂−x₁, y₂−y₁, z₂−z₁)

The magnitude of this vector equals the distance between P₁ and P₂.

2.2 Vector Operations

Let u = (u₁, u₂, u₃) and v = (v₁, v₂, v₃) and let k be a scalar:

Addition
u + v = (u₁+v₁, u₂+v₂, u₃+v₃)
Add corresponding components
Subtraction
u − v = (u₁−v₁, u₂−v₂, u₃−v₃)
Subtract corresponding components
Scalar Multiplication
k·v = (kv₁, kv₂, kv₃)
Multiply every component by k
Zero Vector
0 = (0, 0, 0)
v + 0 = v for any vector v
Negative Vector
−v = (−v₁, −v₂, −v₃)
v + (−v) = 0
Equality
u = v iff u₁=v₁, u₂=v₂, u₃=v₃
All three components must match

2.3 Magnitude and Unit Vector

📌 Magnitude (Length) of a Vector

The magnitude of v = (a, b, c) is:

|v| = √(a² + b² + c²)

This is identical to the distance from the origin to the point (a, b, c).

📌 Unit Vector

A unit vector has magnitude 1. The unit vector in the direction of v is:

û = v / |v| = (a/|v|, b/|v|, c/|v|)

Divide every component by the magnitude. A unit vector preserves direction but has length 1.

📝 Standard unit vectors

î = (1,0,0), ĵ = (0,1,0), k̂ = (0,0,1) are the three standard unit vectors. Every vector v = (a,b,c) can be written as v = aî + bĵ + ck̂. Each has magnitude 1 and they are mutually perpendicular.

2.4 The Dot Product

The dot product (scalar product) of two vectors gives a number, not a vector. It connects the algebraic components to the geometric angle between the vectors.

📌 Dot Product — Algebraic Definition

For u = (u₁, u₂, u₃) and v = (v₁, v₂, v₃):

u · v = u₁v₁ + u₂v₂ + u₃v₃

Multiply corresponding components and add. The result is a scalar (number).

📌 Dot Product — Geometric Definition (Angle Formula)

If θ is the angle between u and v (0° ≤ θ ≤ 180°):

u · v = |u| |v| cos θ

Rearranging to find the angle:

cos θ = (u · v) / (|u| |v|)

Then θ = cos⁻¹((u · v) / (|u| |v|))

Perpendicular Vectors
u · v = 0
cos 90° = 0. If dot product is zero, vectors are perpendicular.
Parallel Vectors
u = k·v for some scalar k
Or |u·v| = |u||v| (cos θ = ±1, θ = 0° or 180°).
📝 Properties of the dot product

u·v = v·u (commutative)  |  u·(v+w) = u·v + u·w (distributive)  |  k(u·v) = (ku)·v  |  v·v = |v|²  |  î·î = ĵ·ĵ = k̂·k̂ = 1  |  î·ĵ = î·k̂ = ĵ·k̂ = 0

Worked Examples
5 exam-style problems solved step by step
Example 1Vector Operations — Addition and Scalar Multiplication
Problem: Let u = (2, −1, 3) and v = (1, 4, −2). Find: (a) u+v   (b) u−v   (c) 3u − 2v
(a)
u+v = (2+1, −1+4, 3+(−2)) = (3, 3, 1)
(b)
u−v = (2−1, −1−4, 3−(−2)) = (1, −5, 5)
(c)
3u = (6, −3, 9)   2v = (2, 8, −4)
3u−2v = (6−2, −3−8, 9−(−4)) = (4, −11, 13)
✅ (a) (3,3,1)  |  (b) (1,−5,5)  |  (c) (4,−11,13)
Example 2Magnitude and Unit Vector
Problem: Find the magnitude and unit vector of v = (2, −2, 1).
Magnitude
|v| = √(4+4+1) = √9 = 3
Unit vector
û = v/|v| = (2/3, −2/3, 1/3)
Verify
|û| = √(4/9+4/9+1/9) = √(9/9) = 1 ✓
✅ |v| = 3   û = (2/3, −2/3, 1/3)
Example 3Dot Product Calculation
Problem: Find u·v for u = (3, 1, −2) and v = (−1, 4, 2).
Formula
u·v = (3)(−1) + (1)(4) + (−2)(2)
= −3 + 4 − 4 = −3
✅ u · v = −3
Example 4Angle Between Two Vectors
Problem: Find the angle between u = (1, 2, 2) and v = (2, 1, −2).
Dot product
u·v = (1)(2)+(2)(1)+(2)(−2) = 2+2−4 = 0
Conclusion
Since u·v = 0, cos θ = 0, so θ = 90°.
The vectors are perpendicular.
✅ θ = 90° — the vectors are perpendicular.
Example 5Finding the Angle — Full Calculation
Problem: Find the angle between a = (1, 0, 1) and b = (1, 1, 0).
Dot product
a·b = (1)(1)+(0)(1)+(1)(0) = 1
Magnitudes
|a| = √(1+0+1) = √2
|b| = √(1+1+0) = √2
cos θ
cos θ = 1/(√2 · √2) = 1/2
θ = cos⁻¹(1/2) = 60°
✅ θ = 60°

Lesson Summary
Everything you learned in Lesson 6
✅ Key Points — Vectors in Space
  • A 3D vector v = (a, b, c) = aî + bĵ + ck̂ has three components along the x, y and z axes.
  • The vector from P₁(x₁,y₁,z₁) to P₂(x₂,y₂,z₂) is P₁P₂ = (x₂−x₁, y₂−y₁, z₂−z₁).
  • Addition: add corresponding components. Scalar multiplication: multiply every component by the scalar.
  • Magnitude: |v| = √(a²+b²+c²). This equals the distance from the origin to (a,b,c).
  • Unit vector: û = v/|v|. Same direction as v, length 1. Divide every component by |v|.
  • Dot product: u·v = u₁v₁+u₂v₂+u₃v₃. The result is a scalar.
  • Angle formula: cos θ = (u·v)/(|u||v|). If u·v = 0 the vectors are perpendicular (θ = 90°).
  • Vectors are parallel if one is a scalar multiple of the other: u = kv for some k ≠ 0.
  • Standard unit vectors: î=(1,0,0), ĵ=(0,1,0), k̂=(0,0,1). They are mutually perpendicular with magnitude 1.
