🔐 Methods of Proof

Learn the four proof techniques that appear on the Ethiopian entrance exam: direct proof, proof by contrapositive, proof by contradiction, and mathematical induction. Each has a specific structure — master them all and you can prove any statement the exam throws at you.

📖 Reading: ~22 min
✏️ Examples: 5 worked
🎯 Quiz: 5 questions
🎥 Videos: 4 resources

Introduction
What you will learn in this lesson

A proof is a logical argument that establishes the truth of a mathematical statement beyond all doubt. Unlike examples (which only show something works sometimes), a proof shows it works always. Every theorem in mathematics rests on a proof.

By the end of this lesson you will be able to:

  • Explain what a mathematical proof is and why examples are not proofs
  • Write a direct proof: assume p, derive q step by step
  • Write a proof by contrapositive: prove ¬q → ¬p instead of p → q
  • Write a proof by contradiction: assume ¬p, derive a contradiction
  • Apply mathematical induction: base case + inductive step
  • Identify which proof method is most appropriate for a given problem
  • Recognise a counterexample as a disproof of a universal statement
📖
Explanation
All four proof methods with structure and examples
Method 1
Direct Proof
The most natural proof method. You start by assuming the hypothesis p is true, then use definitions, axioms and previously proved results to logically derive the conclusion q. It directly proves p → q.
1
Write "Assume p" — state the hypothesis as given.
2
Use logical steps (algebra, definitions, theorems) to transform p toward q.
3
Arrive at q and write "Therefore q" or "Hence proved." Mark with □ or QED.
📝 Best used when

The conclusion q follows naturally from p by straightforward algebra or definition-chasing. If you can see a clear path from p to q, use a direct proof.

Method 2
Proof by Contrapositive
Since p → q is logically equivalent to ¬q → ¬p, proving the contrapositive proves the original statement. You assume ¬q is true and derive ¬p. No contradiction needed — it is still a direct proof, just of the contrapositive.
1
State you will prove the contrapositive: "We prove ¬q → ¬p."
2
Assume ¬q (the negation of the conclusion).
3
Derive ¬p (the negation of the hypothesis) through logical steps.
4
Conclude: "Since ¬q → ¬p, by contrapositive p → q is proved." □
📝 Best used when

The hypothesis p is hard to work with directly, but the negation ¬q gives you something concrete to start from. Common in number theory proofs about even/odd integers.

Method 3
Proof by Contradiction (Reductio ad Absurdum)
You assume the opposite of what you want to prove (assume ¬p), then show this assumption leads to a logical impossibility — a statement that is always false. Since a false assumption produced a contradiction, the original assumption ¬p must be wrong, so p must be true.
1
Write "Assume for contradiction that ¬p" (the negation of what you want to prove).
2
Use valid logical steps from ¬p until you reach a statement that contradicts a known fact, an axiom, or the assumption itself.
3
Write "This is a contradiction. Therefore our assumption is false, and p must be true." □
📝 Best used when

Proving that something does NOT exist, or proving irrational/infinite statements. The classic example is proving √2 is irrational.

Method 4
Mathematical Induction
Used to prove statements of the form "P(n) is true for all positive integers n." It works like an infinite chain of dominoes: prove the first falls (base case), then prove each domino knocks over the next (inductive step).
📌 Structure of Mathematical Induction

Step 1 — Base Case: Prove P(1) is true (or P(0), or whatever the starting value is).

Step 2 — Inductive Hypothesis: Assume P(k) is true for some arbitrary positive integer k.

Step 3 — Inductive Step: Using the assumption that P(k) is true, prove that P(k+1) is also true.

Conclusion: Since P(1) is true and P(k) true implies P(k+1) true, by induction P(n) is true for all positive integers n. □

📝 Best used when

The statement involves a formula with n (like the sum of the first n integers), or any claim about all natural numbers. The key is finding how P(k+1) connects to P(k).

Disproving with a Counterexample

📌 Counterexample

To disprove a universal statement ("For all x, P(x) is true"), you only need to find one specific value of x for which P(x) is false. That one example is called a counterexample.

Example: Disprove "All prime numbers are odd."
Counterexample: 2 is prime and even. □

⚠ Critical distinction

One example proves nothing universally (you cannot prove "all swans are white" by showing one white swan). But one counterexample disproves a universal claim instantly. On the exam, if asked to "disprove" — find a counterexample, not a proof.

Worked Examples
5 exam-style proofs solved step by step
Example 1Direct Proof — Sum of Two Even Numbers
Prove: If m and n are even integers, then m + n is even.
Assume
Let m and n be even integers. By definition of even, there exist integers a and b such that m = 2a and n = 2b.
Derive
Then:
m + n = 2a + 2b = 2(a + b)
Since a and b are integers, a + b is an integer. Call it c = a + b.
Conclude
Then m + n = 2c, which is even by definition.
Proof. Let m = 2a and n = 2b for integers a, b. Then m + n = 2a + 2b = 2(a+b). Since a+b is an integer, m+n is even. □
✅ Direct proof: the sum of two even integers is even.
Example 2Proof by Contrapositive — Odd Product
Prove: If n² is even, then n is even. (Equivalently: if n is odd, then n² is odd.)
Strategy
Proving directly is hard — we do not know what form n takes when n² is even. Use contrapositive: prove "if n is odd then n² is odd."
Assume ¬q
Assume n is odd. Then n = 2k + 1 for some integer k.
Derive ¬p
n² = (2k+1)² = 4k² + 4k + 1 = 2(2k²+2k) + 1
Since 2k²+2k is an integer, n² = 2(integer) + 1, which is odd.
Proof (contrapositive). Assume n is odd; write n = 2k+1. Then n² = 4k²+4k+1 = 2(2k²+2k)+1, which is odd. Thus if n is odd, n² is odd — equivalently, if n² is even, n is even. □
✅ Contrapositive proof: if n² is even then n is even.
Example 3Proof by Contradiction — √2 is Irrational
Prove: √2 is irrational.
Assume ¬p
Assume for contradiction that √2 is rational. Then √2 = a/b where a, b are integers with no common factor (fraction in lowest terms) and b ≠ 0.
Derive
Squaring both sides: 2 = a²/b², so a² = 2b².
This means a² is even, so a is even (by Example 2). Write a = 2k.
Contradiction
Substitute: (2k)² = 2b² → 4k² = 2b² → b² = 2k².
So b² is even, meaning b is even.
But now both a and b are even — they share factor 2. This contradicts our assumption that a/b was in lowest terms.
Proof. Assume √2 = a/b in lowest terms. Then a² = 2b², so a is even; write a = 2k. Then 4k² = 2b², giving b² = 2k², so b is even. Both a and b even contradicts lowest terms. ∴ √2 is irrational. □
✅ Proof by contradiction: √2 is irrational.
Example 4Mathematical Induction — Sum of First n Integers
Prove: For all positive integers n, 1 + 2 + 3 + … + n = n(n+1)/2.
Base case
n = 1: Left side = 1. Right side = 1(1+1)/2 = 1. ✓ Base case holds.
Inductive hypothesis
Assume the formula holds for n = k:
1 + 2 + … + k = k(k+1)/2
Inductive step
Show it holds for n = k+1, i.e. that 1+2+…+k+(k+1) = (k+1)(k+2)/2.

Starting from the left side:
1+2+…+k+(k+1) = k(k+1)/2 + (k+1)   (by inductive hypothesis)
= (k+1)[k/2 + 1]
= (k+1)(k+2)/2 ✓
Proof by induction. Base: n=1 gives 1=1(2)/2=1 ✓. Hypothesis: assume Σᵢ₌₁ᵏ i = k(k+1)/2. Step: Σᵢ₌₁ᵏ⁺¹ i = k(k+1)/2 + (k+1) = (k+1)(k+2)/2. By induction, the formula holds for all n ≥ 1. □
✅ By induction: 1+2+…+n = n(n+1)/2 for all positive integers n.
Example 5Counterexample — Disproving a Statement
Disprove: "For all integers n, n² + n + 41 is prime."
Strategy
This formula gives primes for many values (n = 0 to 39). To disprove it, we need just one value of n where n² + n + 41 is NOT prime.
Try n = 40
40² + 40 + 41 = 1600 + 40 + 41 = 1681
Is 1681 prime? 1681 = 41 × 41 = 41² — not prime.
Conclusion
Since n² + n + 41 = 1681 = 41² is composite when n = 40, the statement "n² + n + 41 is prime for all integers n" is false.
Counterexample. Take n = 40: n²+n+41 = 1681 = 41², which is not prime. The statement is disproved. □
✅ Counterexample: n = 40 gives 41², which is not prime. Statement disproved.

Lesson Summary
Everything you learned in Lesson 2
✅ Key Points — Methods of Proof
  • A proof is a logically valid argument establishing a mathematical truth. Examples are not proofs — they only confirm individual cases.
  • Direct proof: assume p, apply definitions and algebra, derive q. Use when the path from p to q is straightforward.
  • Proof by contrapositive: assume ¬q and derive ¬p. Valid because p→q and ¬q→¬p are logically equivalent. Not a contradiction — a direct proof of the contrapositive.
  • Proof by contradiction: assume ¬p, derive a logical impossibility. Since ¬p leads to a contradiction, p must be true. Best for existence/non-existence and irrationality proofs.
  • Mathematical induction has two steps: (1) Base case — prove P(1) is true. (2) Inductive step — assume P(k) true, prove P(k+1) true. Then P(n) is true for all n ≥ 1.
  • To disprove a universal statement, produce one counterexample — a single case where the statement fails.
  • Key definitions used in proofs: even integer = 2k; odd integer = 2k+1; rational number = a/b where a, b integers, b ≠ 0.
