⚖️ Limit Theorems

Learn the official rules for computing limits algebraically. These theorems let you break complex limits into simpler pieces — a critical skill for the Ethiopian entrance exam. Includes the Squeeze Theorem with visual proof.

📖 Reading: ~25 min
✏️ Examples: 5 worked

Introduction
Why we need limit theorems

In Lesson 1, you learned the concept of a limit and evaluated simple ones by direct substitution or factoring. But what about more complex expressions like lim(x→2) [(x²+3x) · √(x+2)]? Do you need to build a table of values every time?

The answer is no. Mathematicians have proven a set of powerful rules — called limit theorems — that let you break any complex limit into simple, manageable pieces. These are the tools that make calculus practical.

By the end of this lesson you will be able to:

  • Apply all 8 basic limit theorems: sum, difference, product, quotient, constant, power, root, scalar
  • Evaluate complex limits by breaking them into simpler parts
  • Use the Squeeze Theorem to find limits that cannot be found algebraically
  • Apply the Special Limits: lim sin(x)/x = 1 and lim (1−cos x)/x = 0 as x→0
  • Recognize when each theorem applies and when it does not

Explanation
All 8 theorems with visual examples

2.1 Setup — The Foundation

All limit theorems assume: lim(x→a) f(x) = L and lim(x→a) g(x) = M both exist and are finite. Given this, the following rules hold:

If both limits L and M exist, you can combine functions using arithmetic operations.
Theorem 1 Sum Rule
lim(x→a) [f(x) + g(x)] = L + M
The limit of a sum equals the sum of the limits.
Example: lim(x→2)[x² + 3x] = lim(x²) + lim(3x) = 4 + 6 = 10
Theorem 2 Difference Rule
lim(x→a) [f(x) − g(x)] = L − M
The limit of a difference equals the difference of the limits.
Example: lim(x→3)[x² − 2x] = lim(x²) − lim(2x) = 9 − 6 = 3
Theorem 3 Constant Rule
lim(x→a) c = c
The limit of a constant is that constant — it never changes.
Example: lim(x→7) 5 = 5
Theorem 4 Scalar Multiple Rule
lim(x→a) [c · f(x)] = c · L
A constant multiplier comes outside the limit.
Example: lim(x→4) 3x² = 3 · lim(x²) = 3 · 16 = 48
Theorem 5 Product Rule
lim(x→a) [f(x) · g(x)] = L · M
The limit of a product equals the product of the limits.
Example: lim(x→2)[x · (x+1)] = lim(x) · lim(x+1) = 2 · 3 = 6
Theorem 6 Quotient Rule
lim(x→a) [f(x)/g(x)] = L/M   (M ≠ 0)
The limit of a quotient equals the quotient of the limits — only when denominator limit ≠ 0.
Example: lim(x→3)[(x²+1)/(x+2)] = (9+1)/(3+2) = 10/5 = 2
Theorem 7 Power Rule
lim(x→a) [f(x)]ⁿ = Lⁿ
The limit of a power equals the power of the limit.
Example: lim(x→3) (x+1)⁴ = (3+1)⁴ = 4⁴ = 256
Theorem 8 Root Rule
lim(x→a) ⁿ√f(x) = ⁿ√L   (L ≥ 0 for even n)
The limit of a root equals the root of the limit (provided the result is defined).
Example: lim(x→4) √(x+5) = √(4+5) = √9 = 3

2.2 The Squeeze Theorem (Sandwich Theorem)

Sometimes a function is too complex to evaluate directly. If you can squeeze it between two simpler functions that both approach the same limit, then the middle function must approach that limit too.

If g(x) ≤ f(x) ≤ h(x) near x=a, and both g and h approach L, then f must also approach L. f is "squeezed" to L.
📌 Squeeze Theorem — Formal Statement

If g(x) ≤ f(x) ≤ h(x) for all x near a, and
lim(x→a) g(x) = lim(x→a) h(x) = L, then:

lim(x→a) f(x) = L

Classic Application — lim(x→0) sin(x)/x = 1

Using geometry, we can show: cos(x) ≤ sin(x)/x ≤ 1 for x near 0
As x→0: cos(x) → 1 and 1 → 1
By the Squeeze Theorem: lim(x→0) sin(x)/x = 1

2.3 Two Special Limits to Memorise

Special Limit 1
lim(x→0) sin(x)/x = 1
Proved by Squeeze Theorem
x must be in radians
Special Limit 2
lim(x→0) (1−cos x)/x = 0
Derived from Special Limit 1
Also needs x in radians

2.4 Applying Theorems — Step by Step Visual

Let us evaluate lim(x→3) (x² + 4x − 1) by applying theorems one at a time:

Start lim(x→3) (x² + 4x − 1)
Sum Rule = lim(x²) + lim(4x) + lim(−1) → Theorems 1 & 2
Scalar Rule = lim(x²) + 4·lim(x) + lim(−1) → Theorem 4
Power Rule = [lim(x)]² + 4·lim(x) − 1 → Theorem 7
Substitute = (3)² + 4(3) − 1 = 9 + 12 − 1 → = 20

Worked Examples
5 exam-style problems solved step by step
Example 1 Applying Sum, Scalar and Power Rules
Problem: Evaluate lim(x→2) (3x³ − 5x + 4)
Sum Rule
= lim(3x³) − lim(5x) + lim(4)
Scalar & Power
= 3·lim(x)³ − 5·lim(x) + 4
Substitute
= 3(2)³ − 5(2) + 4 = 24 − 10 + 4 = 18
✅ lim(x→2) (3x³−5x+4) = 18
Example 2 Quotient Rule
Problem: Evaluate lim(x→4) (x²−2x)/(x+1)
Check
Denominator at x=4: 4+1 = 5 ≠ 0. Quotient Rule applies.
Quotient Rule
= lim(x²−2x) / lim(x+1)
Substitute
= (16−8)/(4+1) = 8/5
✅ Answer = 8/5
Example 3 Root Rule
Problem: Evaluate lim(x→7) √(x² − 13)
Root Rule
= √[lim(x→7)(x²−13)]
Substitute
= √(49−13) = √36 = 6
✅ lim(x→7) √(x²−13) = 6
Example 4 Special Limit — sin(x)/x Form
Problem: Evaluate lim(x→0) sin(5x)/(5x)
Identify
Let u = 5x. As x→0, u→0 as well.
Rewrite
lim(u→0) sin(u)/u = 1
by the special limit lim sin(x)/x = 1
✅ lim(x→0) sin(5x)/(5x) = 1
Example 5 Combining Multiple Theorems
Problem: Evaluate lim(x→3) [(x+1)² · √(x+6)]
Product Rule
= lim(x+1)² · lim√(x+6)
Power Rule
= [lim(x+1)]² · √[lim(x+6)]
Substitute
= (3+1)² · √(3+6) = 16 · √9 = 16 · 3 = 48
✅ lim(x→3) [(x+1)²·√(x+6)] = 48

✅ Key Points — Limit Theorems
  • Limit theorems let you break complex limits into simpler parts — assuming both individual limits exist.
  • Sum/Difference: lim(f±g) = L±M — split at addition and subtraction signs.
  • Constant: lim(c) = c — constants are unaffected by limits.
  • Scalar Multiple: lim(c·f) = c·L — pull constants outside.
  • Product: lim(f·g) = L·M — multiply the individual limits.
  • Quotient: lim(f/g) = L/M only when M ≠ 0.
  • Power/Root: lim(fⁿ) = Lⁿ and lim(ⁿ√f) = ⁿ√L.
  • Squeeze Theorem: if g ≤ f ≤ h and both g,h → L then f → L.
  • Special limits: lim(x→0) sin(x)/x = 1 and lim(x→0) (1−cos x)/x = 0.
