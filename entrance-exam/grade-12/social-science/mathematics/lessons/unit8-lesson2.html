📊 Representation of Data

Raw data is hard to interpret. Learn how to organise data into frequency distribution tables, tally charts and stem-and-leaf plots, and how to compute relative and cumulative frequencies — the foundation for every statistical graph and analysis that follows.

📖 Reading: ~20 min
✏️ Examples: 5 worked
🎯 Quiz: 5 questions
🎥 Videos: 4 resources
🎯
Introduction
What you will learn in this lesson

After data is collected, the next step is to organise and represent it so that patterns become visible. A list of 50 exam scores tells you almost nothing at a glance. The same data arranged in a frequency table or displayed in a histogram instantly reveals how scores are distributed, where most values fall, and how spread out they are.

By the end of this lesson you will be able to:

  • Distinguish between ungrouped and grouped frequency distributions
  • Construct a frequency distribution table with tally marks for raw data
  • Choose an appropriate class width and number of classes
  • Compute relative frequency and cumulative frequency for each class
  • Construct a stem-and-leaf plot and read values from it
  • Identify the class boundaries, class midpoints and class width
📖
Explanation
Complete theory with visual aids

2.1 Ungrouped vs Grouped Data

Ungrouped (Discrete) Data
Each individual value is listed with its frequency. Best when the data has few distinct values.

Example: number of siblings (0,1,2,3,4).
Grouped (Continuous) Data
Values are grouped into class intervals. Used when data has many distinct values or is continuous.

Example: exam scores (50–59, 60–69, …).

2.2 Building a Grouped Frequency Distribution Table

1
Find the range: Range = Maximum value − Minimum value.
2
Choose number of classes k: Usually 5–10 classes. Use Sturges' rule as a guide: k ≈ 1 + 3.322 log(n).
3
Calculate class width: w = Range ÷ k. Round up to a convenient number.
4
List class intervals starting from the minimum value (or just below it).
5
Tally each value into its class and count to get the frequency f.
6
Add relative and cumulative frequency columns.

2.3 Key Terms for Class Intervals

📌 Class Terminology

For the class 60 – 69:

• Lower class limit: 60 (smallest value in the class)
• Upper class limit: 69 (largest value in the class)
• Class width (w): 69 − 60 + 1 = 10 (for discrete data) or upper boundary − lower boundary for continuous
• Class midpoint (x̄ᵢ): (60 + 69)/2 = 64.5 — the central value, used in calculations
• Lower class boundary: 59.5 (midpoint between 59 and 60)
• Upper class boundary: 69.5 (midpoint between 69 and 70)

Note: Class boundaries remove the gap between consecutive classes — used when drawing histograms.

2.4 Stem-and-Leaf Plot

A stem-and-leaf plot displays each data value split into a stem (leading digit/s) and a leaf (last digit). It preserves all original values while showing the distribution — a compact alternative to a histogram for small datasets.

📌 How to Build a Stem-and-Leaf Plot

1. Sort the data in ascending order.
2. Choose stems (e.g. tens digits for two-digit data).
3. Write each stem once in the left column.
4. For each data value, write the leaf (units digit) next to its stem in the right column.
5. Leaves are written in order from smallest to largest.

Example: Ages of 15 participants: 23, 27, 31, 34, 34, 38, 41, 42, 45, 45, 47, 52, 55, 58, 61

2 3 7
3 1 4 4 8
4 1 2 5 5 7
5 2 5 8
6 1

Key: 2 | 3 means 23. Reading: stems are the tens digits, leaves are units digits.

📝 Advantages of stem-and-leaf plots

Unlike a frequency table, a stem-and-leaf plot preserves all original data values so you can read them back exactly. You can also find the median and mode directly from the plot without recalculation.

Example 1Constructing a Frequency Distribution Table
Problem: The scores of 20 students are: 45, 52, 63, 71, 58, 67, 74, 81, 55, 69, 77, 83, 61, 73, 88, 56, 65, 79, 84, 70. Construct a grouped frequency table with 5 classes.
Range
Min=45, Max=88. Range = 88−45 = 43
Width
w = 43÷5 = 8.6 → round up to 9. Use classes of width 10 for convenience: 40–49, 50–59, 60–69, 70–79, 80–89.
Tally
Count each score into its class:

Example 2Finding Class Midpoint and Boundaries
Problem: For the class 70–79, find: (a) class midpoint, (b) lower class boundary, (c) upper class boundary.
(a)
Midpoint = (70+79)/2 = 149/2 = 74.5
(b)
Lower class boundary = midpoint between upper limit of previous class (69) and lower limit of this class (70) = (69+70)/2 = 69.5
(c)
Upper class boundary = midpoint between 79 and 80 = (79+80)/2 = 79.5
✅ Midpoint = 74.5 · Lower boundary = 69.5 · Upper boundary = 79.5
Example 3Relative Frequency and Percentage
Problem: In a frequency table with n=40 students, the class 60–69 has frequency 12. Find: (a) relative frequency, (b) percentage frequency.
(a)
Relative frequency = f/n = 12/40 = 0.30
(b)
Percentage = 0.30 × 100% = 30%
✅ Relative frequency = 0.30 · Percentage = 30%
Example 4Reading a Stem-and-Leaf Plot
Problem: The stem-and-leaf plot below shows test scores. Find: (a) the number of students, (b) the minimum and maximum scores, (c) how many scored 70 or above.

Stem | Leaf
5 | 2 6 8
6 | 1 3 3 7 9
7 | 0 2 4 5 8
8 | 1 6
(a)
Count all leaves: 3 + 5 + 5 + 2 = 15 students
(b)
Minimum = smallest leaf on stem 5 = 52. Maximum = largest leaf on stem 8 = 86.
(c)
Stems 7 and 8: 5 leaves + 2 leaves = 7 students scored 70 or above.
✅ (a) 15 students  |  (b) Min=52, Max=86  |  (c) 7 students scored ≥ 70
Example 5Cumulative Frequency and Interpretation
Problem: A frequency table for the ages of 50 employees has: 20–29: f=8, 30–39: f=15, 40–49: f=18, 50–59: f=9. Find the cumulative frequency for each class and interpret CF for the 40–49 class.
CF table
20–29: CF = 8
30–39: CF = 8+15 = 23
40–49: CF = 23+18 = 41
50–59: CF = 41+9 = 50 ✓
Interpret
CF for 40–49 is 41. This means 41 out of 50 employees (82%) are aged 49 or under.
✅ CF: 8, 23, 41, 50. The CF of 41 for 40–49 means 41 employees are aged 49 or younger.

Lesson Summary
Everything you learned in Lesson 2
✅ Key Points — Representation of Data
  • Ungrouped data lists individual values with frequencies. Grouped data uses class intervals — better for large or continuous datasets.
  • Steps to build a grouped frequency table: find range → choose k classes → calculate width w = range÷k → list intervals → tally → count frequencies.
  • Class midpoint = (lower limit + upper limit)/2. Used in further calculations like the mean.
  • Class boundaries remove gaps between classes: lower boundary = (upper limit of previous class + lower limit of this class)/2.
  • Relative frequency = f/n. Gives the proportion in each class; all relative frequencies sum to 1.
  • Cumulative frequency = running total of frequencies. The last CF equals n (total number of data values).
  • A stem-and-leaf plot preserves all original values: the stem is the leading digit(s), the leaf is the last digit.
  • Sturges' rule suggests k ≈ 1 + 3.322 log(n) classes for a dataset of n values.
