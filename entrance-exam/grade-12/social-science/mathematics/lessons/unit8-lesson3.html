📈 Construction of Graphs

Turn frequency tables into visual stories. Learn to construct histograms, frequency polygons, bar charts and ogives (cumulative frequency curves), and understand what each graph reveals about the shape of a distribution.

📖 Reading: ~20 min
✏️ Examples: 5 worked
🎯 Quiz: 5 questions
🎥 Videos: 4 resources
🎯
Introduction
What you will learn in this lesson

A frequency table tells you the numbers, but a graph shows you the shape. Is the data symmetric? Skewed left or right? Are there outliers? Where is the bulk of the values? Graphs answer these questions instantly. In this lesson you will learn the four main graph types for grouped data and when to use each.

By the end of this lesson you will be able to:

  • Construct a histogram from a grouped frequency table
  • Construct a frequency polygon and understand how it relates to a histogram
  • Draw and interpret a bar chart for categorical data
  • Construct an ogive (cumulative frequency curve)
  • Read key information from each graph type (median, quartiles, mode class)
  • Choose the most appropriate graph for a given dataset
📖
Explanation
The four main types of statistical graphs

2.1 Histogram

A histogram is a bar chart for continuous data where the bars touch each other. The x-axis shows class boundaries, the y-axis shows frequency. Unlike a bar chart, there are no gaps — because continuous data has no gaps.

📌 Key features of a histogram

• Bars are drawn touching — using class boundaries (not class limits)
• Bar width = class width (all equal in a simple histogram)
• Bar height = frequency of that class
• The shape of the histogram reveals the distribution shape: symmetric, skewed, or bimodal

2.2 Frequency Polygon

A frequency polygon is a line graph connecting the class midpoints at heights equal to their frequencies. It's often overlaid on a histogram by joining the top-midpoints of each bar.

📌 How to construct a frequency polygon

1. Compute the midpoint of each class.
2. Plot a point at (midpoint, frequency) for each class.
3. Join consecutive points with straight lines.
4. To close the polygon, add one extra point at the midpoint before the first class (frequency 0) and one after the last class (frequency 0).

Frequency Polygon — Same data as the histogram above
Points plotted at (class midpoint, frequency) — connects smoothly and shows shape

2.3 Bar Chart

A bar chart displays categorical data — distinct categories on the x-axis (e.g. blood type, favourite subject, product type). Bars are separated by gaps because the categories are not continuous.

📌 Histogram vs Bar Chart — Don't confuse them

Histogram: continuous data, bars touch, x-axis is numerical (class boundaries)
Bar chart: categorical data, gaps between bars, x-axis is labels

Bar Chart — Students' Favourite Subjects
Bars have gaps — each bar is one category

2.4 Ogive (Cumulative Frequency Curve)

An ogive is a line graph of cumulative frequency against the upper class boundaries. It always rises from left to right (or stays flat) and ends at n (total frequency). It's the most useful graph for finding the median and quartiles.

📌 How to construct an ogive

1. Add a cumulative frequency (CF) column to your frequency table.
2. Compute the upper class boundary for each class.
3. Plot points at (upper boundary, cumulative frequency).
4. Join points with a smooth or straight line.
5. To find the median: draw a horizontal line at y = n/2 to the curve, then a vertical line down to the x-axis.

Ogive — Cumulative Frequency of Exam Scores
Reading the median: go up to n/2 = 15, across to the curve, then down to read x
📝 Using the ogive to find quartiles

• Q1 (first quartile): read across at n/4
• Q2 (median): read across at n/2
• Q3 (third quartile): read across at 3n/4
• Interquartile range (IQR): Q3 − Q1

2.5 Choosing the Right Graph

Bar chartCategoricalComparing distinct groups
HistogramContinuous (grouped)Showing distribution shape

Worked Examples
5 exam-style problems solved step by step
Example 1Identify the Graph Type
Problem: A researcher wants to display the distribution of heights (in cm) of 200 students, grouped into class intervals. Which graph is most appropriate?
Reasoning
Heights are continuous numerical data grouped into classes. We want to see the shape of the distribution.
Rule
For continuous data in class intervals, use a histogram (or frequency polygon).
✅ Use a histogram — appropriate for continuous grouped data.
Example 2Histogram vs Bar Chart
Problem: Why does a histogram have bars that touch, but a bar chart has gaps between bars?
Histogram
Data is continuous — there are no gaps between values. Moving from 50 to 51 to 52 is one smooth progression. So bars touch.
Bar chart
Data is categorical — Math, Physics, Chemistry are distinct labels with no natural order or continuity. So bars are separated by gaps.
✅ Histogram = continuous (touch). Bar chart = categorical (gaps).
Example 3Finding the Median from an Ogive
Problem: An ogive for 60 data values shows the curve passing through CF = 30 at the x-value 72. What is the median?
Rule
Median is read from the ogive at cumulative frequency = n/2 = 60/2 = 30.
Read
At CF = 30, the x-value is 72.
✅ Median = 72
Example 4Points for a Frequency Polygon
Problem: For a frequency table with classes 10–19 (f=4), 20–29 (f=8), 30–39 (f=10), 40–49 (f=6), 50–59 (f=2), list the coordinates of the points that make up the frequency polygon.
Midpoints
10–19: midpoint = 14.5
20–29: midpoint = 24.5
30–39: midpoint = 34.5
40–49: midpoint = 44.5
50–59: midpoint = 54.5
Points
Plot (midpoint, frequency):
(14.5, 4), (24.5, 8), (34.5, 10), (44.5, 6), (54.5, 2)
To close the polygon, add (4.5, 0) and (64.5, 0).
✅ Points: (14.5,4), (24.5,8), (34.5,10), (44.5,6), (54.5,2), plus endpoints (4.5,0) and (64.5,0).
Example 5Reading Quartiles from an Ogive
Problem: An ogive for 80 students passes through Q1 = 62, Q2 = 70, Q3 = 78. Find the interquartile range.
Rule
IQR = Q3 − Q1
Substitute
IQR = 78 − 62 = 16
✅ IQR = 16 — the middle 50% of students span 16 units of score.

Lesson Summary
Everything you learned in Lesson 3
✅ Key Points — Construction of Graphs
  • Histogram: for continuous grouped data; bars touch; x-axis = class boundaries; y-axis = frequency.
  • Frequency polygon: line graph connecting points at (class midpoint, frequency). Used to compare distributions.
  • Bar chart: for categorical data; bars have gaps; x-axis = category labels.
  • Ogive: line graph of cumulative frequency vs upper class boundaries. Always increasing, ends at n.
  • Median from ogive: read at CF = n/2.
  • Quartiles from ogive: Q1 at n/4, Q2 at n/2, Q3 at 3n/4.
  • IQR = Q3 − Q1 — measures spread of the middle 50%.
  • Histograms show shape (symmetric, skewed). Bar charts compare categories. Ogives reveal quartiles and percentiles.
