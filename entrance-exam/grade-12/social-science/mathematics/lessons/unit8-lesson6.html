📈 Use of Cumulative Frequency Curves

Master the ogive and box plot — the two most powerful visual tools for finding quartiles, percentiles and outliers. Learn to read any value from a cumulative frequency curve and construct a box plot from scratch.

📖 Reading: ~20 min
✏️ Examples: 5 worked
🎯 Quiz: 5 questions
🎥 Videos: 4 resources
🎯
Introduction
What you will learn in this lesson

A cumulative frequency curve (ogive) is a graph that shows the running total of frequencies. It reveals not just where data is, but how it accumulates — allowing you to find the median, quartiles, percentiles and outliers by simply reading from the graph. The box plot then condenses the same information into a compact five-number summary.

By the end of this lesson you will be able to:

  • Build and interpret a cumulative frequency table
  • Construct an ogive from grouped data
  • Find median, quartiles and percentiles from an ogive
  • Compute the interquartile range (IQR) and identify outliers
  • Construct a box plot (box-and-whisker plot) from the five-number summary
  • Interpret box plots — compare distributions at a glance
📖
Explanation
Complete theory with visual aids

2.1 Cumulative Frequency Table

To construct a cumulative frequency (CF) table, add each class's frequency to the sum of all previous frequencies. The last CF always equals n — the total number of data points.

ClassFrequency fCumulative Freq (CF)Upper Boundary
50 – 593359.5
60 – 6971069.5
70 – 79102079.5
80 – 8972789.5
90 – 9933099.5
Total30——
📝 Why "upper boundary" and not "upper limit"?

Upper class boundaries (e.g. 59.5 instead of 59) remove the gap between consecutive classes. The ogive is plotted against boundaries so the curve is continuous.

2.2 The Ogive (Cumulative Frequency Curve)

The ogive is a line graph with:

  • X-axis: upper class boundaries
  • Y-axis: cumulative frequency

It always rises from left to right (since CF only increases) and ends at (upper boundary of last class, n).

Reading the median from an ogive — go up to CF = n/2, across to the curve, then down to the x-axis.

📌 Reading values from an ogive

Median: go to CF = n/2 on the y-axis → horizontally to the curve → vertically down to the x-axis.

Q1 (first quartile): same process at CF = n/4.
Q3 (third quartile): same process at CF = 3n/4.

Percentile Pk: read at CF = (k/100) × n.

2.3 The Five-Number Summary

The five-number summary is the minimum set of values that describe a distribution — everything a box plot needs.

📌 Five-Number Summary

1. Minimum value — the smallest data point
2. Q1 — first quartile (25th percentile)
3. Q2 — median (50th percentile)
4. Q3 — third quartile (75th percentile)
5. Maximum value — the largest data point

From these five numbers you can also compute:
IQR = Q3 − Q1
Range = Max − Min

2.4 Box Plot (Box-and-Whisker Plot)

A box plot is a compact visual representation of the five-number summary:

  • Box: spans from Q1 to Q3 (the middle 50% of data)
  • Median line: drawn inside the box at Q2
  • Whiskers: extend from Q1 down to Min and from Q3 up to Max
  • Outliers: drawn as individual dots beyond the whiskers (if using 1.5×IQR rule)

Box plot — box shows IQR, line inside is median, whiskers extend to min and max.

📝 Comparing distributions with box plots

Box plots let you compare multiple distributions side by side:
• Higher median line → higher central value
• Wider box → higher IQR (more spread in the middle 50%)
• Longer whiskers → larger overall range
• Box shifted left/right → skewness direction

2.5 Percentiles and Their Uses

A percentile divides data into 100 equal parts. The kth percentile (Pk) is the value below which k% of the data lies.

PercentileRead ogive at CF =Interpretation
P100.10n10% of data lies below this value
P25 (= Q1)0.25nFirst quartile
P50 (= Q2 = Median)0.50nMiddle of data
P75 (= Q3)0.75nThird quartile
P900.90n90% of data lies below this value
📝 Exam tip

Entrance exam questions often ask: "What is the 60th percentile?" — just compute 0.60 × n, find that CF on the ogive, and read the x-value.

2.6 Identifying Outliers from an Ogive or Box Plot

📌 The 1.5×IQR Rule (Recap)

IQR = Q3 − Q1
Lower fence = Q1 − 1.5 × IQR
Upper fence = Q3 + 1.5 × IQR

Any data value below the lower fence or above the upper fence is an outlier. On a box plot, outliers appear as dots beyond the whiskers.

Worked Examples
5 exam-style problems solved step by step
Example 1Building a Cumulative Frequency Table
Problem: Construct a CF table for: 1–10 (f=4), 11–20 (f=7), 21–30 (f=9), 31–40 (f=5), 41–50 (f=2). Also list the upper class boundaries.
Step 1
Find n: 4 + 7 + 9 + 5 + 2 = 27
Step 2
Compute CF by adding cumulatively:
1–10 → CF = 4
11–20 → CF = 4+7 = 11
21–30 → CF = 11+9 = 20
31–40 → CF = 20+5 = 25
41–50 → CF = 25+2 = 27 ✓
Step 3
Upper class boundaries: 10.5, 20.5, 30.5, 40.5, 50.5
✅ n = 27. CF column: 4, 11, 20, 25, 27. Boundaries: 10.5, 20.5, 30.5, 40.5, 50.5.
Example 2Finding the Median from an Ogive
Problem: For the same distribution (n=27), the ogive passes through (25, 20) and (35, 27). Estimate the median.
Step 1
Locate CF = n/2 = 27/2 = 13.5 on the y-axis.
Step 2
CF = 13.5 falls between CF = 11 (x=20.5) and CF = 20 (x=30.5). Interpolate:
Median = 20.5 + [(13.5 − 11)/(20 − 11)] × (30.5 − 20.5)
= 20.5 + (2.5/9) × 10 = 20.5 + 2.78 = 23.28
✅ Median ≈ 23.3
Example 3Finding Quartiles and IQR
Problem: For n=27, Q1 is at CF = 6.75, Q3 is at CF = 20.25. The ogive gives Q1 = 17, Q3 = 30.5. Find the IQR.
Formula
IQR = Q3 − Q1
Substitute
IQR = 30.5 − 17 = 13.5
✅ IQR = 13.5
Example 4Identifying Outliers with the 1.5×IQR Rule
Problem: Using Q1 = 17, Q3 = 30.5, and IQR = 13.5, find the fence values. Is a data value of 55 an outlier?
Fences
Lower = Q1 − 1.5×IQR = 17 − 1.5(13.5) = 17 − 20.25 = −3.25
Upper = Q3 + 1.5×IQR = 30.5 + 1.5(13.5) = 30.5 + 20.25 = 50.75
Compare
Value 55 > 50.75 (upper fence). So 55 is an outlier.
✅ Lower fence = −3.25 · Upper fence = 50.75 · 55 is an outlier (above upper fence).
Example 5Constructing a Box Plot
Problem: Given the five-number summary — Min = 12, Q1 = 18, Median = 24, Q3 = 34, Max = 48 — construct a box plot and describe the distribution shape.
Draw
1. Draw a horizontal axis from 10 to 50.
2. Draw a rectangle (box) from Q1=18 to Q3=34.
3. Draw a line inside the box at Median=24.
4. Draw whiskers from Q1 down to Min=12 and from Q3 up to Max=48.
Analyze
Left half: Q1 to median = 24 − 18 = 6
Right half: median to Q3 = 34 − 24 = 10
Since the right half is longer, the distribution is right-skewed.
✅ Box plot complete. Distribution is right-skewed (longer right half of the box).

Lesson Summary
Everything you learned in Lesson 6
✅ Key Points — Cumulative Frequency Curves
  • A cumulative frequency (CF) is a running total of frequencies. The last CF = n.
  • The ogive plots CF against upper class boundaries. Always rises from left to right.
  • Reading the ogive: Median at CF = n/2, Q1 at CF = n/4, Q3 at CF = 3n/4, Pk at CF = (k/100)n.
  • The IQR = Q3 − Q1 measures spread of the middle 50% of data.
  • Outlier rule: any value below Q1 − 1.5×IQR or above Q3 + 1.5×IQR is an outlier.
  • The five-number summary (Min, Q1, Q2, Q3, Max) captures the entire distribution for a box plot.
  • The box plot: box spans Q1 to Q3, median line inside, whiskers extend to Min and Max. Outliers shown as dots.
  • Box plots allow quick comparison of multiple distributions — position, spread and skewness all visible at a glance.
