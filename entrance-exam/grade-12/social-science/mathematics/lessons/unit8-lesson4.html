📐 Measures of Central Tendency and Variability

Learn to compute the mean, median and mode from grouped data, and quantify the spread of a distribution using range, variance and standard deviation. Understand how central tendency and variability work together to describe a dataset completely.

📖 Reading: ~22 min
✏️ Examples: 5 worked
🎯 Quiz: 5 questions
🎥 Videos: 4 resources
🎯
Introduction
What you will learn in this lesson

Central tendency tells you where the centre of the data lies (mean, median, mode). Variability tells you how spread out the data is (range, variance, standard deviation). A complete description of any dataset requires both. Two classes can have the same average exam score but very different variability — one consistently strong, the other wildly inconsistent.

By the end of this lesson you will be able to:

  • Compute the mean of grouped data: x̄ = Σ(f·xᵢ)/Σf
  • Find the median of grouped data using the interpolation formula
  • Identify the modal class in a grouped distribution
  • Compute the range from a frequency distribution
  • Compute the variance and standard deviation of grouped data
  • Interpret what high vs low variability says about a dataset
📖
Explanation
Complete theory with formulas and examples

2.1 Mean of Grouped Data

For grouped data, we don't know each individual value — only the classes and their frequencies. So we approximate by using the class midpoint as the representative value of each class.

📌 Mean of Grouped Data

x̄ = Σ(fᵢ · xᵢ) / Σfᵢ

where fᵢ = frequency of class i, xᵢ = midpoint of class i, and Σfᵢ = total frequency n.

Steps: (1) Find the midpoint of each class. (2) Multiply each midpoint by its frequency. (3) Sum these products. (4) Divide by n.

2.2 Median of Grouped Data

For grouped data, the median is estimated using interpolation within the median class — the class where the cumulative frequency first reaches or exceeds n/2.

📌 Median Formula for Grouped Data

Median = L + [(n/2 − CF) / f] × w

where:
• L = lower class boundary of the median class
• n = total frequency
• CF = cumulative frequency of the class before the median class
• f = frequency of the median class
• w = class width

📝 Reading the formula

"n/2 − CF" measures how far into the median class we need to go. Dividing by f gives the fraction of that class. Multiplying by w converts the fraction into actual units on the x-axis. Adding L places it in the correct location.

2.3 Modal Class (Mode of Grouped Data)

For grouped data, we identify the modal class — the class with the highest frequency. If we want a single mode value, we estimate it using the formula below.

📌 Mode Formula for Grouped Data

Mode = L + [(f₁ − f₀) / (2f₁ − f₀ − f₂)] × w

where:
• L = lower boundary of the modal class
• f₁ = frequency of the modal class (highest)
• f₀ = frequency of the class before the modal class
• f₂ = frequency of the class after the modal class
• w = class width

2.4 Range

📌 Range

Range = Maximum value − Minimum value

For grouped data, use the lower class boundary of the first class and the upper class boundary of the last class:

Range = Upper boundary of last class − Lower boundary of first class

2.5 Variance and Standard Deviation (Grouped Data)

📌 Variance and Standard Deviation — Grouped

σ² = Σfᵢ(xᵢ − x̄)² / n
σ = √σ²

where xᵢ = class midpoint, x̄ = mean, fᵢ = class frequency, n = Σfᵢ.

Alternative (computational) formula:
σ² = Σfᵢxᵢ² / n − x̄²
This is often faster and reduces rounding errors.

📝 Interpreting standard deviation

Small σ → data is tightly clustered around the mean.
Large σ → data is spread widely.
Comparing two datasets: the one with a larger σ is more variable (less consistent).

2.6 Central Tendency + Variability Together

Consider two classes with the same mean score:

Class A
Mean = 70, σ = 5

Students perform consistently near 70. Most scores fall between 65 and 75.
Class B
Mean = 70, σ = 15

Some score 40, others 100. Huge variation despite the same average.

Lesson: Reporting only the mean is misleading. Always report the standard deviation (or variance) alongside the mean for a complete picture.

Worked Examples
5 exam-style problems solved step by step
Example 1Mean of Grouped Data
Problem: Find the mean of the following frequency distribution:
Class 10–19 (f=5), 20–29 (f=8), 30–39 (f=12), 40–49 (f=6), 50–59 (f=4).
Midpoints
14.5, 24.5, 34.5, 44.5, 54.5
fᵢ·xᵢ
5×14.5 = 72.5
8×24.5 = 196
12×34.5 = 414
6×44.5 = 267
4×54.5 = 218
Σfᵢxᵢ = 1167.5
Mean
Σfᵢ = 5+8+12+6+4 = 35
x̄ = 1167.5 / 35 ≈ 33.36
✅ Mean x̄ ≈ 33.36
Example 2Median of Grouped Data
Problem: Find the median of the same distribution: 10–19 (f=5), 20–29 (f=8), 30–39 (f=12), 40–49 (f=6), 50–59 (f=4).
CF column
10–19: CF = 5
20–29: CF = 13
30–39: CF = 25
40–49: CF = 31
50–59: CF = 35
Locate median class
n/2 = 35/2 = 17.5. First CF ≥ 17.5 is 25 (class 30–39). So the median class is 30–39.
Apply formula
L = 29.5 (lower boundary of median class)
CF = 13 (cumulative freq before median class)
f = 12, w = 10
Median = 29.5 + [(17.5 − 13)/12] × 10
= 29.5 + (4.5/12) × 10 = 29.5 + 3.75 = 33.25
✅ Median ≈ 33.25
Example 3Modal Class and Mode
Problem: Identify the modal class and estimate the mode for the same distribution.
Modal class
Highest frequency is 12, in class 30–39.
Formula
L = 29.5, f₁ = 12, f₀ = 8 (class before), f₂ = 6 (class after), w = 10
Mode = 29.5 + [(12−8)/(2×12−8−6)] × 10
= 29.5 + (4/10) × 10 = 29.5 + 4 = 33.5
✅ Modal class = 30–39 · Estimated mode ≈ 33.5
Example 4Standard Deviation of Grouped Data
Problem: Compute the standard deviation for the same distribution (mean = 33.36).
Table
10–19: xᵢ=14.5, f=5, xᵢ−x̄=−18.86, (xᵢ−x̄)²≈355.7, f·(xᵢ−x̄)²≈1778.5
20–29: xᵢ=24.5, f=8, xᵢ−x̄=−8.86, (xᵢ−x̄)²≈78.5, f·≈628.0
30–39: xᵢ=34.5, f=12, xᵢ−x̄=1.14, (xᵢ−x̄)²≈1.30, f·≈15.6
40–49: xᵢ=44.5, f=6, xᵢ−x̄=11.14, (xᵢ−x̄)²≈124.1, f·≈744.6
50–59: xᵢ=54.5, f=4, xᵢ−x̄=21.14, (xᵢ−x̄)²≈446.9, f·≈1787.6
Σf·(xᵢ−x̄)² ≈ 4954.3
Variance
σ² = 4954.3 / 35 ≈ 141.55
SD
σ = √141.55 ≈ 11.90
✅ Standard deviation ≈ 11.90
Example 5Comparing Two Distributions
Problem: Class A has mean 65 and SD 8; Class B has mean 65 and SD 20. Compare the performance of the two classes.
Mean
Both classes have the same average performance (65).
Variability
Class A: σ=8 — most students score between 57 and 73.
Class B: σ=20 — most students score between 45 and 85.
CV comparison
CV_A = 8/65 × 100% ≈ 12.3%
CV_B = 20/65 × 100% ≈ 30.8%
✅ Class A is more consistent. Class B has much higher variability despite the same mean — the SD reveals what the mean hides.

Lesson Summary
Everything you learned in Lesson 4
✅ Key Points — Central Tendency and Variability
  • Mean of grouped data: x̄ = Σfᵢxᵢ / Σfᵢ — use class midpoints as representative values.
  • Median of grouped data: Median = L + [(n/2 − CF)/f] × w — locate the median class where CF first reaches n/2.
  • Mode of grouped data: Modal class = class with highest frequency. Estimated mode uses the formula with f₀, f₁, f₂.
  • Range = max − min. For grouped data use class boundaries.
  • Variance: σ² = Σfᵢ(xᵢ−x̄)²/n. Measures the average squared deviation from the mean.
  • Standard deviation: σ = √σ². Same units as the original data.
  • Coefficient of variation: CV = (σ/x̄) × 100%. Compares variability across datasets with different means or units.
  • Central tendency describes the middle; variability describes the spread. Both are needed for a complete picture — two datasets with the same mean can be very different.
